# Foundry VTT Limited License Agreement Analysis

> Source: https://foundryvtt.com/article/license/

## Key Developer & User Constraints
1. **Single Hosted Instance per License:** A single software license grants the right to host one active instance for players at any given time.
2. **No Redistribution of Core Code:** Developers may NOT bundle, distribute, or mirror the core Foundry Virtual Tabletop software files.
3. **Add-on Package Ownership:** Developers retain full intellectual property ownership of their original code, systems, and modules.
4. **Third-Party Content:** Developers must respect copyrights of RPG publishers when creating compendiums or systems.
