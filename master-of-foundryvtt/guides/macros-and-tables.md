# Guide: Macros, Rollable Tables & Compendiums

1. **Script Macros:** Execute asynchronous JavaScript with access to `actor`, `token`, `canvas`, and `game`.
2. **Rollable Tables:** Programmatic rolling via `const table = game.tables.getName('Loot'); const result = await table.draw();`.
3. **Compendiums:** Locking, unlocking, creating packs, and migrating content.
