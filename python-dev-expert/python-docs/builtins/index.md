Referência da bibliotecas embutidas do Python
*********************************************

Python vem com diversas funções e classes embutidas.

As classes embutidas incluem tipos de dados que seriam normalmente
considerados como parte "central" de uma linguagem, tais como números
e listas. Para esses tipos, o núcleo da linguagem Python define a
forma de literais e coloca algumas restrições em suas semânticas, mas
não define completamente as semânticas.

Os *built-ins* também incluem funções e  exceções --- objetos que
podem ser usados por todo o código Python sem a necessidade de uma
instrução "import". Alguns desses são definidos pelo núcleo da
linguagem, mas muitos não são essenciais para as semânticas principais
e são apenas descritos aqui.
