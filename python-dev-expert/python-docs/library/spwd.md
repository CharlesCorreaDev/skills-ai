"spwd" --- O banco de dados de senhas shadow
********************************************

Descontinuado desde a versão 3.11, removido na versão 3.13.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.13 após ser descontinuado no Python 3.11. A
remoção foi decidida na **PEP 594**.

Uma possível substituição é a biblioteca de terceiros python-pam. Esta
biblioteca não é suportada ou mantida pela equipe principal do Python.

A última versão do Python que forneceu o módulo "spwd" foi o Python
3.12.
