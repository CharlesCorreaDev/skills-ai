"smtpd" --- Serviços SMTP
*************************

Descontinuado desde a versão 3.6, removido na versão 3.12.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.12 após ser descontinuado no Python 3.6. A
remoção foi decidida na **PEP 594**.

Uma possível substituição é a biblioteca de terceiros aiosmtpd. Esta
biblioteca não é mantida ou suportada pela equipe principal do Python.

A última versão do Python que forneceu o módulo "smtpd" foi o Python
3.11.
