"distutils" --- Criação e instalação de módulos do Python
*********************************************************

Descontinuado desde a versão 3.10, removido na versão 3.12.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.12 após ser descontinuado no Python 3.10. A
remoção foi decidida na **PEP 632**, a qual tem um conselho de
migração.

A última versão do Python que forneceu o módulo "distutils" foi o
Python 3.11.
