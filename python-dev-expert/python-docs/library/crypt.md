"crypt" --- Função para verificar senhas Unix
*********************************************

Descontinuado desde a versão 3.11, removido na versão 3.13.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.13 após ser descontinuado no Python 3.11. A
remoção foi decidida na **PEP 594**.

As aplicações podem usar o módulo "hashlib" da biblioteca padrão.
Outras possíveis substituições são bibliotecas de terceiros do PyPI:
legacycrypt, bcrypt ou argon2-cffi. Elas não são suportadas nem
mantidas pela equipe core do Python.

A última versão do Python que forneceu o módulo "crypt" foi o Python
3.12.
