"cgi" --- Suporte a Common Gateway Interface
********************************************

Descontinuado desde a versão 3.11, removido na versão 3.13.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.13 após ser descontinuado no Python 3.11. A
remoção foi decidida na **PEP 594**.

Um fork do módulo no PyPI pode ser usado em vez disso: legacy-cgi.
Esta é uma cópia do módulo cgi, não mais mantido ou suportado pela
equipe core do Python.

A última versão do Python que forneceu o módulo "cgi" foi o Python
3.12.
