"sndhdr" --- Determina o tipo de arquivos de som
************************************************

Descontinuado desde a versão 3.11, removido na versão 3.13.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.13 após ser descontinuado no Python 3.11. A
remoção foi decidida na **PEP 594**.

Possíveis substituições são módulos de terceiros do PyPI: filetype,
puremagic ou python-magic. Eles não são suportados ou mantidos pela
equipe principal do Python.

A última versão do Python que forneceu o módulo "sndhdr" foi o Python
3.12.
