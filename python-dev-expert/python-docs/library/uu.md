"uu" --- Codifica e decodifica arquivos uuencode
************************************************

Descontinuado desde a versão 3.11, removido na versão 3.13.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.13 após ser descontinuado no Python 3.11. A
remoção foi decidida na **PEP 594**.

A codificação e a decodificação no formato uu podem ser realizadas,
alternativamente, utilizando "codecs.encode()" e "codecs.decode()",
especificando ""uu"" como a codificação.

A última versão do Python que forneceu o módulo "uu" foi o Python
3.12.
