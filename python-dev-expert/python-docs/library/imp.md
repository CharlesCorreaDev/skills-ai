"imp" --- Acessa os componentes internos de importação
******************************************************

Descontinuado desde a versão 3.4, removido na versão 3.12.

Este módulo não faz mais parte da biblioteca padrão do Python. Ele foi
removido no Python 3.12 após ser descontinuado no Python 3.4.

O aviso de remoção inclui orientação para migrar código de "imp" para
"importlib".

A última versão do Python que forneceu o módulo "imp" foi o Python
3.11.
