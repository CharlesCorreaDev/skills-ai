A Referência da Linguagem Python
********************************

Este manual de referência descreve a sintaxe e a semântica fundamental
da linguagem. Ele é conciso, mas busca ser preciso e completo.

Em outras partes, os tipos de objeto e funções embutidos são descritos
em Referência da bibliotecas embutidas do Python. Os módulos da
biblioteca padrão são descritos em A biblioteca padrão do Python.

Para uma introdução informal à linguagem, consulte O tutorial do
Python. Para programadores em C ou C++, existem dois manuais
adicionais: Estendendo e incorporando o interpretador Python descreve
a imagem de alto nível de como escrever um módulo de extensão Python,
e o Manual de referência da API C/Python descreve as interfaces
disponíveis para programadores C/C++ em detalhes.
