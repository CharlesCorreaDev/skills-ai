Como portar códigos do Python 2 para o Python 3
***********************************************

O Python 2 atingiu seu fim de vida oficial no início de 2020. Isso
significa que nenhum novo relatório de bug, correção ou alteração será
feito no Python 2 - ele não é mais compatível: consulte a **PEP 373**
e o status das versões do Python.

Se você está pensando em portar um módulo de extensão em vez de puro
código Python, veja Portando módulos de extensão para o Python 3.

A lista de discussão python-porting arquivada pode conter algumas
orientações úteis.

Desde o Python 3.11, o guia de portabilidade original foi
descontinuado. Você pode encontrar o guia antigo no arquivo.
