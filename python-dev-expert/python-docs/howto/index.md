Python HOWTOs
*************

Python HOWTOs (COMOFAZER) são documentos que cobrem um tópico
específico em profundidade. Modelada na coleção HOWTO do Linux
Documentation Project, esta coleção é um esforço para promover uma
documentação mais detalhada do que a Referência da Biblioteca do
Python.

Geral:

* Uma visão geral conceitual de asyncio

* Boas práticas para anotações

* Tutorial de Argparse

* Guia de descritores

* Enum

* Programação Funcional

* Uma introdução ao módulo ipaddress

* Logging

* Livro de receitas do logging

* Regular expression HOWTO

* Técnicas de ordenação

* Unicode

* Como buscar recursos da Internet usando o pacote urllib

Desenvolvimento avançado:

* Programação em Curses com Python

* Suporte do Python para threads livres

* Suporte a extensões da API C para threads livres

* Isolando módulos de extensão

* Migrating to Stable ABI for free threading (abi3t)

* A Ordem de Resolução de Métodos do Python 2.3

* Programação de Soquetes

* Descritor de arquivo de temporizador

* Portando módulos de extensão para o Python 3

Depuração e perfilação:

* Depurando extensões de API C e internos do CPython com GDB

* Instrumentando o CPython com DTrace e SystemTap

* Python support for the perf map compatible profilers

* Protocolo de anexação de depuração remota
