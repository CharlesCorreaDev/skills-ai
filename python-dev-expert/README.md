## 🇺🇸 English

### 📌 Overview
**Python Developer Expert** is an advanced AI agent skill and architectural knowledge base tailored for Python software engineers across Web (FastAPI, Django 6.1), Data Science (Pandas, NumPy), CLI automation, and asynchronous backend development.

It incorporates modern Pythonic practices, rigorous type hinting (`typing`, `mypy`), ultra-fast PDF reading with **PDF Oxide** (`pdf_oxide`), UI animations via **Claude-Motion**, and canonical AI agent engineering standards ([Karpathy Guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md), [Superpowers](https://github.com/obra/superpowers), [Claude Octopus](https://github.com/nyldn/claude-octopus), [AgentMemory](https://github.com/rohitg00/agentmemory), [Déjà Vu](https://github.com/vshulcz/deja-vu), and Matt Pocock's AI Coding Dictionary).

### 🌟 Core Capabilities
1. **Mandatory Environment & Version Check:** The agent automatically inspects the installed Python runtime (`python --version`) before generating code to guarantee syntax compatibility.
2. **First-Choice PDF Engine (`PDF Oxide`):** Ultra-fast Rust-based extraction, metadata inspection, and layout-to-Markdown conversion (`pip install pdf-oxide`), relegating legacy libraries to fallback.
3. **Advanced Web Development (Django 6.1 & FastAPI):** Asynchronous ORM, modern models, MVT patterns, and robust validation.
4. **Data Science & Scripting:** High-performance data pipelines with Pandas, NumPy, and modern packaging (Poetry, Pipenv).
5. **UI Motion Design (Claude-Motion):** Smooth micro-interactions, GPU acceleration, and visual taste for Python-generated web interfaces.
6. **Agent Memory & Consensus Standards:** Multi-model consensus and cross-session persistence via hybrid search and local transcript indexing.

## 🇧🇷 Português (Brasil)

### 📌 Visão Geral
A skill **Python Developer Expert** é uma suíte completa de engenharia de software sênior para Python, cobrindo desde automações e scripts até microsserviços modernos com FastAPI, arquitetura web robusta com Django 6.1 e ciência de dados.

### 🌟 Destaques Principais
- **Verificação Obrigatória de Versão:** A IA sempre inspeciona a versão instalada na máquina (`python --version`) para utilizar os recursos e sintaxes exatas do ambiente do usuário.
- **Leitura de PDF com PDF Oxide em 1º Lugar:** Extração ultrarrápida de texto e metadados (~0.8ms) via core em Rust (`pip install pdf-oxide`), com licença permissiva MIT/Apache-2.0 e conversão direta para Markdown.
- **Django 6.1 Avançado:** Referência profunda de arquitetura MVT, ORM assíncrono, formulários e middlewares.
- **Animações de Interface (Claude-Motion):** Aplicação de princípios de animação fluida para interfaces web desenvolvidas em Python (Django, Streamlit, Dash).
- **Padrões Canônicos de IA e Memória:** Adoção das diretrizes de Karpathy, orquestração multi-modelo (Octopus), camadas de memória persistente (AgentMemory e Déjà Vu) e Dicionário de AI Coding de Matt Pocock.
