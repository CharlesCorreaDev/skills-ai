# Glossário Técnico de UX/UI & Bootstrap / Technical Glossary 📖

Dicionário essencial de conceitos de Psicologia Cognitiva, Design de Interação e Framework Bootstrap:

- **Affordance (Capacidade de Uso / Pistas de Ação):** Características visuais de um objeto que comunicam como ele deve ser usado (ex: um botão Bootstrap com sombra `.shadow-sm` e relevo que convida ao clique).
- **ARIA (Accessible Rich Internet Applications):** Conjunto de atributos técnicos que tornam o conteúdo da web e os aplicativos mais acessíveis para usuários de tecnologias assistivas (leitores de tela).
- **Chunking (Fracionamento Cognitivo):** Técnica baseada na Lei de Miller de dividir grandes volumes de informação em pequenos pedaços ou "blocos" compreensíveis (ex: agrupamento em `.card` ou seções com divisores).
- **Color Contrast Ratio (Taxa de Contraste):** Razão matemática de luminância entre a cor do texto e a cor de fundo (mínimo de 4.5:1 exigido pela WCAG AA para texto padrão).
- **Dark Mode (Tema Escuro):** Suporte nativo do Bootstrap 5.3+ via atributo `data-bs-theme="dark"` gerenciado no elemento `<html>` ou em nós locais.
- **Error Recovery (Recuperação de Erros):** Padrão de UX que oferece caminhos fáceis e rápidos para o usuário desfazer uma ação indesejada (botões "Desfazer" ou histórico de versões).
- **Focus Ring:** Indicador visual que sinaliza qual elemento da página está selecionado pelo teclado.
- **Progressive Disclosure (Revelação Progressiva):** Mecanismo de UX para adiar a exibição de detalhes secundários ou complexos até que o usuário solicite explicitamente, diminuindo a carga cognitiva inicial (Lei de Hick).
- **Stretched Link:** Utilitário do Bootstrap (`.stretched-link`) que expande a área clicável de um link interno para todo o componente pai posicionado com `position-relative`.
- **Touch Target (Alvo de Toque):** A área mínima recomendada para interação por toque na tela (mínimo de 44x44px conforme Lei de Fitts e diretrizes de acessibilidade mobile).
