Diretriz de Acessibilidade em Alertas (WCAG 3.3.1)

Alertas não devem utilizar apenas a cor para transmitir o estado. A inclusão obrigatória de um ícone vetorial e texto descritivo garante que usuários daltônicos (Protanopia e Deuteranopia) compreendam o status imediatamente.

Use a classe .alert-dismissible para permitir que o usuário feche mensagens após a leitura.
