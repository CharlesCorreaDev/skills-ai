# Léxico Multilíngue, Falsos Cognatos & Nomenclatura Fantástica (EN / ES / PT-BR)
## Parte Integrante da Skill Escritor Pro

A criação de mundos ficcionais, campanhas de RPG e a escrita literária no Brasil dialogam constantemente com as tradições anglo-saxônica e hispânica. No entanto, a tradução direta sem critério introduz **barbarismos graves, falsos cognatos (falsos amigos) e inconsistências de tom**.

Este guia é a referência canônica para blindar o autor contra armadilhas linguísticas e fornecer raízes para criação de nomes críveis.

---

## 1. Falsos Cognatos Críticos na Literatura (EN ➔ PT-BR)

Ao traduzir ou conceber mentalmente uma cena a partir de tropos em inglês, evite os seguintes erros estatísticos frequentes:

| Termo em Inglês | Tradução Errada / Calque Vicioso | Sentido Real & Tradução Correta PT-BR |
| :--- | :--- | :--- |
| **Eventually** | *Eventualmente* (que em PT significa "às vezes / por acaso") | **Ao final, por fim, com o tempo, mais cedo ou mais tarde** |
| **Pretend** | *Pretender* (que em PT significa "ter a intenção de") | **Fingir, simular, aparentar** |
| **Intend** | *Entender* | **Pretender, ter a intenção de, planejar** |
| **Actually** | *Atualmente* (que em PT significa "nos dias de hoje") | **Na verdade, na realidade, de fato** |
| **Currently** | *Correntemente* | **Atualmente, no momento presente** |
| **Grip** | *Gripe* | **Empunhadura, pegada firme, garra** |
| **Armor / Plate** | *Armadura / Prato* | **Couraça, armadura de placas, cota** |
| **Novel** | *Novela* (teledramaturgia seriada) | **Romance literário** |
| **Anticipate** | *Antecipar* (adiantar data) | **Prever, esperar por, precaver-se contra** |
| **Reluctant** | *Relutante* (às vezes aceitável, mas vago) | **Reticente, hesitante, vacilante** |
| **Fabric** | *Fábrica* | **Tecido, estofo, pano, trama** |
| **Notice** | *Notícia* | **Aviso, percepção, reparar em algo** |
| **Patron** | *Patrão* (chefe direto) | **Mecenas, patrono, protetor, cliente assíduo** |
| **Realize** | *Realizar* (fazer acontecer) | **Dar-se conta de, perceber, notar** |
| **Hazard** | *Azar* | **Perigo iminente, risco, ameaça** |

## 2. Falsos Cognatos Críticos na Literatura (ES ➔ PT-BR)

Na narrativa de fantasia e horror inspirada no gótico espanhol ou cenários hispânicos:

| Termo em Espanhol | Falso Amigo em PT | Sentido Real & Tradução Correta |
| :--- | :--- | :--- |
| **Exquisito** | *Esquisito* (estranho, bizarro) | **Delicioso, refinado, primoroso, sublime** |
| **Raro** | *Raro* (apenas escasso) | **Estranho, bizarro, excêntrico, invulgar** |
| **Largo** | *Largo* (amplo, espaçoso) | **Comprido, longo** (espaçoso é *ancho*) |
| **Espalda** | *Espada* | **Costas, dorso** |
| **Cena** | *Cena* (de teatro/filme) | **Jantar, ceia** (cena é *escena*) |
| **Berro** | *Grito, berro* | **Agrião** (planta comestível) |
| **Borrar** | *Borrar* (sujar) | **Apagar, deletar, rasurar** |
| **Todavía** | *Todavia* (contudo, mas) | **Ainda, até agora** |
| **Polvo** | *Polvo* (molusco) | **Poeira, pó** (o molusco é *pulpo*) |
| **Crianza** | *Criança* | **Criação, cultivo, envelhecimento (de vinho)** |
| **Saco** | *Saco* (bolsa) | **Paletó, casaco, jaqueta** |
| **Tapa** | *Tapa* (bofetada) | **Tampa, aperitivo, petisco** |

## 4. Matriz de Raízes Etimológicas para Criação de Nomes Críveis

Evite nomes gerados por IA como *"Zorblax"* ou combinações aleatórias de apóstrofos (*"K'zhar'ul"*). Use raízes linguísticas que comuniquem a cultura imediatamente:

### 1. Cultura Anglo-Saxônica & Nórdica (Reinos do Norte, Geadas, Clãs)
* **Prefixos / Raízes:**
  * `Aethel-` (Nobre, honorável) ➔ *Aethelgard, Aethelred*.
  * `Grim-` (Severo, implacável, máscara) ➔ *Grimhold, Grimwald*.
  * `Thor- / Tor-` (Trovão, torre) ➔ *Tormund, Torheim*.
  * `Frost- / Ice-` (Gelo, frio) ➔ *Frostmark, Isenfell*.
* **Sufixos:**
  * `-mere` (Lago, charco) ➔ *Blackmere, Windermere*.
  * `-stead / -ton` (Assentamento, vila) ➔ *Ravenstead, Dunton*.
  * `-wick / -wich` (Aldeia comercial) ➔ *Northwick, Aldwich*.
  * `-fell` (Colina rochosa ou montanha) ➔ *Shadowfell, Highfell*.

### 2. Cultura Hispânica & Ibérica (Desertos, Impérios Solares, Inquisições)
* **Prefixos / Raízes:**
  * `Val- / Valle-` (Vale fértil ou fortaleza) ➔ *Valdepeñas, Valcárdenas*.
  * `Mon- / Monte-` (Elevação sagrada) ➔ *Montesolar, Montegrís*.
  * `San- / Santo-` (Tradição eclesiástica venerada) ➔ *San Lázaro, Santarém*.
  * `Brava- / Feroz-` (Bravura rude) ➔ *Peñabrava, Terrabrava*.
* **Sufixos:**
  * `-eda / -al` (Bosque ou abundância de algo) ➔ *Robleda, Olival, Cenizal*.
  * `-ero / -era` (Profissão ou lugar geográfico) ➔ *Calderero, Trinchera*.
  * `-dor / -dora` (Aquele que executa a justiça) ➔ *Castigador, Matadora*.
