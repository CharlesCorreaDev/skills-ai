## 🇺🇸 English

### 1. Headroom (`headroomlabs-ai/headroom`) — Context Window Optimizer
Headroom acts as a local proxy, MCP server, and Python library that compresses tool outputs, logs, file dumps, and RAG chunks before they consume the agent's context window.
- **Token Efficiency:** 20% fewer tokens in coding agent sessions; 60–95% compression on JSON tool dumps.
- **Zero Cloud Dependence:** Operates provider-neutrally and locally within your development perimeter.
- **Second Brain Integration:** Ensures that retrieval passes from Notion and local markdown vaults leave maximum headroom for the model's actual reasoning.

### 2. Caveman (`JuliusBrussee/caveman`) — ASD-STE100 Controlled Dialect
Created by Julius Brussee, Caveman eliminates conversational fluff and polite AI theater ("Sure, I can help with that...", "Let me check...") without degrading code or command fidelity.
- **Rule of Active Voice:** Sentences capped at 20 words maximum.
- **Immunity of Payload:** Code blocks, terminal commands, file paths, and stack traces remain 100% exact and untouched.
- **Safety Fallback:** Instantly reverts to plain English for destructive actions or user confusion.
- **Memory Role:** Shrinks episodic session logs stored in Notion and `.second-brain/4-Archives/` by up to 70%.

### 3. Impeccable (`pbakaus/impeccable`) — Design Craft & Anti-Slop System
Authored by Paul Bakaus, Impeccable provides a rigorous design vocabulary and review harness to eradicate generic "AI slop" (cliché purple gradients, generic cards, and uninspired typography).
- **Artifacts:** Documents visual foundations in `DESIGN.md` and user journey requirements in `PRODUCT.md`.
- **Notion Aesthetic:** Ensures that dashboards, templates, and UI views built by the agent possess clean hierarchy, ergonomic spacing, and high craft quality.
- **Neurodivergent Synergy:** Aligns with `not-today-adhd` by enforcing uncluttered, accessible, and distraction-free visual layouts.

## 🇧🇷 Português

### 1. Headroom (`headroomlabs-ai/headroom`) — Otimizador de Janela de Contexto
O Headroom funciona como proxy local, servidor MCP e biblioteca Python que comprime respostas de ferramentas, logs, leituras de arquivos e chunks de RAG antes que entrem na janela de contexto do LLM.
- **Eficiência de Tokens:** Redução de ~20% em sessões de codificação e 60–95% em payloads JSON repetitivos.
- **Privacidade Local:** Opera dentro do perímetro local da máquina sem enviar dados a terceiros.
- **Papel no Second Brain:** Garante que o resgate de notas do Notion e do repositório local preserve espaço livre (headroom) máximo para raciocínio.

### 2. Caveman (`JuliusBrussee/caveman`) — Dialeto Controlado Estilo Aeroespacial
Criado por Julius Brussee, o Caveman elimina enrolações conversacionais e cortesias desnecessárias ("Com certeza, posso te ajudar com isso..."), preservando a precisão técnica.
- **Voz Ativa & Concisão:** Máximo de 20 palavras por sentença, sem artigos supérfluos.
- **Imunidade de Dados Técnicos:** Blocos de código, comandos bash/powershell, caminhos de arquivos e hashes são mantidos 100% literais.
- **Salvaguarda de Segurança:** Volta automaticamente ao tom normal em avisos críticos de segurança ou comandos destrutivos.
- **Papel na Memória:** Reduz em até 70% o tamanho dos logs de sessão salvos no Notion e nos arquivos locais.

### 3. Impeccable (`pbakaus/impeccable`) — Excelência Visual e Eliminação de AI Slop
Criado por Paul Bakaus, o Impeccable define um padrão rigoroso de design front-end para agentes de IA, banindo padrões preguiçosos como gradientes roxos genéricos e caixas dentro de caixas.
- **Artefatos Estruturais:** Formaliza as diretrizes estéticas em `DESIGN.md` e os requisitos de produto em `PRODUCT.md`.
- **Estética no Notion:** Assegura que os dashboards, tabelas e visões do Notion sejam profissionais, limpos e sem poluição visual.
- **Sinergia com Modo TDAH:** Harmoniza perfeitamente com a skill `not-today-adhd` ao exigir interfaces de baixa carga cognitiva e alta clareza.
