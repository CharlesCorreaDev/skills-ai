## 🇺🇸 English

### 1. Why Integrate Karpathy Guidelines?
Andrej Karpathy identified the four most prevalent LLM failure modes:
1. **Blind Assumptions:** Hallucinating answers silently rather than asking for clarification.
2. **Overengineering:** Spawning excessive abstractions when a 40-line script is sufficient.
3. **Uncontrolled Edits:** Mutating adjacent code and unrequested files.
4. **Lack of Verifiable Success:** Claiming a task is complete without running empirical tests.

### 2. The 4 Laws in Second Brain Plus
- **1. Think Before Coding:** Always verify existing project decisions in the Second Brain vault before proposing changes.
- **2. Simplicity First:** Store concise, high-density documentation in Notion and Markdown. Avoid bureaucratic fluff.
- **3. Surgical Changes:** Every edited file must map directly to a project task (PRJ) or decision (ADR).
- **4. Goal-Driven Execution:** Milestones in Notion are only marked complete after verified empirical testing.

## 🇧🇷 Português

### 1. Por que integrar as Karpathy Guidelines?
Andrej Karpathy catalogou os 4 erros mais frequentes de LLMs ao programar:
1. **Suposições Cegas:** Adivinhar silenciosamente em vez de explicitar incertezas.
2. **Supercomplexidade:** Criar 200 linhas de classes abstratas onde 40 linhas simples bastariam.
3. **Modificações Descontroladas:** Mexer em arquivos e estilos que não foram solicitados.
4. **Falta de Critério Verificável:** Afirmar que terminou sem demonstrar testes executados.

### 2. As 4 Leis no Second Brain Plus
- **1. Pense Antes de Codificar:** Consulte o Second Brain antes de agir. Se houver dúvida, pergunte.
- **2. Simplicidade Primeiro:** Mantenha notas e códigos minimalistas, objetivos e densos.
- **3. Mudanças Cirúrgicas:** Cada linha alterada deve ter rastreabilidade direta para uma nota de projeto ou ADR.
- **4. Execução Orientada a Metas:** Os checkboxes no Notion só são marcados como concluídos após testes comprovados.
