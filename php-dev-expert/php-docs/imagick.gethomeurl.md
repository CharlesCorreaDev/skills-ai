# Imagick::getHomeURL

(PECL imagick 2, PECL imagick 3)

Imagick::getHomeURL — Retorna o URL da página do ImageMagick

### Descrição

public static function **Imagick::getHomeURL**(): [string](language.types.string.md)

Retorna o URL da página do ImageMagick

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um atalho para a página do ImageMagick
