# Imagick::getPackageName

(PECL imagick 2, PECL imagick 3)

Imagick::getPackageName — Retorna o nome do pacote ImageMagick

### Descrição

public static function **Imagick::getPackageName**(): [string](language.types.string.md)

Retorna o nome do pacote ImageMagick.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o nome do pacote ImageMagick como uma string.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
