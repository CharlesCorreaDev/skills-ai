# ReflectionMethod::isFinal

(PHP 5, PHP 7, PHP 8)

ReflectionMethod::isFinal — Verifica se o método é final

### Descrição

public function **ReflectionMethod::isFinal**(): [bool](language.types.boolean.md)

Verifica se o método é final.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se o método é final, caso contrário **`false`**
