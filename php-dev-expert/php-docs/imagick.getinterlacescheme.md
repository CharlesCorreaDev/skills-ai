# Imagick::getInterlaceScheme

(PECL imagick 2, PECL imagick 3)

Imagick::getInterlaceScheme — Obtém o esquema de entrelaçamento do objeto

### Descrição

public function **Imagick::getInterlaceScheme**(): [int](language.types.integer.md)

Obtém o esquema de entrelaçamento do objeto.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Obtém o [esquema de
entrelaçamento](imagick.constants.md#imagick.constants.interlace) da varinha.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
