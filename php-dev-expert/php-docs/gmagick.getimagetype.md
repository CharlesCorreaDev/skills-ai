# Gmagick::getimagetype

(PECL gmagick >= Unknown)

Gmagick::getimagetype — Obtém o tipo de imagem potencial

### Descrição

public function **Gmagick::getimagetype**(): [int](language.types.integer.md)

Obtém o tipo de imagem potencial.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o tipo de imagem potencial.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
