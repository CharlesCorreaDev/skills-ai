## Tipos de Recurso

A maioria das funções fdf requer um recurso `fdf`
como seu primeiro parâmetro. Um recurso `fdf`
é um identificador para um arquivo fdf aberto. Recursos `fdf`
podem ser obtidos usando [fdf\_create()](function.fdf-create.md),
[fdf\_open()](function.fdf-open.md) e [fdf\_open\_string()](function.fdf-open-string.md).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
