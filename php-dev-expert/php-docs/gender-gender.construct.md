# Gender\Gender::\_\_construct

(PECL gender >= 0.6.0)

Gender\Gender::\_\_construct — Constrói o objeto Gender

### Descrição

public function **Gender\Gender::\_\_construct**([string](language.types.string.md) `$dsn` = ?)

Cria um objeto Gender opcionalmente conectando-se a um dicionário de nomes
externo. Quando nenhum banco de dados externo for fornecido, os dados compilados serão
usados.

### Parâmetros

`dsn`
:   DSN a ser aberto
