# stats\_rand\_gen\_t

(PECL stats >= 1.0.0)

stats\_rand\_gen\_t — Gera um único desvio aleatório de uma distribuição t

### Descrição

function **stats\_rand\_gen\_t**([float](language.types.float.md) `$df`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição t com os graus de liberdade `df`.

### Parâmetros

`df`
:   Os graus de liberdade

### Valor Retornado

Um desvio aleatório
