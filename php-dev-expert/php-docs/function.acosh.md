# acosh

(PHP 4 >= 4.1.0, PHP 5, PHP 7, PHP 8)

acosh — Arco cosseno hiperbólico

### Descrição

function **acosh**([float](language.types.float.md) `$num`): [float](language.types.float.md)

Retorna o arco cosseno hiperbólico de
`num`, isto é, o valor
cujo cosseno hiperbólico é `num`.

### Parâmetros

`num`
:   O valor a processar

### Valor Retornado

O arco cosseno hiperbólico de `num`
