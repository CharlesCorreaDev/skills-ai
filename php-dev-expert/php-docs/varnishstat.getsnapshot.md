# VarnishStat::getSnapshot

(PECL varnish >= 0.3)

VarnishStat::getSnapshot — Obtém o instantâneo de estatísticas da instância Varnish atual

### Descrição

public function **VarnishStat::getSnapshot**(): [array](language.types.array.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Array com o instantâneo de estatísticas Varnish. As chaves do array são idênticas às
da ferramenta 'varnishstat'.
