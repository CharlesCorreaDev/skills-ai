# rrd\_error

(PECL rrd >= 0.9.0)

rrd\_error — Obtém a última mensagem de erro

### Descrição

function **rrd\_error**(): [string](language.types.string.md)

Retorna a última mensagem de erro global rrd.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Mensagem de erro mais recente.
