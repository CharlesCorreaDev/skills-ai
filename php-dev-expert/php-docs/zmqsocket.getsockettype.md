# ZMQSocket::getSocketType

(PECL zmq >= 0.5.0)

ZMQSocket::getSocketType — Retorna o tipo de socket

### Descrição

public function **ZMQSocket::getSocketType**(): [int](language.types.integer.md)

Retorna o tipo de socket.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um inteiro representando o tipo do socket. O inteiro pode ser comparado com
as constantes **`ZMQ::SOCKET_*`**.
