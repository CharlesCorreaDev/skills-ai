# Gmagick::getimageinterlacescheme

(PECL gmagick >= Unknown)

Gmagick::getimageinterlacescheme — Obtém o esquema de entrelaçamento da imagem

### Descrição

public function **Gmagick::getimageinterlacescheme**(): [int](language.types.integer.md)

Obtém o esquema da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o esquema de entrelaçamento como um número inteiro em caso de sucesso.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
