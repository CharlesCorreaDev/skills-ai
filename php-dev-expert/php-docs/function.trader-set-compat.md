# trader\_set\_compat

(PECL trader >= 0.2.2)

trader\_set\_compat — Define o modo de compatibilidade

### Descrição

function **trader\_set\_compat**([int](language.types.integer.md) `$compatId`): [void](language.types.void.md)

Define o modo de compatibilidade que afetará a maneira como os cálculos são feitos por todas as funções de extensão.

### Parâmetros

`compatId`
:   ID de compatibilidade. A série de constantes [TRADER\_COMPATIBILITY\_\*](trader.constants.md) deve ser usada.

### Valor Retornado

Nenhum valor é retornado.
