# ZMQSocket::isPersistent

(PECL zmq >= 0.5.0)

ZMQSocket::isPersistent — Informa se o soquete é persistente

### Descrição

public function **ZMQSocket::isPersistent**(): [bool](language.types.boolean.md)

Verifica se o soquete é persistente.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um [bool](language.types.boolean.md) informando se o soquete é persistente ou não.
