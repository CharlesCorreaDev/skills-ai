# LuaSandboxFunction::dump

(PECL luasandbox >= 1.0.0)

LuaSandboxFunction::dump — Despeja a função como um blob binário

### Descrição

public function **LuaSandboxFunction::dump**(): [string](language.types.string.md)

Despeja a função como um blob binário.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string que pode ser passada para [LuaSandbox::loadBinary()](luasandbox.loadbinary.md).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
