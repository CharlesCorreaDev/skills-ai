# RecursiveTreeIterator::getPrefix

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::getPrefix — Obtém o prefixo

### Descrição

public function **RecursiveTreeIterator::getPrefix**(): [string](language.types.string.md)

Obtém a string para colocar na frente do elemento atual

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

etorna a string para colocar na frente do elemento atual
