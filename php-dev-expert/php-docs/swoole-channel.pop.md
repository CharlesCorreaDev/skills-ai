# Swoole\Channel::pop

(PECL swoole >= 1.9.0)

Swoole\Channel::pop — Lê e retira dados do canal Swoole.

### Descrição

public function **Swoole\Channel::pop**(): [mixed](language.types.mixed.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Se o canal estiver vazio, a função retornará false, caso contrário, retornará os dados desserializados.
