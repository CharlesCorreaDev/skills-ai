# Memcached::quit

(PECL memcached >= 2.0.0)

Memcached::quit — Fecha todas as conexões abertas

### Descrição

public function **Memcached::quit**(): [bool](language.types.boolean.md)

**Memcached::quit()** fecha qualquer conexão aberta com os
servidores memcache.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso ou **`false`** em caso de falha.
