# stats\_harmonic\_mean

(PECL stats >= 1.0.0)

stats\_harmonic\_mean — Retorna a média harmônica de um array de valores

### Descrição

function **stats\_harmonic\_mean**([array](language.types.array.md) `$a`): number

Retorna a média harmônica dos valores em `a`.

### Parâmetros

`a`
:   O array de entrada

### Valor Retornado

Retorna a média harmônica dos valores em `a`,
ou **`false`** se `a` estiver vazio ou não for um array.
