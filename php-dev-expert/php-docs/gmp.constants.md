# Constantes predefinidas

As constantes abaixo são definidas por esta extensão e
só estarão disponíveis quando a extensão tiver sido compilada no PHP
ou tiver sido carregada dinamicamente em tempo de execução.

**`GMP_ROUND_ZERO`** ([int](language.types.integer.md))

**`GMP_ROUND_PLUSINF`** ([int](language.types.integer.md))

**`GMP_ROUND_MINUSINF`** ([int](language.types.integer.md))

**`GMP_MSW_FIRST`** ([int](language.types.integer.md))

**`GMP_LSW_FIRST`** ([int](language.types.integer.md))

**`GMP_LITTLE_ENDIAN`** ([int](language.types.integer.md))

**`GMP_BIG_ENDIAN`** ([int](language.types.integer.md))

**`GMP_NATIVE_ENDIAN`** ([int](language.types.integer.md))

**`GMP_VERSION`** ([string](language.types.string.md))
:   A versão da biblioteca GMP.

**`GMP_MPIR_VERSION`** ([string](language.types.string.md))
:   A versão da biblioteca MPIR.
