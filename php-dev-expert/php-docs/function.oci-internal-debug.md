# oci\_internal\_debug

(PHP 5, PHP 7, PECL OCI8 >= 1.1.0, PECL OCI8 <= 2.2.0)

oci\_internal\_debug — Habilita ou desabilita a saíde interna de depuração

### Descrição

function **oci\_internal\_debug**([bool](language.types.boolean.md) `$onoff`): [void](language.types.void.md)

Habilita ou desabilita a saíde interna de depuração.

### Parâmetros

`onoff`
:   Defina para **`false`** para desligar a saída de depuração ou **`true`** para ligá-la.

### Valor Retornado

Nenhum valor é retornado.

### Notas

> **Nota**:
>
> Esta função foi removida no PHP 8 e PECL OCI8 3.0.
