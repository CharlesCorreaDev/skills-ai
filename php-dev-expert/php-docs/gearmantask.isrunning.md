# GearmanTask::isRunning

(PECL gearman >= 0.5.0)

GearmanTask::isRunning — Testa se a tarefa está em execução no momento

### Descrição

public function **GearmanTask::isRunning**(): [bool](language.types.boolean.md)

Indica se esta tarefa está ou não em execução.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se a tarefa estiver em execução, **`false`** caso contrário.
