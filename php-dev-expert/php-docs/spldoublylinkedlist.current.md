# SplDoublyLinkedList::current

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplDoublyLinkedList::current — Retorna a entrada de array atual

### Descrição

public function **SplDoublyLinkedList::current**(): [mixed](language.types.mixed.md)

Obtém o nó atual da lista duplamente encadeada.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O valor do nó atual.
