# SplHeap::key

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplHeap::key — Retorna o índice do nó atual

### Descrição

public function **SplHeap::key**(): [int](language.types.integer.md)

Esta função retorna o índice do nó atual

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O índice do nó atual.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
