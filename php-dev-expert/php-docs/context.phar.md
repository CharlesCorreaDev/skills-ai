# Opções de contexto do Phar

Opções de contexto do Phar — Lista de opções de contexto do Phar

### Descrição

Opções de contexto do empacotador `phar://`.

### Opções

`compress` [int](language.types.integer.md)
:   Uma das [constantes de compressão do Phar](phar.constants.md#phar.constants.compression).

`metadata` [mixed](language.types.mixed.md)
:   Metadados do Phar. Consulte o método [Phar::setMetadata()](phar.setmetadata.md).
