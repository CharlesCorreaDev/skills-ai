# Imagick::getImageGamma

(PECL imagick 2, PECL imagick 3)

Imagick::getImageGamma — Obtém o gama da imagem

### Descrição

public function **Imagick::getImageGamma**(): [float](language.types.float.md)

Obtém o gama da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o gama da imagem em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
