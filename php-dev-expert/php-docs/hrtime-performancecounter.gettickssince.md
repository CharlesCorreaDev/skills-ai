# HRTime\PerformanceCounter::getTicksSince

(PECL hrtime >= 0.6.0)

HRTime\PerformanceCounter::getTicksSince — Tiques decorridos desde um valor informado

### Descrição

public static function **HRTime\PerformanceCounter::getTicksSince**([int](language.types.integer.md) `$start`): [int](language.types.integer.md)

Retorna a contagem de tiques decorridos desde o valor de início informado.

### Parâmetros

`start`
:   Valor de início da contagem dos tiques.

### Valor Retornado

Retorna um [int](language.types.integer.md) indicando a contagem de tiques.
