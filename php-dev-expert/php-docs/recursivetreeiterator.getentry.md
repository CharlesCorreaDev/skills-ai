# RecursiveTreeIterator::getEntry

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::getEntry — Obtém entrada atual

### Descrição

public function **RecursiveTreeIterator::getEntry**(): [string](language.types.string.md)

Obtém a parte da árvore construída para o elemento atual.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a parte da árvore construída para o elemento atual.
