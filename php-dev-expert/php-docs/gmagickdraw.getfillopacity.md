# GmagickDraw::getfillopacity

(PECL gmagick >= Unknown)

GmagickDraw::getfillopacity — Retorna a opacidade usada ao desenhar

### Descrição

public function **GmagickDraw::getfillopacity**(): [float](language.types.float.md)

Retorna a opacidade usada ao desenhar

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a opacidade usada ao desenhar usando a cor ou textura de preenchimento. Totalmente opaco é 1.0.
