# stats\_rand\_setall

(PECL stats >= 1.0.0)

stats\_rand\_setall — Define valores de semente para o gerador aleatório

### Descrição

function **stats\_rand\_setall**([int](language.types.integer.md) `$iseed1`, [int](language.types.integer.md) `$iseed2`): [void](language.types.void.md)

Define `iseed1` e `iseed2` como valores iniciais para o gerador aleatório
usado em funções estatísticas.

### Parâmetros

`iseed1`
:   O valor que é usado como semente aleatória

`iseed2`
:   O valor que é usado como semente aleatória

### Valor Retornado

Nenhum valor é retornado.
