# Imagick::setImageInterlaceScheme

(PECL imagick 2, PECL imagick 3)

Imagick::setImageInterlaceScheme — Define a compactação da imagem

### Descrição

public function **Imagick::setImageInterlaceScheme**([int](language.types.integer.md) `$interlace_scheme`): [bool](language.types.boolean.md)

Define a compactação da imagem.

### Parâmetros

`interlace_scheme`

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
