# HRTime\StopWatch::getElapsedTicks

(PECL hrtime >= 0.4.3)

HRTime\StopWatch::getElapsedTicks — Obtém os tiques decorridos para todos os intervalos

### Descrição

public function **HRTime\StopWatch::getElapsedTicks**(): [int](language.types.integer.md)

Obtém os tiques decorridos para todos os intervalos previamente fechados.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um [int](language.types.integer.md) indicando os tiques decorridos.
