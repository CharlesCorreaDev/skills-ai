# RecursiveTreeIterator::key

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::key — Obtém a chave do elemento atual

### Descrição

public function **RecursiveTreeIterator::key**(): [mixed](language.types.mixed.md)

Obtém a chave atual com prefixo e sufixo.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a chave atual com prefixo e sufixo.
