# delete

delete — Consulte [unlink()](function.unlink.md) ou [unset()](function.unset.md)

### Descrição

Não existe função ou instrução "delete" no PHP.
Se você chegou nesta página procurando por deletar arquivos, consulte [unlink()](function.unlink.md).
Para excluir uma variável de um escopo local, consulte [unset()](function.unset.md).

### Veja também

- [unlink()](function.unlink.md) - Apaga um arquivo
- [unset()](function.unset.md) - unset remove a definição de uma variável informada
