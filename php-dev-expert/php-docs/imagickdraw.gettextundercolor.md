# ImagickDraw::getTextUnderColor

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getTextUnderColor — Retorna a cor sob o texto

### Descrição

public function **ImagickDraw::getTextUnderColor**(): [ImagickPixel](class.imagickpixel.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a cor do retângulo de fundo colocado sob as anotações de texto.

### Valor Retornado

Retorna um objeto [ImagickPixel](class.imagickpixel.md) que descreve a cor.
