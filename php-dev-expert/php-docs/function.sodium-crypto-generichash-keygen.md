# sodium\_crypto\_generichash\_keygen

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_generichash\_keygen — Gera uma chave generichash aleatória

### Descrição

function **sodium\_crypto\_generichash\_keygen**(): [string](language.types.string.md)

Gera uma chave aleatória para uso com a API generichash.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Uma chave aleatória de 256 bits.
