# seaslog\_get\_version

(PECL seaslog >=1.0.0)

seaslog\_get\_version — Obtém a versão do SeasLog.

### Descrição

function **seaslog\_get\_version**(): [string](language.types.string.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a versão do SeasLog (SEASLOG\_VERSION) como uma string.

### Examples

**Exemplo #1 Exemplo de **seaslog\_get\_version()****

```
<?php

var_dump(seaslog_get_version());

?>
```

O exemplo acima produzirá
algo semelhante a:

```
string(5) "1.8.4"
```
