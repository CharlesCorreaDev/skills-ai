## Configurações de Execução

O comportamento destas funções é afetado pelas configurações do php.ini.

**Opções de Configuração de GeoIP**

| Nome | Padrão | Modificável | Registro de Alterações |
| --- | --- | --- | --- |
| [geoip.custom\_directory](geoip.configuration.md#ini.geoip.custom-directory) | "" | **`INI_ALL`** |  |

Aqui está uma breve explicação das
diretivas de configuração.

`geoip.custom_directory` [string](language.types.string.md)
:   Vazio por padrão, mas pode ser configurado para forçar um caminho de banco de dados diferente daquele compilado na biblioteca.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
