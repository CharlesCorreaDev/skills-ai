# Phar::getAlias

(PHP 5 >= 5.3.0, PHP 7, PHP 8, PECL phar >= 1.2.1)

Phar::getAlias — Obtém o apelido para o Phar

### Descrição

public function **Phar::getAlias**(): [?](language.types.null.md)[string](language.types.string.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o apelido ou **`null`** se não houver apelido.
