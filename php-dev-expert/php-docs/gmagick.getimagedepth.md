# Gmagick::getimagedepth

(PECL gmagick >= Unknown)

Gmagick::getimagedepth — Obtém a profundidade da imagem

### Descrição

public function **Gmagick::getimagedepth**(): [int](language.types.integer.md)

Obtém a profundidade da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

A profundidade da imagem.

Lança uma exceção
**GmagickException** em caso de erro.
