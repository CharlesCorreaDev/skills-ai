# Yaf\_Controller\_Abstract::getName

(Yaf >=3.2.0)

Yaf\_Controller\_Abstract::getName — Obtém o próprio nome

### Descrição

public function **Yaf\_Controller\_Abstract::getName**(): [string](language.types.string.md)

Obtém o nome deste controlador.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Uma [string](language.types.string.md) contendo o nome do controlador.
