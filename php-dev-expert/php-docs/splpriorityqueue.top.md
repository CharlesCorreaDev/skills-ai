# SplPriorityQueue::top

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplPriorityQueue::top — Observa o nó do topo da fila

### Descrição

public function **SplPriorityQueue::top**(): [mixed](language.types.mixed.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O valor ou prioridade (ou ambos) do nó do topo, dependendo da opção de extração.

`Enter` to select •
