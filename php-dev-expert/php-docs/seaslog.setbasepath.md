# SeasLog::setBasePath

(PECL seaslog >=1.0.0)

SeasLog::setBasePath — Define o caminho base do SeasLog

### Descrição

public static function **SeasLog::setBasePath**([string](language.types.string.md) `$base_path`): [bool](language.types.boolean.md)

Define o caminho base do SeasLog.

### Parâmetros

`base_path`
:   String com o caminho base.

### Valor Retornado

Retorna TRUE em caso de sucesso ao definir o caminho base, ou FALSE em caso de falha.
