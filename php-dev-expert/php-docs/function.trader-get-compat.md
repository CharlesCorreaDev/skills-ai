# trader\_get\_compat

(PECL trader >= 0.2.2)

trader\_get\_compat — Obtém modo de compatibilidade

### Descrição

function **trader\_get\_compat**(): [int](language.types.integer.md)

Obtém o modo de compatibilidade que afeta a maneira como os cálculos são feitos por todas as funções de extensão.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o ID do modo de compatibilidade que pode ser identificado pela série de constantes [TRADER\_COMPATIBILITY\_\*](trader.constants.md).
