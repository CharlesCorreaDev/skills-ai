# Imagick::getImageAttribute

(PECL imagick 2, PECL imagick 3)

Imagick::getImageAttribute — Retorna um atributo nomeado

**Aviso**

Esta função foi *DESCONTINUADA* a partir da Imagick 3.4.4. O uso desta função é fortemente desencorajado.

### Descrição

public function **Imagick::getImageAttribute**([string](language.types.string.md) `$key`): [string](language.types.string.md)

Retorna um atributo nomeado.

### Parâmetros

`key`
:   A chave do atributo a ser obtido.
