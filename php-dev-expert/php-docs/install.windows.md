mas o PHP também pode ser [compilado a partir do código-fonte](install.windows.building.md).

O PHP também pode ser [instalado no Azure App Services](install.cloud.azure.md)
(também conhecido como Microsoft Azure, Windows Azure, ou (Windows) Azure Web Apps).
