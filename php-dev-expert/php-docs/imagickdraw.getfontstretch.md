# ImagickDraw::getFontStretch

(PECL imagick 2 >=2.3.0, PECL imagick 3)

ImagickDraw::getFontStretch — Obtém o esticamento de fonte a ser usado ao fazer anotações com texto

### Descrição

public function **ImagickDraw::getFontStretch**(): [int](language.types.integer.md)

Obtém o esticamento de fonte a ser usado ao fazer anotações com texto. Retorna um StretchType.

### Parâmetros

Esta função não possui parâmetros.
