(mongodb >=1.0.0)

Interface base abstrata que não deve ser implementada diretamente.

## Resumo da Interface

class **MongoDB\BSON\Type**
{

}

Esta interface não tem métodos. Seu único propósito é ser a interface base
para todas as classes do tipo BSON.
