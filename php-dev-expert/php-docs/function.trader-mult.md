# trader\_mult

(PECL trader >= 0.2.0)

trader\_mult — Multiplicação Aritmética Vetorial

### Descrição

function **trader\_mult**([array](language.types.array.md) `$real0`, [array](language.types.array.md) `$real1`): [array](language.types.array.md)

Calcula o produto escalar de `real0` com
`real1` e retorna o vetor resultante.

### Parâmetros

`real0`
:   Array de valores reais.

`real1`
:   Array de valores reais.

### Valor Retornado

Retorna um array com os dados calculados ou false em caso de falha.
