# VarnishAdmin::isRunning

(PECL varnish >= 0.3)

### Descrição

public function **VarnishAdmin::isRunning**(): [bool](language.types.boolean.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso ou **`false`** em caso de falha.
