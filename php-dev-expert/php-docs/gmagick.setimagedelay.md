# Gmagick::setimagedelay

(PECL gmagick >= Unknown)

Gmagick::setimagedelay — Define o atraso da imagem

### Descrição

public function **Gmagick::setimagedelay**([int](language.types.integer.md) `$delay`): [Gmagick](class.gmagick.md)

Define o atraso da imagem.

### Parâmetros

`delay`
:   O atraso da imagem em 1/100 de segundo.

### Valor Retornado

O objeto [Gmagick](class.gmagick.md).

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
