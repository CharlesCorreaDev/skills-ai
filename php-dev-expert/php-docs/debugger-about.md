## Sobre o depurador em PHP

O PHP vem equipado com um depurador básico em linha de comando,
[phpdbg](migration56.new-features.md#migration56.new-features.phpdbg).

A maioria dos IDEs tem suporte para o [» Xdebug](https://xdebug.org/),
uma ferramenta gratuita para depuração que permite analisar as aplicações PHP
passo a passo.

`Enter` to select •
`Esc` to close • `/` to open
