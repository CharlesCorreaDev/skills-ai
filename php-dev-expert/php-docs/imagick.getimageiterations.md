# Imagick::getImageIterations

(PECL imagick 2, PECL imagick 3)

Imagick::getImageIterations — Obtém as iterações da imagem

### Descrição

public function **Imagick::getImageIterations**(): [int](language.types.integer.md)

Obtém as iterações da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna as iterações da imagem como um número inteiro.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
