# stats\_rand\_gen\_chisquare

(PECL stats >= 1.0.0)

stats\_rand\_gen\_chisquare — Gera um desvio aleatório da distribuição qui-quadrado

### Descrição

function **stats\_rand\_gen\_chisquare**([float](language.types.float.md) `$df`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição qui-quadrado onde os graus de
liberdade são `df`.

### Parâmetros

`df`
:   Os graus de liberdade

### Valor Retornado

Um desvio aleatório
