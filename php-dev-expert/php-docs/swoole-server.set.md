# Swoole\Server::set

(PECL swoole >= 1.9.0)

Swoole\Server::set — Define as configurações em tempo de execução do servidor Swoole.

### Descrição

public function **Swoole\Server::set**([array](language.types.array.md) `$settings`): ReturnType

Define as configurações em tempo de execução do servidor Swoole. As configurações podem ser acessadas por $server->setting após o servidor Swoole ter sido iniciado.

### Parâmetros

`settings`
