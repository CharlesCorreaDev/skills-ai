# lzf\_optimized\_for

(PECL lzf >= 1.0.0)

lzf\_optimized\_for — 
Determina para quê a extensão LZF foi otimizada

### Descrição

function **lzf\_optimized\_for**(): [int](language.types.integer.md)

Determina para quê a extensão LZF foi otimizada durante a compilação.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna 1 se LZF foi otimizada para velocidade, 0 para compressão.
