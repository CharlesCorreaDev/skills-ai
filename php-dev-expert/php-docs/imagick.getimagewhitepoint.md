# Imagick::getImageWhitePoint

(PECL imagick 2, PECL imagick 3)

Imagick::getImageWhitePoint — Retorna o ponto branco da cromaticidade

### Descrição

public function **Imagick::getImageWhitePoint**(): [array](language.types.array.md)

Retorna o ponto branco da cromaticidade como um array associativo com as chaves "x" e "y".

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o ponto branco da cromaticidade como um array associativo com as chaves
"x" e "y".

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
