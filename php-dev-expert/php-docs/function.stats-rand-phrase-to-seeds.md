# stats\_rand\_phrase\_to\_seeds

(PECL stats >= 1.0.0)

stats\_rand\_phrase\_to\_seeds — Gera duas sementes para o gerador de números aleatórios RGN

### Descrição

function **stats\_rand\_phrase\_to\_seeds**([string](language.types.string.md) `$phrase`): [array](language.types.array.md)

Gera duas sementes para o gerador de números aleatórios a partir de uma frase no parâmetro `phrase`.

### Parâmetros

`phrase`
:   A frase de entrada

### Valor Retornado

Retorna um array de dois inteiros.
