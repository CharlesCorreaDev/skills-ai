# Imagick::getImageTicksPerSecond

(PECL imagick 2, PECL imagick 3)

Imagick::getImageTicksPerSecond — Obtém os tiques por segundo da imagem

### Descrição

public function **Imagick::getImageTicksPerSecond**(): [int](language.types.integer.md)

Obtém os tiques por segundo da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna os tiques por segundo da imagem.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
