# Verificação de Certificado

Ao chamar uma função que verificará uma assinatura/certificado,
o parâmetro `ca_info` é um array contendo nomes de
arquivo e diretório que especificam os locais de arquivos CA confiáveis. Se um
diretório for especificado, ele deve ser um diretório com hash corretamente formado,
como o comando **openssl** usaria.
