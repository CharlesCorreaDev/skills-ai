# ImagickDraw::getFillOpacity

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getFillOpacity — Retorna a opacidade usada ao desenhar

### Descrição

public function **ImagickDraw::getFillOpacity**(): [float](language.types.float.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a opacidade usada ao desenhar usando a cor ou textura de
preenchimento. Totalmente opaco é 1.0.

### Valor Retornado

A opacidade.
