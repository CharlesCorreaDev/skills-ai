# sodium\_crypto\_stream\_xchacha20\_keygen

(PHP 8 >= 8.1.0)

sodium\_crypto\_stream\_xchacha20\_keygen — Retorna uma chave segura aleatória

### Descrição

function **sodium\_crypto\_stream\_xchacha20\_keygen**(): [string](language.types.string.md)

Retorna uma chave segura aleatória para uso com [sodium\_crypto\_stream\_xchacha20()](function.sodium-crypto-stream-xchacha20.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma chave 32-byte segura aleatória para uso com [sodium\_crypto\_stream\_xchacha20()](function.sodium-crypto-stream-xchacha20.md).
