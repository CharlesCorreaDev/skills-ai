# Imagick::getQuantumDepth

(PECL imagick 2, PECL imagick 3)

Imagick::getQuantumDepth — Obtém a profundidade Quantum

### Descrição

public static function **Imagick::getQuantumDepth**(): [array](language.types.array.md)

Retorna a profundidade Quantum do Imagick.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um array com membros `"quantumDepthLong"` e
`"quantumDepthString"`.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
