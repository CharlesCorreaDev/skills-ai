# Gmagick::getimageheight

(PECL gmagick >= Unknown)

Gmagick::getimageheight — Retorna a altura da imagem

### Descrição

public function **Gmagick::getimageheight**(): [int](language.types.integer.md)

Retorna a altura da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a altura da imagem em pixels.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
