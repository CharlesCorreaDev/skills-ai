# Opções de contexto Zlib

Opções de contexto Zlib — Lista de opções de contexto de Zlib

### Descrição

Opções de contexto Zlib estão disponíveis para empacotadores `zlib`.

### Opções

`level`
:   Usado para especificar o nível de compressão (`0` - `9`).

### Registro de Alterações

| Versão | Descrição |
| --- | --- |
| 7.3.0 | O parâmetro `level` foi incluído. |
