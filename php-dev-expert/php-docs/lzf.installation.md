## Instalação

Esta extensão [» PECL](https://pecl.php.net/) não é distribuída com o PHP.
Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/lzf](https://pecl.php.net/package/lzf).

Para usar estas funções você precisa compilar PHP com suporte a lzf
usando a opção de configuração **--with-lzf[=DIR]**.
Você pode também passar
**--enable-lzf-better-compression** para
otimizar o LZF mais para espaço do que para velocidade.

Usuários Windows podem habilitar a php\_lzf.dll no
php.ini para usar estas funções.
