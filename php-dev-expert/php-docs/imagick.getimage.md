# Imagick::getImage

(PECL imagick 2, PECL imagick 3)

Imagick::getImage — Retorna um novo objeto Imagick

### Descrição

public function **Imagick::getImage**(): [Imagick](class.imagick.md)

Retorna um novo objeto Imagick com a sequência de imagem atual.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um novo objeto Imagick com a sequência de imagem atual.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
