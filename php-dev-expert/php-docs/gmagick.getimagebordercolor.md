# Gmagick::getimagebordercolor

(PECL gmagick >= Unknown)

Gmagick::getimagebordercolor — Retorna a cor da borda da imagem

### Descrição

public function **Gmagick::getimagebordercolor**(): [GmagickPixel](class.gmagickpixel.md)

Retorna a cor da borda da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Objeto [GmagickPixel](class.gmagickpixel.md) que representa a cor da borda.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
