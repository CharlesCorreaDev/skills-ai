# ImagickDraw::comment

(PECL imagick 2, PECL imagick 3)

ImagickDraw::comment — Adiciona um comentário

### Descrição

public function **ImagickDraw::comment**([string](language.types.string.md) `$comment`): [bool](language.types.boolean.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Adiciona um comentário a um fluxo de saída de vetor.

### Parâmetros

`comment`
:   A string de comentário a ser adicionada ao fluxo de saída do vetor.

### Valor Retornado

Nenhum valor é retornado.
