## Instalação

Para ativar o suporte ao PostgreSQL,
**--with-pgsql[=DIR]** é necessário ao compilar o
PHP. `DIR` é o diretório base de instalação do PostgreSQL, o padrão é
/usr/local/pgsql. Se o módulo de objeto compartilhado estiver
disponível, o módulo PostgreSQL poderá ser carregado usando a
diretiva [extension](ini.core.md#ini.extension) no php.ini
ou função
[dl()](function.dl.md).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
