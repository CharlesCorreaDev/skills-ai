# Gmagick::getimageredprimary

(PECL gmagick >= Unknown)

Gmagick::getimageredprimary — Retorna o ponto primário vermelho da cromaticidade

### Descrição

public function **Gmagick::getimageredprimary**(): [array](language.types.array.md)

Retorna o ponto primário vermelho de cromaticidade como um array com as chaves "x" e "y".

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o ponto primário vermelho de cromaticidade como um array com as chaves "x" e "y".

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
