## Instalação

Para habilitar suporte a exif configure o PHP com
**--enable-exif**

Usuários Windows precisam habilitar as DLLs php\_mbstring.dll
e php\_exif.dll no php.ini. A DLL
php\_mbstring.dll precisa ser carregada
*antes* da php\_exif.dll então
ajuste seu php.ini corretamente.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
