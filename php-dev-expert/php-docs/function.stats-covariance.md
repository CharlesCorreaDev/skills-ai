# stats\_covariance

(PECL stats >= 1.0.0)

stats\_covariance — Calcula a covariância de dois conjuntos de dados

### Descrição

function **stats\_covariance**([array](language.types.array.md) `$a`, [array](language.types.array.md) `$b`): [float](language.types.float.md)

Retorna a covariância de `a` e `b`.

### Parâmetros

`a`
:   O primeiro array

`b`
:   O segundo array

### Valor Retornado

Retorna a covariância de `a` e `b`,
ou **`false`** em caso de falha.
