# Gmagick::getimagegamma

(PECL gmagick >= Unknown)

Gmagick::getimagegamma — Obtém o gama da imagem

### Descrição

public function **Gmagick::getimagegamma**(): [float](language.types.float.md)

Obtém o gama da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o gama da imagem em caso de sucesso

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
