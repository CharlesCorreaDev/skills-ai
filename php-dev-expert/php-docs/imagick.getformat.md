# Imagick::getFormat

(PECL imagick 2, PECL imagick 3)

Imagick::getFormat — Retorna o formato do objeto Imagick

### Descrição

public function **Imagick::getFormat**(): [string](language.types.string.md)

Retorna o formato do objeto Imagick.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o formato da imagem.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
