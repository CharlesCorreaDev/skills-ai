## DigitalOcean

DigitalOcean oferece as seguintes plataformas para instalação do PHP,
e para executar aplicações web em sua infraestrutura de hospedagem em nuvem.

- [» Cloudways](https://www.cloudways.com/en/managed-hosting-for-digital-ocean.php):
  Implantação em um clique das principais aplicações PHP:
  WordPress, Magento, Drupal, Laravel, e mais.
- [» Droplet](https://www.digitalocean.com/products/droplets):
  Máquinas virtuais e instalação do
  [» 
  Lamp em um servidor Linux](https://www.digitalocean.com/community/tutorials/how-to-install-linux-apache-mysql-php-lamp-stack-on-ubuntu-16-04).
- [» Plataforma de Aplicações](https://www.digitalocean.com/products/app-platform):
  Infraestrutura gerenciada para construir, implantar e escalar aplicações rapidamente.
  Aprenda
  [» 
  como executar aplicações PHP na Plataforma de Aplicações](https://docs.digitalocean.com/products/app-platform/getting-started/sample-apps/php/).
- [» Funções](https://www.digitalocean.com/products/functions):
  Plataforma sem servidor que permite aos desenvolvedores executar código sem provisionar ou manter servidores.
  O PHP é suportado de forma nativa.
  Aprenda
  [» 
  como criar funções sem servidores no PHP](https://docs.digitalocean.com/products/functions/reference/runtimes/php/).
