# Gerenciador de processos FastCGI

# Introdução

FPM (FastCGI Process Manager) é
uma implementação PHP primária do FastCGI contendo alguns recursos úteis (principalmente) para sites pesados.

Este SAPI vem junto com o PHP.

- [Instalação/Configuração](fpm.setup.md)
- [Observabilidade](fpm.observability.md)
  - [Página de status](fpm.status.md)
- [Funções de FPM](ref.fpm.md)
  - [fastcgi\_finish\_request](function.fastcgi-finish-request.md) — Envia todos os dados de resposta ao cliente
  - [fpm\_get\_status](function.fpm-get-status.md) — Retorna o status do pool FPM atual
