## Dependências

Você não precisará de nada se o sistema que estiver usando for um dos
sistemas compatíveis com POSIX recentes porque as bibliotecas C padrão
fornecidas neles devem fornecer o recurso iconv. Caso contrário, você deve ter a biblioteca
[» libiconv](https://www.gnu.org/software/libiconv/) instalada em
seu sistema.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
