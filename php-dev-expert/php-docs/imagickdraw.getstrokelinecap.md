# ImagickDraw::getStrokeLineCap

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getStrokeLineCap — Retorna a forma a ser usada no final dos subcaminhos abertos quando eles são traçados

### Descrição

public function **ImagickDraw::getStrokeLineCap**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a forma a ser usada no final dos subcaminhos abertos quando eles são
traçados.

### Valor Retornado

Retorna uma constante [LINECAP](imagick.constants.md#imagick.constants.linecap)
(`imagick::LINECAP_*`) ou 0 se a forma não estiver definida.
