## Sinalizadores globais Phar em mapa de bits

Aqui estão os sinalizadores de mapa de bits atualmente reconhecidos pela extensão Phar
para o mapa de bits global Phar:

**Valores de mapa de bits reconhecidos**

| Valor | Descrição |
| --- | --- |
| `0x00010000` | Se definido, este Phar contém uma assinatura de verificação |
| `0x00001000` | Se definido, este Phar contém pelo menos 1 arquivo compactado com DEFLATE do zlib |
| `0x00002000` | Se definido, este Phar contém pelo menos 1 arquivo compactado com bzip2 |
