## Instalação

Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/operator](https://pecl.php.net/package/operator).

Usuários do Windows podem baixar binários pré-compilados do site do [» PECL](https://pecl.php.net/package/operator).

As versões da extesão operator são hospedadas pelo PECL e o código-fonte pelo
[» github](https://github.com/jb-lopez/pecl-php-operator).
