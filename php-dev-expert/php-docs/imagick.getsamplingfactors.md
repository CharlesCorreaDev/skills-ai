# Imagick::getSamplingFactors

(PECL imagick 2, PECL imagick 3)

Imagick::getSamplingFactors — Obtém o fator de amostragem horizontal e vertical

### Descrição

public function **Imagick::getSamplingFactors**(): [array](language.types.array.md)

Obtém o fator de amostragem horizontal e vertical.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um array associativo com os fatores de amostragem horizontal
e vertical da imagem.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
