# SplPriorityQueue::valid

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplPriorityQueue::valid — Verifica se a fila contém mais nós

### Descrição

public function **SplPriorityQueue::valid**(): [bool](language.types.boolean.md)

Verifica se a fila contém mais nós.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se a fila contém mais nós, **`false`** caso contrário.
