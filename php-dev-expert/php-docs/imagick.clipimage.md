# Imagick::clipImage

(PECL imagick 2, PECL imagick 3)

Imagick::clipImage — Recorta ao longo do primeiro caminho do perfil 8BIM

### Descrição

public function **Imagick::clipImage**(): [bool](language.types.boolean.md)

Recorta ao longo do primeiro caminho do perfil 8BIM, se estiver presente.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
