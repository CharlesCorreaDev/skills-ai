## Instalação

Esta extensão [» PECL](https://pecl.php.net/) não é distribuída com o PHP.
Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/memcache](https://pecl.php.net/package/memcache).

> **Nota**:
>
> É possível desabilitar o suporte ao manipulador de sessões do memcache. A opção 'pecl install'
> solicita isso (o padrão é ativado); no entanto, ao compilar estaticamente no PHP, a opção de
> configuração **--disable-memcache-session** pode ser
> utilizada.
