## Instalação

Rar está atualmente disponível através do PECL
[» https://pecl.php.net/package/rar](https://pecl.php.net/package/rar).

Além disso, você pode usar o instalador PECL para instalar a extensão Rar,
usando o seguinte comando: **pecl -v install rar**.

Você sempre pode baixar o pacote tar.gz e instalar o Rar manualmente:

**Exemplo #1 Instalação Rar**

```
gunzip rar-xxx.tgz
tar -xvf rar-xxx.tar
cd rar-xxx
phpize
./configure && make && make install
```

Os usuários do Windows ativarão o php\_rar.dll dentro
do php.ini para usar essas funções.
