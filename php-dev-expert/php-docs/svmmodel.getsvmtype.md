# SVMModel::getSvmType

(PECL svm >= 0.1.5)

SVMModel::getSvmType — Obtém o tipo de SVM com o qual o modelo foi treinado

### Descrição

public function **SVMModel::getSvmType**(): [int](language.types.integer.md)

Retorna um valor inteiro que representa o tipo do modelo SVM usado, por exemplo, SVM::C\_SVC.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um valor inteiro do tipo do modelo SVM.
