# rrd\_version

(PECL rrd >= 1.0.0)

rrd\_version — Obtém informações sobre a biblioteca rrdtool subjacente

### Descrição

function **rrd\_version**(): [string](language.types.string.md)

Retorna informações sobre a biblioteca rrdtool subjacente.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

String com o número da versão do rrdtool, por exemplo "1.4.3".
