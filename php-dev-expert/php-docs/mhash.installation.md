## Instalação

É necessário compilar o PHP com o parâmetro
**--with-mhash[=DIR]** para habilitar
esta extensão. DIR é o diretório de instalação da mhash.

A partir do PHP 5.3.0, a extensão mhash extension é emulada através da
extensão [Hash](ref.hash.md). Isto faz com que
o diretório de instalação da mhash não tenha efeito, e requer
a extensão hash habilitada para que o suporte a mhash esteja disponível.
