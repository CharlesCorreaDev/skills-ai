# Swoole\Channel::stats

(PECL swoole >= 1.9.0)

Swoole\Channel::stats — Obtém estatísticas do canal Swoole.

### Descrição

public function **Swoole\Channel::stats**(): [array](language.types.array.md)

Obtenha o número de elementos na fila e o tamanho total da memória usada pela fila.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

As estatísticas do canal Swoole.
