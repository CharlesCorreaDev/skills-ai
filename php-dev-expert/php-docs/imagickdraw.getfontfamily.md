# ImagickDraw::getFontFamily

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getFontFamily — Retorna a família de fontes

### Descrição

public function **ImagickDraw::getFontFamily**(): [string](language.types.string.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a família de fontes a ser usada ao fazer anotações com texto.

### Valor Retornado

Retorna a família de fontes atualmente selecionada ou falso se a família de fontes não estiver definida.
