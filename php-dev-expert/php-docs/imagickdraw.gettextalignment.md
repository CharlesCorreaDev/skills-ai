# ImagickDraw::getTextAlignment

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getTextAlignment — Retorna o alinhamento do texto

### Descrição

public function **ImagickDraw::getTextAlignment**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna o alinhamento aplicado ao fazer anotações com texto.

### Valor Retornado

Retorna uma constante [ALIGN](imagick.constants.md#imagick.constants.align)
(`imagick::ALIGN_*`) ou 0 se nenhum alinhamento estiver definido.
