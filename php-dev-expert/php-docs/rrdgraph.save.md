# RRDGraph::save

(PECL rrd >= 0.9.0)

RRDGraph::save — Salva o resultado da consulta na imagem

### Descrição

public function **RRDGraph::save**(): [array](language.types.array.md)

Salva o resultado da consulta ao banco de dados RRD na imagem definida por
[RRDGraph::\_\_construct()](rrdgraph.construct.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um array com informações sobre a imagem gerada, ou **`false`** em caso de falha.
