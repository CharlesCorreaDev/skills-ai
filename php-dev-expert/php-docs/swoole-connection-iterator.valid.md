# Swoole\Connection\Iterator::valid

(PECL swoole >= 1.9.0)

Swoole\Connection\Iterator::valid — Verifica se a posição atual é válida.

### Descrição

public function **Swoole\Connection\Iterator::valid**(): [bool](language.types.boolean.md)

Verifica se a posição atual é válida.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna TRUE se a posição atual do iterador for válida, caso contrário, FALSE.
