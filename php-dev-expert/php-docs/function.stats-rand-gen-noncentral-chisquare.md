# stats\_rand\_gen\_noncentral\_chisquare

(PECL stats >= 1.0.0)

stats\_rand\_gen\_noncentral\_chisquare — Gera um desvio aleatório da distribuição qui-quadrado não centralizada

### Descrição

function **stats\_rand\_gen\_noncentral\_chisquare**([float](language.types.float.md) `$df`, [float](language.types.float.md) `$xnonc`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição qui-quadrado não centralizada com graus de liberdade
`df`, e parâmetro não central `xnonc`.

### Parâmetros

`df`
:   Os graus de liberdade

`xnonc`
:   O parâmetro de não centralidade

### Valor Retornado

Um desvio aleatório
