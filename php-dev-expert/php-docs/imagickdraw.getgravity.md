# ImagickDraw::getGravity

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getGravity — Retorna o alinhamento de posicionamento do texto

### Descrição

public function **ImagickDraw::getGravity**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna o alinhento de posicionamento usado ao fazer anotações com texto.

### Valor Retornado

Retorna uma constante [GRAVITY](imagick.constants.md#imagick.constants.gravity)
(`imagick::GRAVITY_*`) em caso de sucesso ou 0 se nenhum alinhamento estiver definido.
