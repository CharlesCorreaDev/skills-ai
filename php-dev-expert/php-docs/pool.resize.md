# Pool::resize

(PECL pthreads >= 2.0.0)

Pool::resize — Redimensiona o Pool

### Descrição

public function **Pool::resize**([int](language.types.integer.md) `$size`): [void](language.types.void.md)

Redimensiona o Pool.

### Parâmetros

`size`
:   O número máximo de trabalhadores que este pool pode criar.

### Valor Retornado

Nenhum valor é retornado.
