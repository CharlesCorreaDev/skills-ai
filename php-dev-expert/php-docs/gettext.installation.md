## Instalação

Para incluir o suporte ao 'gettext' GNU na instalação PHP, deve ser adicionada
a opção **--with-gettext[=DIR]** onde DIR é o diretório
de instalação do 'gettext', o padrão é /usr/local.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
