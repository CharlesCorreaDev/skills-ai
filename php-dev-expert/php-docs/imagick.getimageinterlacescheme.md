# Imagick::getImageInterlaceScheme

(PECL imagick 2, PECL imagick 3)

Imagick::getImageInterlaceScheme — Obtém o esquema de entrelaçamento da imagem

### Descrição

public function **Imagick::getImageInterlaceScheme**(): [int](language.types.integer.md)

Obtém o esquema de entrelaçamento da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o esquema de entrelaçamento como um número inteiro em caso de sucesso.
Lança uma exceção
[ImagickException](class.imagickexception.md) em caso de erro.
