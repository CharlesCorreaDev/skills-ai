# SQLite3::lastErrorCode

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SQLite3::lastErrorCode — 
Retorna o código de resultado numérico da última solicitação SQLite que falhou

### Descrição

public function **SQLite3::lastErrorCode**(): [int](language.types.integer.md)

Retorna o código de resultado numérico da última solicitação SQLite que falhou.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um valor inteiro representando o código de resultado numérico da solicitação
SQLite mais recente que falhou.
