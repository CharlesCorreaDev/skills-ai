# Tipos de chave

> **Fonte / Source:** https://www.php.net/manual/pt_BR/openssl.key-types.php

---

## Tipos de chave

**`OPENSSL_KEYTYPE_RSA`** ([int](language.types.integer.md))
:   Tipo de chave RSA.

**`OPENSSL_KEYTYPE_DSA`** ([int](language.types.integer.md))
:   Tipo de chave DSA.

**`OPENSSL_KEYTYPE_DH`** ([int](language.types.integer.md))
:   Tipo de chave DH (Diffie-Hellman).

**`OPENSSL_KEYTYPE_EC`** ([int](language.types.integer.md))
:   Tipo de chave curva elíptica.

**`OPENSSL_KEYTYPE_X25519`** ([int](language.types.integer.md))
:   Tipo de chave curva X25519.
    Esta constante só está disponível quando o PHP for compilado com o OpenSSL 3.0+.

**`OPENSSL_KEYTYPE_ED25519`** ([int](language.types.integer.md))
:   Tipo de chave curva Ed25519.
    Esta constante só está disponível quando o PHP for compilado com o OpenSSL 3.0+.

**`OPENSSL_KEYTYPE_X448`** ([int](language.types.integer.md))
:   Tipo de chave curva X448.
    Esta constante só está disponível quando o PHP for compilado com o OpenSSL 3.0+.

**`OPENSSL_KEYTYPE_ED448`** ([int](language.types.integer.md))
:   Tipo de chave curva Ed448.
    Esta constante só está disponível quando o PHP for compilado com o OpenSSL 3.0+.
