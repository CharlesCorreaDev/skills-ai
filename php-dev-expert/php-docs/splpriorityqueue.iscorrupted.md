# SplPriorityQueue::isCorrupted

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplPriorityQueue::isCorrupted — Indica se a fila de prioridade está em um estado corrompido

### Descrição

public function **SplPriorityQueue::isCorrupted**(): [bool](language.types.boolean.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se a fila de prioridade estiver corrompida, **`false`** caso contrário.
