# Gmagick::getimageiterations

(PECL gmagick >= Unknown)

Gmagick::getimageiterations — Obtém as iterações da imagem

### Descrição

public function **Gmagick::getimageiterations**(): [int](language.types.integer.md)

Obtém as iterações da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna as iterações da imagem como um número inteiro.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
