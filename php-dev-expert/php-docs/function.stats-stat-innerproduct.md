# stats\_stat\_innerproduct

(PECL stats >= 1.0.0)

stats\_stat\_innerproduct — Retorna o produto interno de dois vetores

### Descrição

function **stats\_stat\_innerproduct**([array](language.types.array.md) `$arr1`, [array](language.types.array.md) `$arr2`): [float](language.types.float.md)

Retorna o produto interno de `arr1` e `arr2`.

### Parâmetros

`arr1`
:   O primeiro array

`arr2`
:   O segundo array

### Valor Retornado

Retorna o produto interno de `arr1` e `arr2`,
ou **`false`** em caso de falha.
