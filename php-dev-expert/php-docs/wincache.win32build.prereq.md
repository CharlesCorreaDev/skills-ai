## Pré-requisitos

A construção da extensão WinCache exigirá:

1. Código-fonte do PHP
2. Ambiente de compilação/construção PHP
3. Código-fonte do WinCache

Para concluir os dois primeiros passos, siga o guia passo a passo sobre como
[» compilar o PHP no Windows](https://wiki.php.net/internals/windows/stepbystepbuild).

Para obter o código-fonte do WinCache, siga as instruções descritas em
[Baixando extensões PECL](install.pecl.downloads.md).
