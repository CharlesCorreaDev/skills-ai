# Imagick::setFilename

(PECL imagick 2, PECL imagick 3)

Imagick::setFilename — Define o nome do arquivo antes de ler ou gravar a imagem

### Descrição

public function **Imagick::setFilename**([string](language.types.string.md) `$filename`): [bool](language.types.boolean.md)

Define o nome do arquivo antes de ler ou gravar um arquivo de imagem.

### Parâmetros

`filename`

### Valor Retornado

Retorna **`true`** em caso de sucesso.
