## Configurações INI

**Opções de configuração da CLI SAPI**

| Nome | Padrão | Modificável | Registro de Alterações |
| --- | --- | --- | --- |
| [cli\_server.color](features.commandline.ini.md#ini.cli-server.color) | "0" | **`INI_ALL`** |  |

Aqui está uma breve explicação das
diretivas de configuração.

`cli_server.color` [bool](language.types.boolean.md)
:   Habilita o uso de cores ANSI na saída do terminal pelo
    servidor web.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
