# Gmagick::getimagecolors

(PECL gmagick >= Unknown)

Gmagick::getimagecolors — Retorna a cor do índice do mapa de cores especificado

### Descrição

public function **Gmagick::getimagecolors**(): [int](language.types.integer.md)

Retorna a cor do índice do mapa de cores especificado.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O número de cores na imagem.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
