# stats\_rand\_gen\_ipoisson

(PECL stats >= 1.0.0)

stats\_rand\_gen\_ipoisson — Gera um único desvio aleatório de uma distribuição de Poisson

### Descrição

function **stats\_rand\_gen\_ipoisson**([float](language.types.float.md) `$mu`): [int](language.types.integer.md)

Retorna um desvio aleatório da distribuição de Poisson com parâmetro `mu`.

### Parâmetros

`mu`
:   O parâmetro da distribuição de Poisson

### Valor Retornado

Um desvio aleatório
