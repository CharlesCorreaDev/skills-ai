# Gmagick::labelimage

(PECL gmagick >= Unknown)

Gmagick::labelimage — Adiciona um rótulo a uma imagem

### Descrição

public function **Gmagick::labelimage**([string](language.types.string.md) `$label`): [mixed](language.types.mixed.md)

Adiciona um rótulo a uma imagem.

### Parâmetros

`label`
:   O rótulo a ser adicionado

### Valor Retornado

Gmagick com rótulo.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
