(PHP 8)

ReflectionAttribute::getArguments — Obtém os argumentos passados para o atributo

### Descrição

public function **ReflectionAttribute::getArguments**(): [array](language.types.array.md)

Obtém os argumentos passados para o atributo.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Os argumentos passados para o atributo.
