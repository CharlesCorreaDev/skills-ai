## Constantes de indicação de nome do servidor

**`OPENSSL_TLSEXT_SERVER_NAME`** ([int](language.types.integer.md))
:   Se o suporte SNI está disponível ou não.

> **Nota**:
>
> Esta constante requer que o PHP seja
> compilado com OpenSSL 0.9.8j ou superior.
