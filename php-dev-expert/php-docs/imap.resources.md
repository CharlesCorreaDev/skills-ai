## Tipos de Recurso

Antes do PHP 8.1.0, esta extensão definia o tipo de recurso `imap`, conforme retornado por
[imap\_open()](function.imap-open.md), que faz referência a um fluxo IMAP aberto.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open

document.addEventListener("DOMContentLoaded", function() {
/\*{{{Search Modal\*/
const language = 'local';
initSearchModal();
initPHPSearch(language).then((searchCallback) => {
initSearchUI({language, searchCallback, limit: 30});
});
/\*}}}\*/
});
