# RecursiveTreeIterator::valid

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::valid — Verifica validade

### Descrição

public function **RecursiveTreeIterator::valid**(): [bool](language.types.boolean.md)

Verifica se a posição atual é válida.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se a posição atual for válida, caso contrário **`false`**
