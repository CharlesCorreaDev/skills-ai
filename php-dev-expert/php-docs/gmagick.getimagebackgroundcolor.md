# Gmagick::getimagebackgroundcolor

(PECL gmagick >= Unknown)

Gmagick::getimagebackgroundcolor — Retorna a cor de fundo da imagem

### Descrição

public function **Gmagick::getimagebackgroundcolor**(): [GmagickPixel](class.gmagickpixel.md)

Retorna a cor de fundo da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um GmagickPixel definido para a cor de fundo da imagem.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
