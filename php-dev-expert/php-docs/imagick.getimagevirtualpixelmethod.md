# Imagick::getImageVirtualPixelMethod

(PECL imagick 2, PECL imagick 3)

Imagick::getImageVirtualPixelMethod — Retorna o método do pixel virtual

### Descrição

public function **Imagick::getImageVirtualPixelMethod**(): [int](language.types.integer.md)

Retorna o método do pixel virtual para a imagem especificada.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o método do pixel virtual em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
