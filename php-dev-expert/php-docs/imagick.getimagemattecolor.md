# Imagick::getImageMatteColor

(PECL imagick 2, PECL imagick 3)

Imagick::getImageMatteColor — Retorna a cor fosca da imagem

**Aviso**

Esta função foi *DESCONTINUADA* a partir da Imagick 3.4.4. O uso desta função é fortemente desencorajado.

### Descrição

public function **Imagick::getImageMatteColor**(): [ImagickPixel](class.imagickpixel.md)

Retorna a cor fosca da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o objeto ImagickPixel em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
