# stats\_stat\_independent\_t

(PECL stats >= 1.0.0)

stats\_stat\_independent\_t — Retorna o valor t do teste t independente de duas amostras

### Descrição

function **stats\_stat\_independent\_t**([array](language.types.array.md) `$arr1`, [array](language.types.array.md) `$arr2`): [float](language.types.float.md)

Retorna o valor t do teste t independente de duas amostras entre
`arr1` e `arr2`.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

`arr1`
:   O primeiro conjunto de valores

`arr2`
:   O segundo conjunto de valores

### Valor Retornado

Retorna o valor t, ou **`false`** se houver falha.
