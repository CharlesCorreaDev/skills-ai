# RRDGraph::\_\_construct

(PECL rrd >= 0.9.0)

RRDGraph::\_\_construct — Cria uma nova instância de [RRDGraph](class.rrdgraph.md)

### Descrição

public function **RRDGraph::\_\_construct**([string](language.types.string.md) `$path`)

Cria uma nova instância de [RRDGraph](class.rrdgraph.md). Esta instância é responsável por renderizar
o resultado da consulta ao banco de dados RRD na imagem.

### Parâmetros

`path`
:   Caminho completo para a imagem recém-criada.
