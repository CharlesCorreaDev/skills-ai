## Tipos de Recurso

Existem dois tipos de recursos usados no módulo MySQL. O primeiro
é o identificador de conexão com o banco de dados, e o segundo é o recurso
que guarda o resultado de uma consulta.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
