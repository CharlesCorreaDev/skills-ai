## Dependências

Para usar esta extensão, é necessário instalar uma versão do Varnish Cache superior ou igual a 3.0,
disponível na [» página inicial do Varnish Cache](https://www.varnish-cache.org/).

`Enter` to select •
`Esc` to close • `/` to open
