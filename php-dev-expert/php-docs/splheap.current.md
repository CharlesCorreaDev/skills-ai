# SplHeap::current

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplHeap::current — Retorna o nó atual apontado pelo iterador

### Descrição

public function **SplHeap::current**(): [mixed](language.types.mixed.md)

Obtém o nó atual da estrutura de dados.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O valor do nó atual.
