## Tipos de Recurso

Antes do PHP 8.0.0, havia um tipo de recurso usado pela versão procedural da
extensão XMLWriter: retornado por [xmlwriter\_open\_memory()](xmlwriter.openmemory.md) ou
[xmlwriter\_open\_uri()](xmlwriter.openuri.md).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open

document.addEventListener("DOMContentLoaded", function() {
/\*{{{Search Modal\*/
const language = 'local';
initSearchModal();
initPHPSearch(language).then((searchCallback) => {
initSearchUI({language, searchCallback, limit: 30});
});
/\*}}}\*/
});
