SplHeap::isCorrupted — Indica se o heap está em um estado corrompido

### Descrição

public function **SplHeap::isCorrupted**(): [bool](language.types.boolean.md)

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se o heap estiver corrompido, **`false`** caso contrário.
