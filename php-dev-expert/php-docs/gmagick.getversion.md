# Gmagick::getversion

(PECL gmagick >= Unknown)

Gmagick::getversion — Retorna a versão da API GraphicsMagick

### Descrição

public function **Gmagick::getversion**(): [array](language.types.array.md)

Retorna a versão da API GraphicsMagick como uma string e um número.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a versão da API GraphicsMagick como uma string e um número.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
