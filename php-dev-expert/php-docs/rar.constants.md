# Constantes predefinidas

As constantes abaixo são definidas por esta extensão e
só estarão disponíveis quando a extensão tiver sido compilada no PHP
ou tiver sido carregada dinamicamente em tempo de execução.

**`RAR_HOST_MSDOS`** ([int](language.types.integer.md))
:   Use [**`RarEntry::HOST_MSDOS`**](class.rarentry.md#rarentry.constants.host-msdos) no lugar.

**`RAR_HOST_OS2`** ([int](language.types.integer.md))
:   Use [**`RarEntry::HOST_OS2`**](class.rarentry.md#rarentry.constants.host-os2) no lugar.

**`RAR_HOST_WIN32`** ([int](language.types.integer.md))
:   Use [**`RarEntry::HOST_WIN32`**](class.rarentry.md#rarentry.constants.host-win32) no lugar.

**`RAR_HOST_UNIX`** ([int](language.types.integer.md))
:   Use [**`RarEntry::HOST_UNIX`**](class.rarentry.md#rarentry.constants.host-unix) no lugar.

**`RAR_HOST_BEOS`** ([int](language.types.integer.md))
:   Use [**`RarEntry::HOST_BEOS`**](class.rarentry.md#rarentry.constants.host-beos) no lugar.
