## Instalação

Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/svn](https://pecl.php.net/package/svn)

Se ./configure estiver com problemas para encontrar os arquivos
SVN (por exemplo, o Subversion foi instalado com um
diretório de prefixo diferente), use
**`./configure --with-svn=$USR_PATH`**
para especificar o diretório onde a pasta
include/subversion-1/ está localizada.

Uma DLL para esta
extensão PECL não está disponível no momento. Veja também a seção
[Compilando no Windows](install.windows.building.md).

**Aviso**

Se a extensão for compilada com a libsvn 1.3,
as funções que funcionam com cópias de trabalho falharão
quando usadas em cópias de trabalho criadas pelo Subversion 1.4.
