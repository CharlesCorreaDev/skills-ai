# atanh

(PHP 4 >= 4.1.0, PHP 5, PHP 7, PHP 8)

atanh — Arco tangente hiperbólico

### Descrição

function **atanh**([float](language.types.float.md) `$num`): [float](language.types.float.md)

Retorna o arco tangente hiperbólico de
`num`, isto é, o valor cuja
tangente hiperbólica é `num`.

### Parâmetros

`num`
:   O argumento a processar

### Valor Retornado

O arco tangente hiperbólico de `num`
