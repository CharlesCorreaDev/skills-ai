# stats\_rand\_gen\_ibinomial

(PECL stats >= 1.0.0)

stats\_rand\_gen\_ibinomial — Gera um desvio aleatório da distribuição binomial

### Descrição

function **stats\_rand\_gen\_ibinomial**([int](language.types.integer.md) `$n`, [float](language.types.float.md) `$pp`): [int](language.types.integer.md)

Retorna um desvio aleatório da distribuição binomial cujo número de tentativas é `n`
e cuja probabilidade de um evento em cada tentativa é `pp`.

### Parâmetros

`n`
:   O número de tentativas

`pp`
:   A probabilidade de um evento em cada tentativa

### Valor Retornado

Um desvio aleatório
