# Imagick::getImageScene

(PECL imagick 2, PECL imagick 3)

Imagick::getImageScene — Obtém a cena da imagem

### Descrição

public function **Imagick::getImageScene**(): [int](language.types.integer.md)

Obtém a cena da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a cena da imagem.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
