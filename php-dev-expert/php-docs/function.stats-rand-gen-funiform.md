# stats\_rand\_gen\_funiform

(PECL stats >= 1.0.0)

stats\_rand\_gen\_funiform — Gera um float uniforme entre o limite inferior (exclusive) e superior (exclusive)

### Descrição

function **stats\_rand\_gen\_funiform**([float](language.types.float.md) `$low`, [float](language.types.float.md) `$high`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição uniforme entre
`low` e `high`.

### Parâmetros

`low`
:   O limite inferior (exclusive)

`high`
:   O limite superior (exclusive)

### Valor Retornado

Um desvio aleatório
