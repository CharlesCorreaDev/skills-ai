# stats\_rand\_gen\_exponential

(PECL stats >= 1.0.0)

stats\_rand\_gen\_exponential — Gera um desvio aleatório da distribuição exponencial

### Descrição

function **stats\_rand\_gen\_exponential**([float](language.types.float.md) `$av`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição exponencial da qual a escala é
`av`.

### Parâmetros

`av`
:   O parâmetro de escala

### Valor Retornado

Um desvio aleatório
