(PECL swoole >= 1.9.0)

Swoole\Connection\Iterator::current — Retorna a entrada de conexão atual.

### Descrição

public function **Swoole\Connection\Iterator::current**(): Connection

Obtém a entrada de conexão atual.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

A entrada de conexão atual.
