# trader\_errno

(PECL trader >= 0.3.0)

trader\_errno — Obtém código de erro

### Descrição

function **trader\_errno**(): [int](language.types.integer.md)

Obtém o código de erro da última operação.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o código de erro identificado por uma das constantes [TRADER\_ERR\_\*](trader.constants.md).
