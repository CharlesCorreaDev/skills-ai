# ImagickPixelIterator::getIteratorRow

(PECL imagick 2, PECL imagick 3)

ImagickPixelIterator::getIteratorRow — Retorna a linha atual do iterador de pixel

### Descrição

public function **ImagickPixelIterator::getIteratorRow**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a linha atual do iterador de pixel.

### Valor Retornado

Retorna a posição da linha como um inteiro, lançando
uma ImagickPixelIteratorException em caso de erro.
