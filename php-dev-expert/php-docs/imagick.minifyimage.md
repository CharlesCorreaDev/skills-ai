# Imagick::minifyImage

(PECL imagick 2, PECL imagick 3)

Imagick::minifyImage — Dimensiona uma imagem proporcionalmente à metade do seu tamanho

### Descrição

public function **Imagick::minifyImage**(): [bool](language.types.boolean.md)

É um método de conveniência que dimensiona uma imagem proporcionalmente à metade do seu tamanho original.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso.
