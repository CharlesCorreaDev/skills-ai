## Instalação

Esta extensão [» PECL](https://pecl.php.net/) não é distribuída com o PHP.
Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/mailparse](https://pecl.php.net/package/mailparse).

Para usar essas funções, você deve compilar o PHP com suporte ao mailparse
usando a opção de configuração
**--enable-mailparse**.

Usuários do Windows devem habilitar o php\_mailparse.dll dentro
de php.ini para usar essas funções.
Binários do Windows (arquivos DLL)
para esta extensão PECL estão disponíveis no site do PECL.

É necessário que a extensão [mbstring](ref.mbstring.md)
esteja carregada antes do mailparse.
