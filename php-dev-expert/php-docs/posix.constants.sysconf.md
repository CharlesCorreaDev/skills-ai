# Constantes posix_sysconf

> **Fonte / Source:** https://www.php.net/manual/pt_BR/posix.constants.sysconf.php

---

## Constantes [posix\_sysconf()](function.posix-sysconf.md)

**`POSIX_SC_ARG_MAX`** ([int](language.types.integer.md))
:   O número máximo de bytes que os argumentos (e variáveis de ambiente) podem ter.
    Disponível a partir do PHP 8.3.0.

**`POSIX_SC_PAGESIZE`** ([int](language.types.integer.md))
:   O número de bytes da página atual.
    Disponível a partir do PHP 8.3.0.

**`POSIX_SC_NPROCESSORS_CONF`** ([int](language.types.integer.md))
:   O número de CPUs configurados por sistema.
    Disponível a partir do PHP 8.3.0.

**`POSIX_SC_NPROCESSORS_ONLN`** ([int](language.types.integer.md))
:   O número de CPUs atualmente ativas no sistema.
    Disponível a partir do PHP 8.3.0.

**`POSIX_SC_CHILD_MAX`** ([int](language.types.integer.md))
:   O número máximo de processos simultâneos por usuário.
    Disponível a partir do PHP 8.4.0.

**`POSIX_SC_CLK_TCK`** ([int](language.types.integer.md))
:   O número de tiques do relógio por segundo.
    Disponível a partir do PHP 8.4.0.
