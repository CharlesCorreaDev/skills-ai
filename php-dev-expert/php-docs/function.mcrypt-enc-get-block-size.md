# mcrypt\_enc\_get\_block\_size

(PHP 4 >= 4.0.2, PHP 5, PHP 7 < 7.2.0, PECL mcrypt >= 1.0.0)

mcrypt\_enc\_get\_block\_size — Retorna o tamanho do bloco do algoritmo aberto

**Aviso**

Esta função foi
*DESCONTINUADA* a partir do PHP 7.1.0 e foi
*REMOVIDA* a partir do PHP 7.2.0. O uso desta função
é fortemente desencorajado.

### Descrição

function **mcrypt\_enc\_get\_block\_size**([resource](language.types.resource.md) `$td`): [int](language.types.integer.md)

Obtém o tamanho do bloco do algoritmo aberto.

### Parâmetros

`td`
:   O descritor de criptografia.

### Valor Retornado

Retorna o tamanho do bloco do algoritmo especificado em bytes.
