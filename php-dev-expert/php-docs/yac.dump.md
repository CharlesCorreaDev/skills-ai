# Yac::dump

(PECL yac >= 1.0.0)

Yac::dump — Despeja o cache

### Descrição

public function **Yac::dump**([int](language.types.integer.md) `$num`): [mixed](language.types.mixed.md)

Despeja os valores armazenados em cache.

### Parâmetros

`num`
:   O máximo número de itens que devem ser retornados.

### Valor Retornado

Retorna os valores despejados.
