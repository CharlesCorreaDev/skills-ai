# Yaf\_Route\_Regex::route

(Yaf >=1.0.0)

Yaf\_Route\_Regex::route — Encaminha uma solicitação

### Descrição

public function **Yaf\_Route\_Regex::route**([Yaf\_Request\_Abstract](class.yaf-request-abstract.md) `$request`): [bool](language.types.boolean.md)

Encaminha uma solicitação de entrada.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

`request`

### Valor Retornado

Se a expressão fornecida no primeiro parâmetros de
**Yaf\_Route\_Regex::\_construct()** corresponder ao URI
da requisição, retorna **`true`**, caso contrário retorna **`false`**.
