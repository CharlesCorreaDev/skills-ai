## Instalação

As funções da extensão Socket descritas aqui fazem parte de uma extensão do PHP
que deve ser habilitada no momento da compilação adicionando a opção **--enable-sockets** à linha de comando
**configure**.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open

document.addEventListener("DOMContentLoaded", function() {
/\*{{{Search Modal\*/
const language = 'local';
initSearchModal();
initPHPSearch(language).then((searchCallback) => {
initSearchUI({language, searchCallback, limit: 30});
});
/\*}}}\*/
});
