# Imagick::listRegistry

(PECL imagick 3 >= 3.3.0)

Imagick::listRegistry — Lista todas as configurações do registro

### Descrição

public static function **Imagick::listRegistry**(): [array](language.types.array.md)

Lista todas as configurações do registro. Retorna um array com todos os pares chave/valor no registro

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Um array contendo as chaves/valores do registro.
