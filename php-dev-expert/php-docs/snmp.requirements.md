## Dependências

A instalação do pacote [» Net-SNMP](https://www.net-snmp.org/) é
requerida para para utilizar as funções SNMP. As funções
SNMPv3 só estarão disponíveis quando o pacote [» OpenSSL](https://www.openssl.org/)
também estiver instalado

Net-SNMP versão 5.3+ é necessária para Unix
e o Net-SNMP 5.4+ para Windows.
