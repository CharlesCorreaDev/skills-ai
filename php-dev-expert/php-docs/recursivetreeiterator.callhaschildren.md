# RecursiveTreeIterator::callHasChildren

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::callHasChildren — Tem filhos

### Descrição

public function **RecursiveTreeIterator::callHasChildren**(): [bool](language.types.boolean.md)

Chamado para cada elemento para testar se ele tem filhos.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se houver filhos, caso contrário, **`false`**
