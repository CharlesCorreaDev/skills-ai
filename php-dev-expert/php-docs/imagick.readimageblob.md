# Imagick::readImageBlob

(PECL imagick 2, PECL imagick 3)

Imagick::readImageBlob — Lê imagem de uma string binária

### Descrição

public function **Imagick::readImageBlob**([string](language.types.string.md) `$image`, [string](language.types.string.md) `$filename` = ?): [bool](language.types.boolean.md)

Lê uma imagem a partir de uma string binária.

### Parâmetros

`image`

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
