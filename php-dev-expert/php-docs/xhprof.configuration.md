## Configurações de Execução

O comportamento destas funções é afetado pelas configurações do php.ini.

**Opções de Configuração de Xhprof**

| Nome | Padrão | Modificável | Registro de Alterações |
| --- | --- | --- | --- |
| [xhprof.output\_dir](xhprof.configuration.md#ini.xhprof.output-dir) | "" | **`INI_ALL`** |  |

Aqui está uma breve explicação das
diretivas de configuração.

`xhprof.output_dir` [string](language.types.string.md)
:   Diretório usado pela implementação padrão da interface iXHProfRuns
    (ou seja, a classe XHProfRuns\_Default) para armazenar
    execuções XHProf.
