## Instalação

A distribuição do Windows do [» Net-SNMP](https://www.net-snmp.org/) contém arquivos de suporte para SNMP no
diretório mibs. Este diretório
deve ser adicionado às variáveis ​​de ambiente do Windows, como MIBDIRS, com o
valor sendo o caminho completo para o diretório mibs:
por exemplo, c:\usr\mibs.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
