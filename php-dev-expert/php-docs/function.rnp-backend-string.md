# rnp\_backend\_string

(PECL rnp >= 0.1.1)

rnp\_backend\_string — Retorna o nome da biblioteca de back-end criptográfico

### Descrição

function **rnp\_backend\_string**(): [string](language.types.string.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

String de nome de back-end. Os backends atualmente
suportados são "Botan" e "OpenSSL".

`Enter` to select •
`Esc` to close • `/` to open
