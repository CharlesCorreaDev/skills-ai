# ImagickPixel::clear

(PECL imagick 2, PECL imagick 3)

ImagickPixel::clear — Limpa recursos associados a este objeto

### Descrição

public function **ImagickPixel::clear**(): [bool](language.types.boolean.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Limpa o objeto ImagickPixel, deixando-o em estado de novo. Isso também
remove as definições de cor associadas ao objeto.

### Valor Retornado

Retorna **`true`** em caso de sucesso.
