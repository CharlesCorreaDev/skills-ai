# Examples

Uso básico

**Exemplo #1 Execução básica de Javascript**

```
<?php

$v8 = new V8Js();

/* basic.js */
$JS = <<< EOT
len = print('Hello' + ' ' + 'World!' + "\\n");
len;
EOT;

try {
  var_dump($v8->executeString($JS, 'basic.js'));
} catch (V8JsException $e) {
  var_dump($e);
}

?>
```

O exemplo acima produzirá:

```
Hello World!
int(13)
```
