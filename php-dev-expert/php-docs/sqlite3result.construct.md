private function **SQLite3Result::\_\_construct**()

As instâncias de [SQLite3Result](class.sqlite3result.md) são criadas por
[SQLite3::query()](sqlite3.query.md) e [SQLite3Stmt::execute()](sqlite3stmt.execute.md).
