# ImagickPixelIterator::getCurrentIteratorRow

(PECL imagick 2, PECL imagick 3)

ImagickPixelIterator::getCurrentIteratorRow — Retorna a linha atual de objetos ImagickPixel

### Descrição

public function **ImagickPixelIterator::getCurrentIteratorRow**(): [array](language.types.array.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a linha atual como um array de objetos ImagickPixel do iterador de pixel.

### Valor Retornado

Retorna uma linha como um array de objetos ImagickPixel que podem ser iterados.
