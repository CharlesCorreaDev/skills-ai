# trader\_div

(PECL trader >= 0.2.0)

trader\_div — Divisão Aritmética Vetorial

### Descrição

function **trader\_div**([array](language.types.array.md) `$real0`, [array](language.types.array.md) `$real1`): [array](language.types.array.md)

Divide cada valor de `real0` pelo valor
correspondente de `real1` e retorna o array resultante.

### Parâmetros

`real0`
:   Array de valores reais.

`real1`
:   Array de valores reais.

### Valor Retornado

Retorna um array com os dados calculados ou false em caso de falha.
