# stats\_stat\_paired\_t

(PECL stats >= 1.0.0)

stats\_stat\_paired\_t — Retorna o valor t do teste t dependente para amostras pareadas

### Descrição

function **stats\_stat\_paired\_t**([array](language.types.array.md) `$arr1`, [array](language.types.array.md) `$arr2`): [float](language.types.float.md)

Retorna o valor t do teste t dependente para amostras pareadas
`arr1` e `arr2`.

### Parâmetros

`arr1`
:   As amostras do primeiro par

`arr2`
:   As amostras do segundo par

### Valor Retornado

Retorna o valor t, ou **`false`** se houver falha.
