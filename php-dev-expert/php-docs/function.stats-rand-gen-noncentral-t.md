# stats\_rand\_gen\_noncentral\_t

(PECL stats >= 1.0.0)

stats\_rand\_gen\_noncentral\_t — Gera um único desvio aleatório de uma distribuição t não centralizada

### Descrição

function **stats\_rand\_gen\_noncentral\_t**([float](language.types.float.md) `$df`, [float](language.types.float.md) `$xnonc`): [float](language.types.float.md)

Retorna um desvio aleatório da distribuição t não central com os graus de liberdade
`df`, e o parâmetro de não centralidade `xnonc`.

### Parâmetros

`df`
:   Os graus de liberdade

`xnonc`
:   O parâmetro de não centralidade

### Valor Retornado

Um desvio aleatório
