## Instalação

Nenhuma instalação é necessária para usar estas
funções; elas fazem parte do núcleo do PHP.

A partir do PHP 8.1.0, [crypt()](function.crypt.md) pode ser compilada contra uma bilbioteca de criptografia de sistema
especificando-se a opção de configuração **--with-external-libcrypt**.
