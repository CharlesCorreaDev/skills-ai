# Gmagick::getimagematte

(PECL gmagick >= Unknown)

Gmagick::getimagematte — Verifique se a imagem possui um canal fosco

### Descrição

public function **Gmagick::getimagematte**(): [int](language.types.integer.md)

Retorna **`true`** se a imagem tiver um canal fosco, caso contrário, **`false`**.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se a imagem tiver um canal fosco, caso contrário, **`false`**.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
