# Imagick::getRegistry

(PECL imagick 3 >= 3.3.0)

Imagick::getRegistry — Obtém uma entrada StringRegistry

### Descrição

public static function **Imagick::getRegistry**([string](language.types.string.md) `$key`): [string](language.types.string.md)

Obtém a entrada StringRegistry para a chave nomeada ou false se não estiver definida.

### Parâmetros

`key`
:   A entrada a ser obtida.
