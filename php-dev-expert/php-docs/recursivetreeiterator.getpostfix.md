# RecursiveTreeIterator::getPostfix

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::getPostfix — Obtém o sufixo

### Descrição

public function **RecursiveTreeIterator::getPostfix**(): [string](language.types.string.md)

Obtém a string para colocar após o elemento atual.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a string para colocar após o elemento atual.
