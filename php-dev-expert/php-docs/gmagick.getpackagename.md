# Gmagick::getpackagename

(PECL gmagick >= Unknown)

Gmagick::getpackagename — Retorna o nome do pacote GraphicsMagick

### Descrição

public function **Gmagick::getpackagename**(): [string](language.types.string.md)

Retorna o nome do pacote GraphicsMagick.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o nome do pacote GraphicsMagick como uma string.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
