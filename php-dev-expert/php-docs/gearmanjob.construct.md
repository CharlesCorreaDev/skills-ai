# GearmanJob::\_\_construct

(PECL gearman >= 0.5.0)

GearmanJob::\_\_construct — Cria uma instância de GearmanJob

### Descrição

public function **GearmanJob::\_\_construct**()

Cria uma instância de [GearmanJob](class.gearmanjob.md) representando um trabalho que o trabalhador deve concluir.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Um objeto [GearmanJob](class.gearmanjob.md).
