# VarnishAdmin::getPanic

(PECL varnish >= 0.4)

VarnishAdmin::getPanic — Obtém a última mensagem de pânico em uma instância do Varnish

### Descrição

public function **VarnishAdmin::getPanic**(): [string](language.types.string.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a última mensagem de pânico na instância atual do Varnish.
