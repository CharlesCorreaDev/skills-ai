# RRDUpdater::\_\_construct

(PECL rrd >= 0.9.0)

RRDUpdater::\_\_construct — Cria uma nova instância de [RRDUpdater](class.rrdupdater.md)

### Descrição

public function **RRDUpdater::\_\_construct**([string](language.types.string.md) `$path`)

Cria uma nova instância RRDUpdater. Esta instância é responsável por atualizar
o arquivo de banco de dados RRD.

### Parâmetros

`path`
:   Caminho do sistema de arquivos para o arquivo de banco de dados RRD, que será atualizado.
