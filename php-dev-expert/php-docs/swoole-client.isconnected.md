# Swoole\Client::isConnected

(PECL swoole >= 1.9.0)

Swoole\Client::isConnected — Verifica se a conexão está estabelecida.

### Descrição

public function **Swoole\Client::isConnected**(): [bool](language.types.boolean.md)

Este método retorna o status da conexão da camada de aplicação.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Se a conexão está estabelecida
