# GmagickDraw::getfontsize

(PECL gmagick >= Unknown)

GmagickDraw::getfontsize — Retorna o tamanho da fonte em pontos

### Descrição

public function **GmagickDraw::getfontsize**(): [float](language.types.float.md)

Retorna o tamanho da fonte, em pontos, usado ao fazer anotações com texto.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o tamanho da fonte associado ao objeto
[GmagickDraw](class.gmagickdraw.md) atual.
