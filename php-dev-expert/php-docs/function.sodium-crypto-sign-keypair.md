# sodium\_crypto\_sign\_keypair

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_sign\_keypair — Gera aleatoriamente uma chave secreta e uma chave pública correspondente

### Descrição

function **sodium\_crypto\_sign\_keypair**(): [string](language.types.string.md)

Gera uma par de chaves Ed25519 aleatório como uma string.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Par de chaves Ed25519.
