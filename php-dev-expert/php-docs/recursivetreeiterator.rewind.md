# RecursiveTreeIterator::rewind

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

RecursiveTreeIterator::rewind — Rebobina o iterador

### Descrição

public function **RecursiveTreeIterator::rewind**(): [void](language.types.void.md)

Rebobina o iterador para o primeiro elemento do iterador interno do nível superior.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Nenhum valor é retornado.
