# ReflectionConstant::\_\_toString

(PHP 8 >= 8.4.0)

ReflectionConstant::\_\_toString — Retorna representação em string

### Descrição

public function **ReflectionConstant::\_\_toString**(): [string](language.types.string.md)

Retorna a representação em string do
objeto [ReflectionConstant](class.reflectionconstant.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Uma representação em string desta instância de [ReflectionConstant](class.reflectionconstant.md).
