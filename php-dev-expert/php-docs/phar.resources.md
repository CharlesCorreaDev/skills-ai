## Tipos de Recurso

A extensão Phar fornece o fluxo `phar`, que
permite acessar arquivos contidos em um phar de forma transparente. Veja também a
[descrição do formato de arquivo Phar](phar.fileformat.md).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open

document.addEventListener("DOMContentLoaded", function() {
/\*{{{Search Modal\*/
const language = 'local';
initSearchModal();
initPHPSearch(language).then((searchCallback) => {
initSearchUI({language, searchCallback, limit: 30});
});
/\*}}}\*/
});
