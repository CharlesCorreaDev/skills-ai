# dba\_list

(PHP 4 >= 4.3.0, PHP 5, PHP 7, PHP 8)

dba\_list — Lista todos os arquivos de banco de dados abertos

### Descrição

function **dba\_list**(): [array](language.types.array.md)

**dba\_list()** lista todos os arquivos de banco de dados abertos.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Um array associativo, na forma `id_recurso => nome_arquivo`.
