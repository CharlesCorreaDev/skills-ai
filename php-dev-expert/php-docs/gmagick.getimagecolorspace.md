# Gmagick::getimagecolorspace

(PECL gmagick >= Unknown)

Gmagick::getimagecolorspace — Obtém o espaço de cores da imagem

### Descrição

public function **Gmagick::getimagecolorspace**(): [int](language.types.integer.md)

Obtém o espaço de cores da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O espaço de cores da imagem.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
