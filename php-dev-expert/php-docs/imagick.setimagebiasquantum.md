# Imagick::setImageBiasQuantum

(PECL imagick 3 >= 3.3.0)

Imagick::setImageBiasQuantum — Define o ajuste (bias) da imagem

**Aviso**

Esta função foi *DESCONTINUADA* a partir da Imagick 3.4.4. O uso desta função é fortemente desencorajado.

### Descrição

public function **Imagick::setImageBiasQuantum**([float](language.types.float.md) `$bias`): [void](language.types.void.md)

Define o ajuste da imagem. O ajuste deve ser dimensionado entre `0` (sem ajuste) a `1` (valor Quantum).

### Parâmetros

`bias`
