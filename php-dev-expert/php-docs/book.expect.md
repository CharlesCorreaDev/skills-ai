# Expect

# Introdução

Esta extensão permite interagir com processos através do PTY. Pode-se
considerar o uso do [empacotador `expect://`](wrappers.expect.md)
com as [funções do sistema de
arquivos](ref.filesystem.md) que fornece uma interface mais simples e intuitiva.

  - [expect\_popen](function.expect-popen.md) — Executa comando via Bourne shell, e abre o fluxo PTY para
    o processo
