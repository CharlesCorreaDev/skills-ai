# SplFixedArray::getIterator

(PHP 8)

SplFixedArray::getIterator — Recupera o iterador para percorrer o array

### Descrição

public function **SplFixedArray::getIterator**(): [Iterator](class.iterator.md)

Retorna o iterador para percorrer o array.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Uma instância de um objeto que implementa [Iterator](class.iterator.md) para
percorrer o array.
