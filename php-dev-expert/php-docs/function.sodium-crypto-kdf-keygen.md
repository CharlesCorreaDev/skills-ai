# sodium\_crypto\_kdf\_keygen

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_kdf\_keygen — Gera uma chave raiz aleatória para a interface KDF

### Descrição

function **sodium\_crypto\_kdf\_keygen**(): [string](language.types.string.md)

Gera uma chave aleatória adequada para servir como chave raiz para [sodium\_crypto\_kdf\_derive\_from\_key()](function.sodium-crypto-kdf-derive-from-key.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Uma chave aleatória de 256 bits.
