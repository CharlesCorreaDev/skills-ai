# SVMModel::getNrClass

(PECL svm >= 0.1.5)

SVMModel::getNrClass — Retorna o número de classes com as quais o modelo foi treinado

### Descrição

public function **SVMModel::getNrClass**(): [int](language.types.integer.md)

Retorna o número de classes com as quais o modelo foi treinado, retornará 2 para uma classe e modelos de regressão.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um número inteiro de classes.
