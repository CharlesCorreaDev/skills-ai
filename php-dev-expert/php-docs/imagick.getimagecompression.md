# Imagick::getImageCompression

(PECL imagick 3 >= 3.3.0)

Imagick::getImageCompression — Obtém o tipo de compactação da imagem atual

### Descrição

public function **Imagick::getImageCompression**(): [int](language.types.integer.md)

Obtém o tipo de compactação da imagem atual.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a constante de compactação.
