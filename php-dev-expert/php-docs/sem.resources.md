## Tipos de Recurso

Antes do PHP 8.0.0, esta extensão definia os tipos de recursos
`sysvmsg queue` (Fila de Mensagens System V),
`sysvsem` (Semáforos System V) e
`sysvshm` (Memória Compartilhada System V).

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
