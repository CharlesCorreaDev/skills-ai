# MultipleIterator::countIterators

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

MultipleIterator::countIterators — Obtém o número de instâncias de iteradores anexadas

### Descrição

public function **MultipleIterator::countIterators**(): [int](language.types.integer.md)

Obtém o número de instâncias de iteradores anexadas.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O número de instâncias de iteradores anexadas (como um [int](language.types.integer.md)).
