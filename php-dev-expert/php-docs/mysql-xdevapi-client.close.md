### Descrição

public function **mysql\_xdevapi\Client::close**(): [bool](language.types.boolean.md)

Fecha todas as conexões de cliente com o servidor.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se as conexões forem fechadas.
