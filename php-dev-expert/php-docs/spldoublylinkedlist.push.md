# SplDoublyLinkedList::push

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplDoublyLinkedList::push — Adiciona um elemento no final da lista duplamente encadeada

### Descrição

public function **SplDoublyLinkedList::push**([mixed](language.types.mixed.md) `$value`): [void](language.types.void.md)

Adiciona o `value` no final da lista duplamente encadeada.

### Parâmetros

`value`
:   O valor a ser adicionado.

### Valor Retornado

Nenhum valor é retornado.
