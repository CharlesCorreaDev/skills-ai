## Dependências

Opcionalmente, podeme ser habilitadas as extensões [zlib](book.zlib.md)
e [bzip2](book.bzip2.md) para aproveitar
o suporte a phar compactado. Além disso, para aproveitar
a assinatura OpenSSL, a extensão [OpenSSL](book.openssl.md) deve estar
habilitada.

Se [zend.multibyte](ini.core.md#ini.zend.multibyte) estiver habilitado, [zend.detect\_unicode](ini.core.md#ini.zend.detect-unicode) também deverá ser habilitado.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
