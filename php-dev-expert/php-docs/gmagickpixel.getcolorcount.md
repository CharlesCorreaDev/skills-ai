# GmagickPixel::getcolorcount

(PECL gmagick >= Unknown)

GmagickPixel::getcolorcount — Retorna a contagem de cores associada a esta cor

### Descrição

public function **GmagickPixel::getcolorcount**(): [int](language.types.integer.md)

Retorna a contagem de cores associada a esta cor.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a contagem de cores como um número inteiro em caso de sucesso, lança uma **GmagickPixelException** em caso de falha.
