# stats\_absolute\_deviation

(PECL stats >= 1.0.0)

stats\_absolute\_deviation — Retorna o desvio absoluto de um array de valores

### Descrição

function **stats\_absolute\_deviation**([array](language.types.array.md) `$a`): [float](language.types.float.md)

Retorna o desvio absoluto dos valores em `a`.

### Parâmetros

`a`
:   The input array

### Valor Retornado

Retorna o desvio absoluto dos valores em `a`,
ou **`false`** se `a` estiver vazio ou não for um array.
