# Imagick::getImageCompressionQuality

(PECL imagick 2 >= 2.2.2, PECL imagick 3)

Imagick::getImageCompressionQuality — Obtém a qualidade de compressão da imagem atual

### Descrição

public function **Imagick::getImageCompressionQuality**(): [int](language.types.integer.md)

Obtém a qualidade de compressão da imagem atual.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um número inteiro que descreve a qualidade de compressão das imagens.
