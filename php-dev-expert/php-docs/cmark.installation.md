## Instalação

As versões da extensão CommonMark são hospedadas pelo PECL e a fonte é hospedada no
[» github](https://github.com/krakjoe/cmark),
o caminho mais fácil para instalação é o caminho PECL normal:
[» https://pecl.php.net/package/cmark](https://pecl.php.net/package/cmark).

Os usuários do Windows podem baixar binários de versões pré-construídas no site do [» PECL](https://pecl.php.net/package/cmark).

**Cuidado**

Os usuários do Windows precisam realizar a etapa adicional de adicionar cmark.dll (distribuído com versões do Windows) ao PATH.

`Enter` to select •
`Esc` to close • `/` to open
