# Swoole\Buffer::append

(PECL swoole >= 1.9.0)

Swoole\Buffer::append — Anexa a string ou dados binários ao final do buffer de memória e retorna o novo tamanho da memória alocada.

### Descrição

public function **Swoole\Buffer::append**([string](language.types.string.md) `$data`): [int](language.types.integer.md)

### Parâmetros

`data`
:   A string ou dados binários para anexar ao final do buffer de memória.

### Valor Retornado

O novo tamanho do buffer de memória.
