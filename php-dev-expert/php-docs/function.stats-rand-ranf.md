# stats\_rand\_ranf

(PECL stats >= 1.0.0)

stats\_rand\_ranf — Gera um número de ponto flutuante aleatório entre 0 e 1

### Descrição

function **stats\_rand\_ranf**(): [float](language.types.float.md)

Retorna um número de ponto flutuante aleatório de uma distribuição uniforme entre 0 (exclusive) e 1 (exclusive).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Um número de ponto flutuante aleatório
