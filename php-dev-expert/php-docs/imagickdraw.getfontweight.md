# ImagickDraw::getFontWeight

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getFontWeight — Retorna a espessura da fonte

### Descrição

public function **ImagickDraw::getFontWeight**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a espessura da fonte usada ao fazer anotações com texto.

### Valor Retornado

Retorna um [int](language.types.integer.md) em caso de sucesso e 0 se nenhum peso for definido.
