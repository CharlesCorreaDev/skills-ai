# RecursiveCachingIterator::hasChildren

(PHP 5 >= 5.1.0, PHP 7, PHP 8)

RecursiveCachingIterator::hasChildren — Verifica se o elemento atual do iterador interno possui filhos

### Descrição

public function **RecursiveCachingIterator::hasChildren**(): [bool](language.types.boolean.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se o iterador interno tiver filhos, caso contrário, retorna **`false`**
