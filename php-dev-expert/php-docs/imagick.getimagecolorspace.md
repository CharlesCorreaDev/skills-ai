# Imagick::getImageColorspace

(PECL imagick 2, PECL imagick 3)

Imagick::getImageColorspace — Obtém o espaço de cores da imagem

### Descrição

public function **Imagick::getImageColorspace**(): [int](language.types.integer.md)

Obtém o espaço de cores da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um número inteiro que pode ser comparado com as [constantes de espaço de cores](imagick.constants.md#imagick.constants.colorspace).
