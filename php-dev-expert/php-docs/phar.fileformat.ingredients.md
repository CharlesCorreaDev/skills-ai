## Ingredientes de todos os arquivos Phar, independentemente do formato do arquivo

Todos os arquivos Phar contêm de três a quatro seções:

1. um stub
2. um manifesto descrevendo o conteúdo
3. o conteúdo do arquivo
4. [opcional] uma assinatura para verificar a integridade do Phar (somente formato de arquivo phar)

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
