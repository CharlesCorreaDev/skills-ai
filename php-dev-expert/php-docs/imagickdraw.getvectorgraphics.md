# ImagickDraw::getVectorGraphics

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getVectorGraphics — Retorna uma string contendo gráficos vetoriais

### Descrição

public function **ImagickDraw::getVectorGraphics**(): [string](language.types.string.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna uma string que especifica os gráficos vetoriais gerados por quaisquer
chamadas gráficas feitas desde que o objeto [ImagickDraw](class.imagickdraw.md) foi instanciado.

### Valor Retornado

Retorna uma string contendo os gráficos vetoriais.
