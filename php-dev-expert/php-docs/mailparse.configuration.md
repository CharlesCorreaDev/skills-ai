## Configurações de Execução

O comportamento destas funções é afetado pelas configurações do php.ini.

**Opções de Configuração de Mailparse**

| Nome | Padrão | Modificável | Registro de Alterações |
| --- | --- | --- | --- |
| [mailparse.def\_charset](mailparse.configuration.md#ini.mailparse.def_charset) | "us-ascii" | **`INI_SYSTEM`** |  |

Para mais detalhes e definições dos modos
INI\_\*, consulte os [Onde uma configuração deve ser definida](configuration.changes.modes.md).

Aqui está uma breve explicação das
diretivas de configuração.

`mailparse.def_charset` [string](language.types.string.md)
:   O conjunto de caracteres padrão.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
