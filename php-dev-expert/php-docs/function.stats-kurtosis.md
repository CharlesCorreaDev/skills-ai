# stats\_kurtosis

(PECL stats >= 1.0.0)

stats\_kurtosis — Calcula a curtose dos dados no array

### Descrição

function **stats\_kurtosis**([array](language.types.array.md) `$a`): [float](language.types.float.md)

Retorna a curtose dos valores em `a`.

### Parâmetros

`a`
:   O array de entrada

### Valor Retornado

Retorna a curtose dos valores em `a`,
ou **`false`** se `a` estiver vazio ou não for um array.
