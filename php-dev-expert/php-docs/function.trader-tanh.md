# trader\_tanh

(PECL trader >= 0.2.0)

trader\_tanh — Tangente Hiperbólica Trigonométrica Vetorial

### Descrição

function **trader\_tanh**([array](language.types.array.md) `$real`): [array](language.types.array.md)

Calcula a tangente hperbólica para cada valor em
`real` e retorna o array resultante.

### Parâmetros

`real`
:   Array de valores reais.

### Valor Retornado

Retorna um array com os dados calculados ou false em caso de falha.
