## Tipos de Recurso

Esta extensão define os seguintes tipos de recursos:

- SSH2 Session
- SSH2 Listener
- SSH2 SFTP
- SSH2 Publickey Subsystem (a partir de ssh2 0.10)

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
