## Instalação

Esta extensão [» PECL](https://pecl.php.net/) não é distribuída com o PHP.

Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui: [» https://pecl.php.net/package/mqseries](https://pecl.php.net/package/mqseries).

> **Nota**:
>
> O nome oficial desta extensão é *mqseries*.

Há duas maneiras de se conectar a um gerenciador de filas. Elas dependem da maneira como a extensão é compilada e vinculada.

- A primeira e também a padrão é usar as bibliotecas mqic. Compilar e vincular a
  extensão com essas bibliotecas IBM WebSphere MQSeries permite que a extensão se conecte ao
  gerenciador de filas usando a interface do cliente. Conexões remotas são possíveis dessa maneira.
- A outra maneira é compilar e vincular com as bibliotecas mqm. Usando essas bibliotecas é
  possível fazer uso do gerenciamento de transações de um gerenciador de filas.

Atualmente, a seleção das bibliotecas a serem usadas é feita alterando o arquivo config.m4.
