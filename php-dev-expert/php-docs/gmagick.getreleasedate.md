# Gmagick::getreleasedate

(PECL gmagick >= Unknown)

### Descrição

public function **Gmagick::getreleasedate**(): [string](language.types.string.md)

Retorna a data de lançamento do GraphicsMagick como uma string.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a data de lançamento do GraphicsMagick como uma string.
