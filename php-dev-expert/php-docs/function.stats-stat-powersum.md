# stats\_stat\_powersum

(PECL stats >= 1.0.0)

stats\_stat\_powersum — Retorna a soma de potências de um vetor

### Descrição

function **stats\_stat\_powersum**([array](language.types.array.md) `$arr`, [float](language.types.float.md) `$power`): [float](language.types.float.md)

Retorna a soma da `power`-ésima potência de um vetor representado como um array `arr`.

### Parâmetros

`arr`
:   O array de entrada

`power`
:   A potência

### Valor Retornado

Retorna a soma de potências do array de entrada.
