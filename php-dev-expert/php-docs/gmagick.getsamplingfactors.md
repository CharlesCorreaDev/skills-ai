# Gmagick::getsamplingfactors

(PECL gmagick >= Unknown)

Gmagick::getsamplingfactors — Obtém o fator de amostragem horizontal e vertical

### Descrição

public function **Gmagick::getsamplingfactors**(): [array](language.types.array.md)

Obtém o fator de amostragem horizontal e vertical.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um array associativo com os fatores de amostragem horizontal e vertical da imagem.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
