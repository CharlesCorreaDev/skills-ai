# ImagickDraw::getTextDecoration

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getTextDecoration — Retorna a decoração do texto

### Descrição

public function **ImagickDraw::getTextDecoration**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a decoração aplicada ao anotar com texto.

### Valor Retornado

Retorna uma constante [DECORATION](imagick.constants.md#imagick.constants.decoration)
(`imagick::DECORATION_*`) ou 0 se nenhuma decoração estiver definida.
