# Imagick::setImageGamma

(PECL imagick 2, PECL imagick 3)

Imagick::setImageGamma — Define o gama da imagem

### Descrição

public function **Imagick::setImageGamma**([float](language.types.float.md) `$gamma`): [bool](language.types.boolean.md)

Define o gama da imagem.

### Parâmetros

`gamma`

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
