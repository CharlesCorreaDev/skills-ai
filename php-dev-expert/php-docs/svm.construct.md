# SVM::\_\_construct

(PECL svm >= 0.1.0)

SVM::\_\_construct — Constrói um novo objeto SVM

### Descrição

public function **SVM::\_\_construct**()

Constrói um novo objeto SVM pronto para aceitar dados de treinamento.

### Parâmetros

Esta função não possui parâmetros.

### Erros/Exceções

Lança uma **SVMException** se a biblioteca libsvm
não puder ser carregada.
