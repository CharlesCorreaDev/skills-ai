# GearmanClient::removeOptions

(PECL gearman >= 0.6.0)

GearmanClient::removeOptions — Remove opções do cliente

### Descrição

public function **GearmanClient::removeOptions**([int](language.types.integer.md) `$option`): [bool](language.types.boolean.md)

Remove (desativa) uma ou mais opções.

### Parâmetros

`option`
:   As opções a serem removidas (desdefinidas).

### Valor Retornado

Sempre retorna **`true`**.
