# Gmagick::getcopyright

(PECL gmagick >= Unknown)

Gmagick::getcopyright — Retorna os direitos autorais da API GraphicsMagick como uma string

### Descrição

public function **Gmagick::getcopyright**(): [string](language.types.string.md)

Retorna os direitos autorais da API GraphicsMagick como uma string.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string contendo o aviso de direitos autorais da API
GraphicsMagick e Magickwand C.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
