## Instalação

Esta extensão está habilitada por padrão.

Usuários do Windows devem incluir a DLL fornecida
php\_fileinfo.dll no php.ini para habilitar esta extensão.

A biblioteca libmagic é fornecida com o PHP, mas inclui alterações específicas do PHP.
Uma alteração para libmagic chamada libmagic.patch é mantido
e pode ser encontrada no diretório de arquivos fontes da extensão fileinfo.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
