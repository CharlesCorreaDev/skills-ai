# ZMQDevice::getTimerTimeout

(No version information available, might only be in Git)

ZMQDevice::getTimerTimeout — Obtém o tempo limite do temporizador

### Descrição

public function **ZMQDevice::getTimerTimeout**(): [ZMQDevice](class.zmqdevice.md)

Obtém o valor do tempo limite do temporizador. Adicionado na versão 1.0.0 da extensão ZMQ.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Este método retorna o valor do tempo limite do temporizador.
