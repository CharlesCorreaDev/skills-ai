# sodium\_crypto\_auth\_keygen

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_auth\_keygen — Gera uma chave aleatória para sodium\_crypto\_auth

### Descrição

function **sodium\_crypto\_auth\_keygen**(): [string](language.types.string.md)

Gera uma chave para uso com [sodium\_crypto\_auth()](function.sodium-crypto-auth.md) e [sodium\_crypto\_auth\_verify()](function.sodium-crypto-auth-verify.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma chave 256-bit aleatória.
