## Instalação

As versões do pthreads são hospedadas pelo PECL e o código fonte pelo
[» github](https://github.com/krakjoe/pthreads),
o caminho mais fácil para instalação é o caminho normal do PECL:
[» https://pecl.php.net/package/pthreads](https://pecl.php.net/package/pthreads).

Os usuários do Windows podem baixar binários de versão pré-construídos no site [» PECL](https://pecl.php.net/package/pthreads).

**Cuidado**

Os usuários do Windows precisam realizar a etapa adicional de adicionar pthreadVC2.dll (distribuído com as versões do Windows) ao seu PATH.
