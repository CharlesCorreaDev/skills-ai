# GearmanJob::setReturn

(PECL gearman >= 0.5.0)

GearmanJob::setReturn — Define um valor de retorno

### Descrição

public function **GearmanJob::setReturn**([int](language.types.integer.md) `$gearman_return_t`): [bool](language.types.boolean.md)

Define o valor de retorno para este trabalho indicando como o trabalho foi concluído.

### Parâmetros

`gearman_return_t`
:   Um valor de retorno Gearman válido.

### Valor Retornado
