## Instalação

Esta extensão [» PECL](https://pecl.php.net/) não é distribuída com o PHP.
Informações para instalar esta extensão PECL podem ser
encontradas no capítulo [Instalação de
Extensões PECL](install.pecl.md) do manual. Informações adicionais, como novas versões,
downloads, arquivos fontes, informações do mantenedor e um CHANGELOG, podem ser
encontradas aqui:
[» https://pecl.php.net/package/expect](https://pecl.php.net/package/expect).

Para usar essas funções, deve-se compilar o PHP com suporte a Expect
usando a opção de configuração
**--with-expect[=DIR]**.

Os usuários do Windows devem ativar o php\_expect.dll dentro
do php.ini para usar essas funções.
Uma DLL para esta
extensão PECL não está disponível no momento. Veja também a seção
[Compilando no Windows](install.windows.building.md).
