## Tipos de Recurso

Antes do PHP 8.0.0, esta extensão definia o tipo de recurso
`shmop` que é um identificador para um bloco de memória compartilhada.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
