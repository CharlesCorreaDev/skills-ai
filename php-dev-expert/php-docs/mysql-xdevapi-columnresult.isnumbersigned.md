ColumnResult::isNumberSigned — Verifica se é do tipo com sinal

### Descrição

public function **mysql\_xdevapi\ColumnResult::isNumberSigned**(): [int](language.types.integer.md)

Recupera informação da coluna e é instanciado pelo método
**mysql\_xdevapi\RowResult::getColumns()**.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

**`true`** se a coluna informada tem um tipo com sinal.
