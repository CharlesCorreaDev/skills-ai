# ReflectionProperty::getName

(PHP 5, PHP 7, PHP 8)

ReflectionProperty::getName — Obtém o nome da propriedade

### Descrição

public function **ReflectionProperty::getName**(): [string](language.types.string.md)

Obtém o nome da propriedade.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O nome da propriedade refletida.
