# ImagickDraw::getFont

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getFont — Retorna a fonte

### Descrição

public function **ImagickDraw::getFont**(): [string](language.types.string.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna uma string especificando a fonte usada ao fazer anotações com texto.

### Valor Retornado

Retorna uma string em caso de sucesso e falso se nenhuma fonte for definida.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
