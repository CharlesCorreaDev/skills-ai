# ImagickDraw::getClipRule

(PECL imagick 2, PECL imagick 3)

ImagickDraw::getClipRule — Retorna a regra atual de preenchimento do polígono

### Descrição

public function **ImagickDraw::getClipRule**(): [int](language.types.integer.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a regra atual de preenchimento do polígono para ser usada pelo caminho de recorte.

### Valor Retornado

Retorna uma constante [FILLRULE](imagick.constants.md#imagick.constants.fillrule)
(`imagick::FILLRULE_*`).
