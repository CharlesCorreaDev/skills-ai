## Dependências

É necessário obter e compilar bibliotecas clientes LDAP a partir de
[» OpenLDAP](https://www.openldap.org/software/download/) ou [» Bind9.net](http://www.bind9.net/download-openldap/) para compilar o PHP com
suporte LDAP.
Para PHP 5.6 ou posterior é necessário OpenLDAP 2.4 ou mais recente.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
