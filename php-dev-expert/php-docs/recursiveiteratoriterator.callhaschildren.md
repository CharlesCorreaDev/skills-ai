# RecursiveIteratorIterator::callHasChildren

(PHP 5 >= 5.1.0, PHP 7, PHP 8)

RecursiveIteratorIterator::callHasChildren — Tem filhos

### Descrição

public function **RecursiveIteratorIterator::callHasChildren**(): [bool](language.types.boolean.md)

Chamado para cada elemento para testar se ele possui filhos.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna se o elemento possui filhos.
