### Descrição

public function **GearmanTask::\_\_construct**()

Cria uma instância de [GearmanTask](class.gearmantask.md) representando uma tarefa a ser enviada a um servidor de trabalho.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado
