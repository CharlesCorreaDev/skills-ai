### Descrição

Estilo orientado a objetos

public function **tidy::getRelease**(): [string](language.types.string.md)

Estilo procedural

function **tidy\_get\_release**(): [string](language.types.string.md)

Obtém a data de lançamento da biblioteca Tidy.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string com a data de lançamento da biblioteca Tidy,
que pode ser `'unknown'`.
