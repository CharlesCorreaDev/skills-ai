# stats\_stat\_binomial\_coef

(PECL stats >= 1.0.0)

stats\_stat\_binomial\_coef — Retorna um coeficiente binomial

### Descrição

function **stats\_stat\_binomial\_coef**([int](language.types.integer.md) `$x`, [int](language.types.integer.md) `$n`): [float](language.types.float.md)

Retorna o coeficiente binomial de `n` elementos e `x` escolhas.

### Parâmetros

`x`
:   O número de escolhas do conjunto

`n`
:   O número de elementos no conjunto

### Valor Retornado

Retorna o coeficiente binomial
