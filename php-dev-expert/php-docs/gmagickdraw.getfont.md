# GmagickDraw::getfont

(PECL gmagick >= Unknown)

GmagickDraw::getfont — Retorna a fonte

### Descrição

public function **GmagickDraw::getfont**(): [mixed](language.types.mixed.md)

Retorna uma string especificando a fonte usada ao fazer anotações com texto.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string em caso de sucesso ou **`false`** se nenhuma fonte estiver definida.
