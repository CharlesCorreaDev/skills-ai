# SplFixedArray::valid

(PHP 5 >= 5.3.0, PHP 7)

SplFixedArray::valid — Verifica se o array contém mais elementos

### Descrição

public function **SplFixedArray::valid**(): [bool](language.types.boolean.md)

Verifica se o array contém mais elementos.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** se o array contém mais elementos, **`false`** caso contrário.
