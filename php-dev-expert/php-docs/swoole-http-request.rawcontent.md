# Swoole\Http\Request::rawcontent

(PECL swoole >= 1.9.0)

Swoole\Http\Request::rawcontent — Obtém o corpo HTTP POST bruto.

### Descrição

public function **Swoole\Http\Request::rawcontent**(): [string](language.types.string.md)

Este método é usado para os dados POST que não estão no formato `application/x-www-form-urlencoded`.

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

Esta função não possui parâmetros.
