# stomp\_version

(PECL stomp >= 0.1.0)

stomp\_version — Obtém a versão atual da extensão stomp

### Descrição

function **stomp\_version**(): [string](language.types.string.md)

Retorna uma string contendo a versão da extensão stomp atual.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a versão atual da extensão stomp.

### Examples

**Exemplo #1 Exemplo de **stomp\_version()****

```
<?php

var_dump(stomp_version());

?>
```

O exemplo acima produzirá
algo semelhante a:

```
string(5) "0.2.0"
```
