# Ev::sleep

(PECL ev >= 0.2.0)

Ev::sleep — Bloqueia o processo pelo número de segundos fornecido

### Descrição

final
public
static
function **Ev::sleep**(
[float](language.types.float.md) `$seconds`
): [void](language.types.void.md)

Bloqueia o processo pelo número de segundos fornecido.

### Parâmetros

`seconds`
:   Número fracionário de segundos

### Valor Retornado

Nenhum valor é retornado.
