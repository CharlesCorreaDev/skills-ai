# sodium\_crypto\_stream\_keygen

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_stream\_keygen — Gera uma chave sodium\_crypto\_stream aleatória.

### Descrição

function **sodium\_crypto\_stream\_keygen**(): [string](language.types.string.md)

Gera uma chave para uso com [sodium\_crypto\_stream()](function.sodium-crypto-stream.md) e [sodium\_crypto\_stream\_xor()](function.sodium-crypto-stream-xor.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Chave de criptografia (256-bit).
