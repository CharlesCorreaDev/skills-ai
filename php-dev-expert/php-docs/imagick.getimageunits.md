# Imagick::getImageUnits

(PECL imagick 2, PECL imagick 3)

Imagick::getImageUnits — Obtém as unidades de resolução da imagem

### Descrição

public function **Imagick::getImageUnits**(): [int](language.types.integer.md)

Obtém as unidades de resolução da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna as unidades de resolução da imagem.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
