# ImagickPixelIterator::getPreviousIteratorRow

(PECL imagick 2, PECL imagick 3)

ImagickPixelIterator::getPreviousIteratorRow — Retorna a linha anterior

### Descrição

public function **ImagickPixelIterator::getPreviousIteratorRow**(): [array](language.types.array.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Retorna a linha anterior como um array de varinhas de pixels do iterador de pixels.

### Valor Retornado

Retorna a linha anterior como um array de objetos ImagickPixelWand do
ImagickPixelIterator, lançando uma ImagickPixelIteratorException em caso de erro.
