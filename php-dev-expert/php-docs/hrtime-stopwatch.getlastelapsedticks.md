# HRTime\StopWatch::getLastElapsedTicks

(PECL hrtime >= 0.4.3)

HRTime\StopWatch::getLastElapsedTicks — Obtém os tiques decorridos para o último intervalo

### Descrição

public function **HRTime\StopWatch::getLastElapsedTicks**(): [int](language.types.integer.md)

Obtém os tiques decorridos para o último intervalo previamente fechado.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um [int](language.types.integer.md) indicando od tiques decorridos.
