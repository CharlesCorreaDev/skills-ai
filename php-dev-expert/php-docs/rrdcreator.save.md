# RRDCreator::save

(PECL rrd >= 0.9.0)

RRDCreator::save — Salva o banco de dados RRD em um arquivo

### Descrição

public function **RRDCreator::save**(): [bool](language.types.boolean.md)

Salva o banco de dados RRD em um arquivo, cujo nome é definido por [RRDCreator::\_\_construct()](rrdcreator.construct.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso ou **`false`** em caso de falha.
