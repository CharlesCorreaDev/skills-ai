# seaslog\_get\_author

(PECL seaslog >=1.0.0)

seaslog\_get\_author — Obtém o autor do SeasLog.

### Descrição

function **seaslog\_get\_author**(): [string](language.types.string.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o autor do SeasLog como uma string.

### Examples

**Exemplo #1 Exemplo de **seaslog\_get\_author()****

```
<?php

var_dump(seaslog_get_author());

?>
```

O exemplo acima produzirá
algo semelhante a:

```
string(29) "Chitao.Gao  [ neeke@php.net ]"
```
