# Imagick::nextImage

(PECL imagick 2, PECL imagick 3)

Imagick::nextImage — Passa para a próxima imagem

### Descrição

public function **Imagick::nextImage**(): [bool](language.types.boolean.md)

Associa a próxima imagem na lista de imagens a um objeto Imagick.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna **`true`** em caso de sucesso.
