# Gmagick::despeckleimage

(PECL gmagick >= Unknown)

Gmagick::despeckleimage — Reduz manchas em uma imagem

### Descrição

public function **Gmagick::despeckleimage**(): [Gmagick](class.gmagick.md)

Reduz o ruído pontilhado em uma imagem, preservando as bordas da imagem original.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O objeto [Gmagick](class.gmagick.md) sem manchas.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
