# Gmagick::getimagewhitepoint

(PECL gmagick >= Unknown)

Gmagick::getimagewhitepoint — Retorna o ponto branco da cromaticidade

### Descrição

public function **Gmagick::getimagewhitepoint**(): [array](language.types.array.md)

Retorna o ponto branco da cromaticidade como um array associativo com as chaves "x" e "y".

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o ponto branco da cromaticidade como um array associativo com as chaves "x" e "y".

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
