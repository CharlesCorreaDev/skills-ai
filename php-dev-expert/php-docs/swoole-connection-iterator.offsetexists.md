# Swoole\Connection\Iterator::offsetExists

(PECL swoole >= 1.9.0)

Swoole\Connection\Iterator::offsetExists — Verifica se o deslocamento existe.

### Descrição

public function **Swoole\Connection\Iterator::offsetExists**([int](language.types.integer.md) `$index`): [bool](language.types.boolean.md)

Verifica se o deslocamento existe.

### Parâmetros

`index`
:   O deslocamento sendo verificado.

### Valor Retornado

Retorna TRUE se o deslocamento existir, caso contrário, FALSE.
