# SplDoublyLinkedList::unserialize

(PHP 5 >= 5.4.0, PHP 7, PHP 8)

SplDoublyLinkedList::unserialize — Deserializa o armazenamento

### Descrição

public function **SplDoublyLinkedList::unserialize**([string](language.types.string.md) `$data`): [void](language.types.void.md)

Deserializa o armazenamento, a partir de [SplDoublyLinkedList::serialize()](spldoublylinkedlist.serialize.md).

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

### Parâmetros

`data`
:   A string serializada.

### Valor Retornado

Nenhum valor é retornado.
