# Gmagick::minifyimage

(PECL gmagick >= Unknown)

Gmagick::minifyimage — Reduz uma imagem à metade de seu tamanho

### Descrição

public function **Gmagick::minifyimage**(): [Gmagick](class.gmagick.md)

Um método conveniente que dimensiona uma imagem proporcionalmente à metade do seu tamanho original.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O objeto [Gmagick](class.gmagick.md).

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
