# Gmagick::getimagedispose

(PECL gmagick >= Unknown)

Gmagick::getimagedispose — Obtém o método de descarte de imagem

### Descrição

public function **Gmagick::getimagedispose**(): [int](language.types.integer.md)

Obtém o método de descarte de imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o método de descarte em caso de sucesso.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
