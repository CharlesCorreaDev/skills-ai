# trader\_exp

(PECL trader >= 0.2.0)

trader\_exp — Exponenciação Aritmética Vetorial

### Descrição

function **trader\_exp**([array](language.types.array.md) `$real`): [array](language.types.array.md)

Calcula **`e`** elevado à potência de cada valor em `real`. Retorna um array com os dados calculados.

### Parâmetros

`real`
:   Array de valores reais.

### Valor Retornado

Retorna um array com os dados calculados ou false em caso de falha.
