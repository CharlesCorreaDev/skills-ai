# asinh

(PHP 4 >= 4.1.0, PHP 5, PHP 7, PHP 8)

asinh — Arco seno hiperbólico

### Descrição

function **asinh**([float](language.types.float.md) `$num`): [float](language.types.float.md)

Retorna o arco seno hiperbólico de
`num`, isto é, o valor cujo
seno hiperbólico é `num`.

### Parâmetros

`num`
:   O argumento a processar

### Valor Retornado

O arco seno hiperbólico de `num`
