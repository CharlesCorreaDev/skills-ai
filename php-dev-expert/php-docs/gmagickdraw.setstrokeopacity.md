# GmagickDraw::setstrokeopacity

(PECL gmagick >= Unknown)

GmagickDraw::setstrokeopacity — Especifica a opacidade dos contornos dos objetos traçados

### Descrição

public function **GmagickDraw::setstrokeopacity**([float](language.types.float.md) `$stroke_opacity`): [GmagickDraw](class.gmagickdraw.md)

Especifica a opacidade dos contornos dos objetos traçados.

### Parâmetros

`stroke_opacity`
:   Opacidade do traço. O valor 1.0 é totalmente opaco.

### Valor Retornado

O objeto [GmagickDraw](class.gmagickdraw.md).
