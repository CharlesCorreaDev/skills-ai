# wkhtmltox\PDF\Converter::getVersion

wkhtmltox\PDF\Converter::getVersion — Determina a versão do conversor

### Descrição

public function **wkhtmltox\PDF\Converter::getVersion**(): [string](language.types.string.md)

Determina a versão do conversor conforme relatado por libwkhtmltox.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string de versão.
