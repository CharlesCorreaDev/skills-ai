# Constantes predefinidas

As constantes abaixo são definidas por esta extensão e
só estarão disponíveis quando a extensão tiver sido compilada no PHP
ou tiver sido carregada dinamicamente em tempo de execução.

**`CRYPT_SALT_LENGTH`** ([int](language.types.integer.md))

**`CRYPT_STD_DES`** [int](language.types.integer.md)
:   Indica se hashes baseados em DES padrão são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`CRYPT_EXT_DES`** [int](language.types.integer.md)
:   Indica se hashes baseados em DES estendido são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`CRYPT_MD5`** [int](language.types.integer.md)
:   Indica se hashes MD5 são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`CRYPT_BLOWFISH`** [int](language.types.integer.md)
:   Indica se hashes Blowfish são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`CRYPT_SHA256`** ([int](language.types.integer.md))
:   Indica se hashes SHA-256 hashes são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`CRYPT_SHA512`** ([int](language.types.integer.md))
:   Indica se hashes SHA-512 hashes são suportados em [crypt()](function.crypt.md). Sempre `1`.

**`HTML_SPECIALCHARS`** ([int](language.types.integer.md))

**`CHAR_MAX`** ([int](language.types.integer.md))

**`LC_CTYPE`** ([int](language.types.integer.md))
:   Classificação de caracteres e conversões afetadas por configuração de localidade.

**`LC_NUMERIC`** ([int](language.types.integer.md))
:   Separador de decimais afetado por configuração de localidade.

**`LC_TIME`** ([int](language.types.integer.md))
:   Formatação de data e horário afetada por configuração de localidade.

**`LC_COLLATE`** ([int](language.types.integer.md))
:   Comparação de strings afetada por configuração de localidade.

**`LC_MONETARY`** ([int](language.types.integer.md))
:   Formatação de moeda afetada por configuração de localidade.

**`LC_ALL`** ([int](language.types.integer.md))
:   Afeta todas as funções que qualquer das outras
    constantes **`LC_*`** afeta.

**`LC_MESSAGES`** ([int](language.types.integer.md))
:   Respostas do sistema afetadas por configuração de localidade.
