# Imagick::getImageSignature

(PECL imagick 2, PECL imagick 3)

Imagick::getImageSignature — Gera um resumo da mensagem SHA-256

### Descrição

public function **Imagick::getImageSignature**(): [string](language.types.string.md)

Gera um resumo da mensagem SHA-256 para o fluxo de pixels da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string contendo o hash SHA-256 do arquivo.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
