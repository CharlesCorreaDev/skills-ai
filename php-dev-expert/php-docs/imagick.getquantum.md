# Imagick::getQuantum

(PECL imagick 3 >= 3.3.0)

Imagick::getQuantum — Retorna o intervalo Quantum do Imagick

### Descrição

public static function **Imagick::getQuantum**(): [int](language.types.integer.md)

Retorna o intervalo Quantum do Imagick. Se HDRI estiver habilitado, o tipo será float, caso contrário, será int.

### Parâmetros

Esta função não possui parâmetros.
