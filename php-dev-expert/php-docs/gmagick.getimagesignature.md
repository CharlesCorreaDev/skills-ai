# Gmagick::getimagesignature

(PECL gmagick >= Unknown)

Gmagick::getimagesignature — Gera um resumo de mensagem SHA-256

### Descrição

public function **Gmagick::getimagesignature**(): [string](language.types.string.md)

Gera um resumo de mensagem SHA-256 para o fluxo de pixels da imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma string contendo o hash SHA-256 do arquivo.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
