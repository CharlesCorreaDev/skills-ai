# ZMQPoll::clear

ZMQPoll::clear — Limpa a lista de consulta

### Descrição

public function **ZMQPoll::clear**(): [ZMQPoll](class.zmqpoll.md)

### Parâmetros

Esta função não possui parâmetros.
