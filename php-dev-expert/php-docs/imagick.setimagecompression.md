# Imagick::setImageCompression

(PECL imagick 2, PECL imagick 3)

Imagick::setImageCompression — Define a compactação da imagem

### Descrição

public function **Imagick::setImageCompression**([int](language.types.integer.md) `$compression`): [bool](language.types.boolean.md)

### Parâmetros

`compression`
:   Uma das constantes **`COMPRESSION`**.

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
