# trader\_add

(PECL trader >= 0.2.0)

trader\_add — Adição Aritmética Vetorial

### Descrição

function **trader\_add**([array](language.types.array.md) `$real0`, [array](language.types.array.md) `$real1`): [array](language.types.array.md)

Calcula a adição vetorial de `real0` a
`real1` e retorna o vetor resultante.

### Parâmetros

`real0`
:   Array de valores reais.

`real1`
:   Array de valores reais.

### Valor Retornado

Retorna um array com os dados calculados ou false em caso de falha.
