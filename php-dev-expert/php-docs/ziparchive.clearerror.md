# ZipArchive::clearError

(PHP 8 >= 8.2.0, PECL zip >= 1.20.0)

ZipArchive::clearError — Limpa a mensagem de erro de status, mensagens do sistema e/ou do zip

### Descrição

public function **ZipArchive::clearError**(): [void](language.types.void.md)

Limpa a mensagem de erro de status, mensagens do sistema e/ou do zip.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Nenhum valor é retornado.
