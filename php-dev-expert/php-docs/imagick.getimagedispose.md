# Imagick::getImageDispose

(PECL imagick 2, PECL imagick 3)

Imagick::getImageDispose — Obtém o método de descarte de imagem

### Descrição

public function **Imagick::getImageDispose**(): [int](language.types.integer.md)

Obtém o método de descarte de imagem.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna o método de descarte em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
