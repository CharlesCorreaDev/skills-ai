# Pdo\Firebird::getApiVersion

(PHP 8 >= 8.4.0)

Pdo\Firebird::getApiVersion — Obtém a versão da API

### Descrição

public static function **Pdo\Firebird::getApiVersion**(): [int](language.types.integer.md)

Retorna a versão da API do Firebird como definida pela constante C
**`FB_API_VER`** em ibase.h.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna a API do FireBird como um [int](language.types.integer.md).
