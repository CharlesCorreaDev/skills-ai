# rrd\_info

(PECL rrd >= 0.9.0)

rrd\_info — Obtém informações sobre o arquivo rrd

### Descrição

function **rrd\_info**([string](language.types.string.md) `$filename`): [array](language.types.array.md)

Retorna informações sobre um arquivo de banco de dados RRD específico.

### Parâmetros

`file`
:   Nome do arquivo de banco de dados RRD.

### Valor Retornado

Array com informações sobre o arquivo RRD solicitado, ou **`false`** em caso de falha.
