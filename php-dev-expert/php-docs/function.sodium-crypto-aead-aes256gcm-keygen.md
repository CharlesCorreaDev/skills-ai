# sodium\_crypto\_aead\_aes256gcm\_keygen

(PHP 7 >= 7.2.0, PHP 8)

sodium\_crypto\_aead\_aes256gcm\_keygen — Gera uma chave AES-256-GCM aleatória

### Descrição

function **sodium\_crypto\_aead\_aes256gcm\_keygen**(): [string](language.types.string.md)

Gera uma chave aleatória para uso com [sodium\_crypto\_aead\_aes256gcm\_encrypt()](function.sodium-crypto-aead-aes256gcm-encrypt.md) e
[sodium\_crypto\_aead\_aes256gcm\_decrypt()](function.sodium-crypto-aead-aes256gcm-decrypt.md).

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna uma chave 256-bit aleatória.
