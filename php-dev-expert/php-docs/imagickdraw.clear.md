# ImagickDraw::clear

(PECL imagick 2, PECL imagick 3)

ImagickDraw::clear — Limpa o ImagickDraw

### Descrição

public function **ImagickDraw::clear**(): [bool](language.types.boolean.md)

**Aviso**

Esta função não
está documentada; apenas a lista de argumentos está disponível.

Limpa todos os comandos acumulados do objeto ImagickDraw e redefine as
configurações para o seu padrão.

Retorna um objeto [ImagickDraw](class.imagickdraw.md).
