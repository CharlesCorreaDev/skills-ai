# Imagick::setImageRedPrimary

(PECL imagick 2, PECL imagick 3)

public function **Imagick::setImageRedPrimary**([float](language.types.float.md) `$x`, [float](language.types.float.md) `$y`): [bool](language.types.boolean.md)

Define o ponto primário vermelho da cromaticidade da imagem.

### Parâmetros

`x`

`y`

### Valor Retornado
