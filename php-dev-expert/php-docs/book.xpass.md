# Xpass

# Introdução

Esta extensão fornece algoritmos de hash de senha usados ​​por distribuições Linux,
usando a biblioteca crypt estendida.

Também fornece funções adicionais de libxcrypt ausentes no núcleo do PHP.

- [Instalação/Configuração](xpass.setup.md)
  - [Dependências](xpass.requirements.md)
  - [Instalação via PECL](xpass.installation.md)
- [Constantes predefinidas](xpass.constants.md)
- [Funções de Xpass](ref.xpass.md)
  - [crypt\_checksalt](function.crypt-checksalt.md) — Valida uma string de configuração de criptografia
  - [crypt\_gensalt](function.crypt-gensalt.md) — Compila uma string para uso como argumento salt para crypt
  - [crypt\_preferred\_method](function.crypt-preferred-method.md) — Obtém o prefixo do método de hash preferido
