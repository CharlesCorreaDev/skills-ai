## Instalação

Para habilitar a extensão FFI, o PHP precisa ser configurado com
**--with-ffi**.

Usuários do Windows precisam incluir php\_ffi.dll no php.ini
para habilitar a extensão FFI.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
