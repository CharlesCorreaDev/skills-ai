# ZMQDevice::getIdleTimeout

(No version information available, might only be in Git)

ZMQDevice::getIdleTimeout — Obtém o tempo limite de inatividade

### Descrição

public function **ZMQDevice::getIdleTimeout**(): [ZMQDevice](class.zmqdevice.md)

Obtém o valor do tempo limite de inatividade do retorno. Adicionado na versão 1.0.0 da extensão ZMQ.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Esse método retorna o valor do tempo limite de inatividade do retorno.
