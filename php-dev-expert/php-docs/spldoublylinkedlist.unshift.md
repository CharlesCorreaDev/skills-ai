# SplDoublyLinkedList::unshift

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplDoublyLinkedList::unshift — Acrescenta um elemento ao início da lista duplamente encadeada

### Descrição

public function **SplDoublyLinkedList::unshift**([mixed](language.types.mixed.md) `$value`): [void](language.types.void.md)

Acrescenta `value` ao início da lista duplamente encadeada.

### Parâmetros

`value`
:   O valor a ser acrescentado.

### Valor Retornado

Nenhum valor é retornado.
