# Gmagick::enhanceimage

(PECL gmagick >= Unknown)

Gmagick::enhanceimage — Melhora a qualidade de uma imagem com ruído

### Descrição

public function **Gmagick::enhanceimage**(): [Gmagick](class.gmagick.md)

Aplica um filtro digital que melhora a qualidade de uma imagem com ruído.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

O objeto [Gmagick](class.gmagick.md) aprimorado.

### Erros/Exceções

Lança uma exceção
**GmagickException** em caso de erro.
