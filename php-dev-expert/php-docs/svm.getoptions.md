# SVM::getOptions

(PECL svm >= 0.1.0)

SVM::getOptions — Retorna os parâmetros de treinamento atuais

### Descrição

public function **SVM::getOptions**(): [array](language.types.array.md)

Recupera um array contendo os parâmetros de treinamento.
Os parâmetros serão indexados nas constantes SVM predefinidas.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um array de definições de configuração.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
