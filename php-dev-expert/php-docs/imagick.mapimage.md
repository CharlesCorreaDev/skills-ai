# Imagick::mapImage

(PECL imagick 2, PECL imagick 3)

Imagick::mapImage — Substitui as cores de uma imagem pela cor mais próxima de uma imagem de referência

**Aviso**

Esta função foi *DESCONTINUADA* a partir da Imagick 3.4.4. O uso desta função é fortemente desencorajado.

### Descrição

public function **Imagick::mapImage**([Imagick](class.imagick.md) `$map`, [bool](language.types.boolean.md) `$dither`): [bool](language.types.boolean.md)

### Parâmetros

`map`

`dither`

### Valor Retornado

Retorna **`true`** em caso de sucesso.

### Erros/Exceções

Lança uma exceção ImagickException em caso de erro.
