# Constantes predefinidas

As constantes abaixo são definidas por esta extensão e
só estarão disponíveis quando a extensão tiver sido compilada no PHP
ou tiver sido carregada dinamicamente em tempo de execução.

Aqui está uma lista de hashes que são atualmente suportadas por mhash. Se uma
hash não está listada aqui, mas é listada na documentação do mhash
como suportada, pode-se assumir seguramente que esta documentação está desatualizada.
