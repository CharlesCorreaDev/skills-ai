# Imagick::getImageSize

(PECL imagick 2, PECL imagick 3)

Imagick::getImageSize — Retorna o comprimento da imagem em bytes

**Aviso**

Esta função foi *DESCONTINUADA* a partir da Imagick 3.4.4. O uso desta função é fortemente desencorajado.

### Descrição

public function **Imagick::getImageSize**(): [int](language.types.integer.md)

Retorna o comprimento da imagem em bytes.
Função preterida em favor de [Imagick::getImageLength()](imagick.getimagelength.md)

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um int contendo o comprimento atual da imagem.
