a comunidade PHP. A melhor maneira é através das listas de discussão via e-mail.

**Existe alguma lista de discussão do PHP?**
:   É claro! Existem várias listas de discussão sobre vários assuntos.
    Uma listagem das principais listas de discussão pode ser encontrada na nossa
    [» listas de discussão por email](https://www.php.net/mailing-lists.php).

    A lista de discussão mais geral é `php-general`.
    Para participar, mande um e-mail em branco para
    [» php-general+subscribe@lists.php.net](mailto:php-general+subscribe@lists.php.net).
    Para sair da lista, mande um e-mail para [» php-general+unsubscribe@lists.php.net](mailto:php-general+unsubscribe@lists.php.net).

    Você pode se inscrever e sair das listas usando nossa interface
    web disponível em [» listas de discussão](https://www.php.net/mailing-lists.php),
    além de instruções incluídas no rodapé
    de cada e-mail da lista.

**Existem outras comunidades?**
:   Existem incontáveis comunidades voltadas ao PHP ao redor do mundo. Nós
    temos links, para algumas delas (e informação de como aprender mais) em nossa página
    de [» Suporte](https://www.php.net/support.php)

**Posso iniciar minha própria lista de discussões de PHP?**
:   Com certeza! Aliás, nós não só permitimos como encorajamos você a iniciar uma lista de discussões!
    Ajudar os outros dividindo seu conhecimento e experiência com o PHP
    amplia o crescimento da comunidade e o desenvolvimento global do PHP,
    além da própria linguagem.

**Ajuda! Não consigo me inscrever ou sair de nenhuma das listas de discussão!**
:   A causa mais comum para as pessoas terem dificuldades em sair de
    nossas listas de discussão é por causa do uso de e-mails encaminhados. Por exemplo, se
    seu e-mail for `elephpant@example.com`, mas você
    se inscreveu na lista de discussão com o e-mail
    `php-lists@example.com` que encaminha para
    `elephpant@example.com`, tentar remover da lista o e-mail
    `elephpant@example.com` não vai funcionar pois este e-mail
    não é conhecido nos nossos sistemas. Ao invés disso, você vai precisar pedir para remover da lista
    o e-mail para o qual as mensagens estão sendo enviadas, enviando um e-mail a partir
    dele - neste exemplo,
    `php-lists@example.com`.

**Existe um histórico das listas de discussão em algum lugar?**
:   Sim, você encontrará uma lista de sites com o histórico na
    página de [» listas de email](https://www.php.net/mailing-lists.php).
    Você também vai encontrar dezenas de arquivos e/ou referências
    para nossas listas de discussões usando seu mecanismo de busca preferido
    ao procurar por "php mailing list archives".

    Os artigos da lista de discussão também são arquivados como
    mensagens de notícia. Você pode acessar o servidor de notícias em [» news://news.php.net/](news://news.php.net/)
    com um cliente de notícias. Também existe uma interface web
    experimental para o servidor de notícias em [» http://news.php.net/](http://news.php.net/)

**O que posso perguntar na lista de discussão?**
:   Uma vez que o PHP está crescendo em popularidade todo dia, o tráfego
    na lista de discussão php-general cresceu e até agora a
    lista recebe entre 75 a 200 mensagens por dia. Por isso é do
    interesse de todos que você use a lista como último recurso
    quando você procurou em todos os outros lugares.

    Antes de postar em uma lista verifique nessa FAQ e no
    manual se não consegue encontrar a informação aqui. Se não
    encontrar então tente os arquivos das listas (veja acima).
    Se está tendo problemas instalando ou configurando o PHP primeiro
    leia toda a documentação incluída e os README's. Se ainda não
    conseguir encontrar a informação que lhe ajude, você é
    bem vindo a utilizar a lista apropriada.

    Para garantir que você receba as melhores respostas (e para reduzir a
    probabilidade de frustrar seus colegas desenvolvedores) envie sua pergunta para
    a lista apropriada. Por exemplo, se você está
    tendo dificuldades para instalar PHP, você deve enviar sua pergunta para a lista de
    discussão `php-install`. Uma ressalva: algumas listas
    têm nomes semelhantes mas usos completamente diferentes; uma pergunta sobre
    os scripts PHP no Windows deve ser direcionado para a lista de usuários do Windows
    PHP, *not* para a lista do Windows Internals.

    Antes de perguntar, você deve ler o arquivo
    [» Como Fazer Perguntas de Maneira
    Inteligente](http://www.catb.org/~esr/faqs/smart-questions.html) que é uma boa idéia para todo mundo.

**Que informação devo incluir quando faço perguntas na lista?**
:   Mensagens como "Não consigo colocar o PHP para funcionar! Me ajude! O que está
    errado?" são inúteis. Se você tiver problemas
    fazendo o PHP funcionar, você deve incluir que sistema operacional
    você está usando, qual a versão do PHP você está tentando instalar,
    como você obteve (pré-compilado, CVS, RPM e por aí vai), o que você fez
    até agora, onde ficou preso e a mensagem de erro exata.

    Isso vale para qualquer outro problema também. Você deve incluir informações
    sobre o que você fez, o que você está tentando fazer e quaisquer mensagens de erro
    encontradas no processo. Se você tiver problemas com nosso código
    fonte, você precisa incluir a parte do código que não está funcionando,
    indicando a linha que apresenta o problema através do posicionamento de
    um comentário de código. Não inclua mais código
    que o necessário! Isso torna a mensagem difícil de ler e muitas
    pessoas podem simplesmente ignorar ela por isso. Se você não
    tiver certeza sobre quanta informação incluir na mensagem, é melhor
    incluir muito do que pouco.

    Outra coisa importante a lembrar é resumir o problema no
    assunto da mensagem. Um assunto como "SOCCOOORRROO!!!" ou "Qual é o
    problema aqui" será ignorada pela maioria dos leitores.

    E finalmente, você é encorajado a ler o artigo sobre
    [» Como Fazer Perguntas de
    Maneira Inteligente](http://www.catb.org/~esr/faqs/smart-questions.html) já que irá ser de grande ajuda para todo mundo,
    especialmente você.
