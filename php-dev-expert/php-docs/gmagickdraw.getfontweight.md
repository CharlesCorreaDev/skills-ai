# GmagickDraw::getfontweight

(PECL gmagick >= Unknown)

GmagickDraw::getfontweight — Retorna o peso da fonte

### Descrição

public function **GmagickDraw::getfontweight**(): [int](language.types.integer.md)

Retorna a espessura da fonte usada ao fazer anotações com texto.

### Parâmetros

Esta função não possui parâmetros.

### Valor Retornado

Retorna um inteiro em caso de sucesso ou 0 se nenhum peso for definido.
