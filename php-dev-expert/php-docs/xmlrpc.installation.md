## Instalação

Suporte a XML-RPC no PHP não é habilitado por padrão. Deve-se usar
a opção de configuração **--with-xmlrpc[=DIR]**
ao compilar o PHP para habilitar o suporte a XML-RPC.

`↑` and `↓` to navigate •
`Enter` to select •
`Esc` to close • `/` to open
