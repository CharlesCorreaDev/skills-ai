# Contributing

[Edit this page](https://github.com/symfony/symfony-docs/edit/8.1/contributing/index.rst)

Symfony is an open source, community-driven project, and there are many ways to contribute:

- [Report a Bug](current__contributing__code.md#reporting-a-bug) you found (no setup needed)
- [Review and Triage](current__contributing__reviews.md) issues and pull
  requests to help move them forward (no coding needed)
- [Contribute Code](current__contributing__code.md) (bug fixes and features)
- [Contribute Docs](current__contributing__doc.md) to improve the documentation
  (small fixes can be done online, without installing anything)
- [Contribute Translations](current__contributing__translation.md) to translate the
  Symfony error and validation messages

One special case: if you found a **security issue**, don't report it publicly.
Follow the [security procedure](current__contributing__code__security.md) instead.

New to contributing? The `#contribs` and `#mentoring` channels on the
[Symfony Slack](https://symfony.com/slack-invite) are there to help.
