#### get\_id()

Returns the drivers unique id. This can be used to identify the driver, or to select a specific driver instance.

|  |  |
| --- | --- |
| Static | No |
| Parameters | None |
| Returns | The drivers id string. |
| Example | ``` // returns 'simpleacl' $id = Auth::acl()->get_id(); ``` |
