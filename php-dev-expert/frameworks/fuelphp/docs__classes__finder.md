#### forge($paths = array())

The **forge** method returns a new finder object.

|  |  |
| --- | --- |
| Static | Yes |
| Parameters | | Param | Default | Description | | --- | --- | --- | | `$paths` | ``` array() ``` | Array of paths to initialise this finder instance with. | |
| Returns | Finder Object |
| Example | ``` $array = array(APPPATH, COREPATH); $finder = Finder::forge($array)); ``` |
