## markdown

### Introduction

“Markdown” is two things: a plain text markup syntax, and a software tool that converts the plain text markup to HTML for publishing on the web.

The Markdown syntax allows you to write text naturally and format it without using HTML tags. More importantly: in Markdown format, your text
stays enjoyable to read for a human being, and this is true enough that it makes a Markdown document publishable as-is, as plain text.
If you are using text-formatted email, you already know some part of the syntax.

### Documentation

You can find the original markdown documentation [here](http://michelf.com/projects/php-markdown/).

### FuelPHP Usage

The markdown vendor package is used by FuelPHP in the Markdown class, to render strings in markdown syntax.

### Application Usage

You can access markdown through the [Markdown::parse()](docs__classes__markdown.md#/method_parse) method.
