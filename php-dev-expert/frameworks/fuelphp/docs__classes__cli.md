#### beep($num = 1)

The **beep** method fires a system beep on the computer running the command.

|  |  |
| --- | --- |
| Static | Yes |
| Parameters | | Param | Default | Description | | --- | --- | --- | | `$num` | *1* | Number of beeps. | |
| Returns | void |
| Example | ``` Cli::beep(25); ``` |
