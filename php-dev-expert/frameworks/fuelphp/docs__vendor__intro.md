## Third Party Vendor packages

### Introduction

The FuelPHP core comes with several vendor packages pre-installed. Vendor packages are libraries from external parties that
are integrated into the FuelPHP core.

- [PHPQuickProfiler](docs__vendor__phpquickprofiler.md)
