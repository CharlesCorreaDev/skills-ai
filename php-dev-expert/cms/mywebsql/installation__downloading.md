# Downloading the package

To download the latest version of MyWebSQL, use the link below to sourceforge.net website.

<http://sourceforge.net/projects/mywebsql/files/>

If you are using an older version of your favorite browser and the application does not work properly, try downloading older packages of the software from the sourceforge download page.

MyWebSQL can also be downloaded from other mirror download sites. If the above link does not work for you, try downloading from one the links provided on the [Download page](https://samnan.github.io/downloads)
