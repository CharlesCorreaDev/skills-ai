This page lists new features and improvements for teachers.

## Course page and navigation

### Dark mode

If your administrator has turned it on, you can switch between Light, Dark and System modes from the navigation bar for a more comfortable reading experience.

![Dark mode in Boost theme](/503/en/images_en/thumb/2/21/5.3_MDL-68037_Boost_theme_dark_mode_settings%281%29.png/800px-5.3_MDL-68037_Boost_theme_dark_mode_settings%281%29.png)

Dark mode in Boost theme

See [Setting Dark mode](Boost_theme.md#Set_Dark_mode_in_Boost_theme "Boost theme") in Boost theme.

### Clearer course page layout: sections, activities, Collapse all

The course page has a clear hierarchy for sections and activities in a centre-aligned layout that is easy to read. You can use Collapse all to scan long courses quickly.

See [Parts of a course](Course_homepage.md#Parts_of_a_course "Course homepage") in Course homepage.

### Course linear navigation

You can use the **Previous** and **Next** buttons at the bottom of each activity and resource page to move through a course in order. Linear navigation is on by default in the Custom sections and Weekly sections formats.

![Linear navigation for courses with Previous and Next buttons](/503/en/images_en/thumb/0/02/5.3_MDL-89406_linear_navigation_previous_next_EN%281%29.png/800px-5.3_MDL-89406_linear_navigation_previous_next_EN%281%29.png)

Linear navigation for courses with Previous and Next buttons

See [Previous and Next navigation](Course_linear_navigation.md#Previous_and_Next_navigation "Course linear navigation") in Course linear navigation.

### Global search matches the start of words

You can search using the start of a word, so searching for ‘Veg’ finds both ‘Veg’ and ‘Vegetarian’. The search field is also always visible in the top navigation bar.

![Global search results for 'Veg', with 'vegan and vegetarian' highlighted in a course description](/503/en/images_en/thumb/c/c4/MDL70225simpleglobalsearch%281%29.png/800px-MDL70225simpleglobalsearch%281%29.png)

Partial word search and prefix match support in Global search

See [Partial word matching](Global_search.md#Partial_word_matching "Global search") in Global search.

## Learning outcomes

### New Learning outcomes page

You can see every learning outcome enabled for your course, and the activities linked to each one, on the Learning outcomes page under Course > More.

![Manage learning outcomes page](/503/en/images_en/thumb/9/99/5.3_MDL-89334_managelearningoutcomes_v2_EN.png/800px-5.3_MDL-89334_managelearningoutcomes_v2_EN.png)

Manage learning outcomes page

See [Learning outcomes page](Learning_outcomes.md#Learning_outcomes_page "Learning outcomes") in Learning outcomes.

### Learning outcomes without a scale, including backup, restore and import

You can create learning outcomes without a scale to describe a skill or piece of knowledge without grading it. These outcomes are kept when you back up, restore, import or export a course.

![Learning outcomes section of an activity's settings, listing outcomes with and without a scale](/503/en/images_en/thumb/f/fa/5.3_MDL-88881_makescalesoptional_EN.png/800px-5.3_MDL-88881_makescalesoptional_EN.png)

Optional scale for learning outcomes

See [Optional scales](Learning_outcomes.md#Optional_scales_for_learning_outcomes "Learning outcomes") in Learning outcomes.

## Assignment

### Per-marker feedback and optional markers

In assignments with multiple markers, each marker can give their own feedback alongside the overall feedback, and students can see both. You can also add optional markers for submissions that need an extra opinion.

![Assignment Submissions page with the optional Marker 3 slot enabled and a marker allocated for each student](/503/en/images_en/thumb/5/5c/5.3_MDL-86007_teachersubmissionspermarker_EN.png/800px-5.3_MDL-86007_teachersubmissionspermarker_EN.png)

Assignment Submissions page with the optional Marker 3 slot enabled and a marker allocated for each student

See [Feedback from each marker](Using_multiple_markers.md#Feedback_from_each_marker "Using multiple markers") in Using multiple markers.

## Quiz

### Due date

You can set a due date for a quiz alongside the open and close dates. Students can still attempt the quiz after the due date, and their attempt is marked as overdue until the quiz closes.

![Quiz page showing its Opened, Due and Closes dates, with the message Quiz is overdue](/503/en/images_en/thumb/5/50/5.3_MDL-82521_quizduedate_v2_EN.png/800px-5.3_MDL-82521_quizduedate_v2_EN.png)

Due date for quiz

See [Due date](Quiz_settings.md#Due_date_for_quiz_activity "Quiz settings") in Quiz settings.

### New filters in the Grades and Responses reports

You can search for users, select groups and filter by name in the quiz Grades and Responses reports, making it quicker to find students in large courses.

![New filters in the Quiz reports](/503/en/images_en/thumb/e/e6/5.3_MDL-81096_quiz_reports_new_filters%281%29.png/800px-5.3_MDL-81096_quiz_reports_new_filters%281%29.png)

New filters in the Quiz reports

See [New filters](Quiz_reports.md#New_filters_in_Quiz_reports_UI "Quiz reports") in Quiz reports.

### Safe Exam Browser: allowed displays and screen capture

In the Safe Exam Browser, you can allow up to three displays and allow browser access to the screen, for example when using a proctoring tool.

![Safe Exam Browser (SEB) manual-configuration add-ons](/503/en/images_en/thumb/0/03/5.3_MDL88998_MDL88440_SEB_addons.png/800px-5.3_MDL88998_MDL88440_SEB_addons.png)

Safe Exam Browser (SEB) manual-configuration add-ons

See [Manual-configuration add-ons](Safe_Exam_Browser.md#Manual-configuration_add-ons "Safe Exam Browser") in Safe Exam Browser.

## Question bank

### Export selected questions as Moodle XML

Select multiple questions in the Question bank and export them together as a single Moodle XML file.

![Select multiple questions and export as Moodle XML](/503/en/images_en/thumb/7/75/5.3_MDL89051exportasMoodleXMLnewUI%281%29.png/800px-5.3_MDL89051exportasMoodleXMLnewUI%281%29.png)

Select multiple questions and export as Moodle XML

See [Exporting selected questions in Moodle XML](Export_questions.md#Export_selected_questions_in_Moodle_XML_format "Export questions") in Export questions.

### Delete questions when deleting a category

When you delete a question category, you can delete its questions at the same time. Questions used in a quiz are protected and must be moved to another category.

![Move questions before deleting category page, where you choose which questions to keep before the rest are deleted with the category](/503/en/images_en/thumb/e/ee/MDL61427movequestionsbeforedeletingcategory.png/800px-MDL61427movequestionsbeforedeletingcategory.png)

Option to move questions while deleting a category

See [Deleting questions with a category](Question_categories.md#Option_to_delete_questions_while_deleting_a_category "Question categories") in Question categories.

### Bulk actions bar and delete confirmation

Move or delete selected questions from the bulk actions bar at the bottom of the page, and confirm deletions in a dialogue without leaving the Question bank.

![Sticky footer icon bar for bulk actions](/503/en/images_en/thumb/3/3f/5.3_MDL-73051_Questionbank_sticky_footer_bulk_actions_EN%281%29.png/800px-5.3_MDL-73051_Questionbank_sticky_footer_bulk_actions_EN%281%29.png)

Sticky footer icon bar for bulk actions

See [UI improvements](Question_banks.md#UI_Improvements_in_Moodle_5.3 "Question banks") in Question banks.

## Reports and participants

### Course-level AI usage report

You can find out how students in your course use AI in the AI usage report, under More > Reports > AI usage. Students can view their own AI usage from their profile.

See [Course-level AI usage report](AI_usage_report.md#Course-level_AI_usage_report "AI usage report") in AI usage report.

### Download options for the Course completion report

Download the Course completion report, with your current filters applied, as CSV, Excel, PDF and other formats.

![Download widget for course completion report](/503/en/images_en/thumb/2/22/MDL88575coursecompletionreportdownloadwidget%281%29.png/800px-MDL88575coursecompletionreportdownloadwidget%281%29.png)

Download widget for Course completion report

See [Download widget](Course_completion_report.md#Download_widget_for_course_completion_report "Course completion report") in Course completion report.

### Reason shown for Not current status

On the Participants page, you can select the information icon next to a ‘Not current’ status to see why: for example, the enrolment has not started, has expired, or uses a disabled enrolment plugin.

![“Not current” enrolment status with reason](/503/en/images_en/thumb/c/ce/5.3_MDL64249notcurrent-enrollmentnotstarted%281%29.png/800px-5.3_MDL64249notcurrent-enrollmentnotstarted%281%29.png)

“Not current” enrolment status with reason

See [‘Not current’ status](Participants.md#Reason_for_%22Not_current%22_status_included_in_Participants_tab "Participants") in Participants.

### Accordion and list styles

Add collapsible Accordion sections and choose from more List styles in the TinyMCE editor.

![TinyMCE editor with three collapsible accordion sections, each containing a lettered or numbered list](/503/en/images_en/thumb/6/6c/5.3_MDL-88618_accordionliststyles_v2_EN.png/800px-5.3_MDL-88618_accordionliststyles_v2_EN.png)

Accordion sections and list styles in the TinyMCE editor

See [Accordion and list styles](TinyMCE_editor.md#Insert_Accordion_and_List_Styles_(advlist) "TinyMCE editor") in TinyMCE editor.

### Paste Markdown, with TinyMCE Premium

With a TinyMCE Premium subscription, you can paste Markdown text and it is converted to formatted content automatically.

See [Markdown plugin](TinyMCE_editor.md#Markdown_plugin "TinyMCE editor") in TinyMCE editor.
