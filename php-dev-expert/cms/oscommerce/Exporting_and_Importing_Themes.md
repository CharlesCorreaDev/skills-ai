# Exporting and Importing Themes

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to create theme groups, export an existing theme and how to import a theme into your osCommerce system.

Start with the video to get a quick introduction to the feature.

**If you need additional details, the manual below provides step-by-step instructions.**

**1) Access the Theme Management Section**

1. Access the **admin area** of your website.
2. Click on **Design and CMS**.
3. Open the **Themes** tab.
4. Locate the **required theme** in the list.

**2) Exporting a Theme**

1. Within the selected theme, click on the **Backups** button.

[![1 Export Theme.jpg](/wiki/images/thumb/6/6c/1_Export_Theme.jpg/800px-1_Export_Theme.jpg)](https://www.oscommerce.com/wiki/File:1_Export_Theme.jpg)

2. Click **Export** to generate the theme backup file.

3. Select the required files.

4. Click **Save** to download.

[![2 Click Export to create Theme backup.jpg](/wiki/images/thumb/a/a1/2_Click_Export_to_create_Theme_backup.jpg/799px-2_Click_Export_to_create_Theme_backup.jpg)](https://www.oscommerce.com/wiki/File:2_Click_Export_to_create_Theme_backup.jpg)

**3) Importing a Theme**

1. Click on the **Add Theme** button.
2. In the pop-up window, enter a theme title.
3. Click **Upload** or **drop file** right to the popup window to upload the **theme ZIP file** from your local device.
4. Wait for the import process to complete.

[![4 Import Theme.jpg](/wiki/images/thumb/d/d4/4_Import_Theme.jpg/800px-4_Import_Theme.jpg)](https://www.oscommerce.com/wiki/File:4_Import_Theme.jpg)

**4) Creating a Theme**

1. Return to the Themes page.

2. Click **Create theme**.

[![5 Create Theme.jpg](/wiki/images/thumb/a/ae/5_Create_Theme.jpg/800px-5_Create_Theme.jpg)](https://www.oscommerce.com/wiki/File:5_Create_Theme.jpg)

3. On the **Create theme** page, enter the theme name.

4. Click **Continue**.

[![5 A Create Theme.jpg](/wiki/images/thumb/b/b2/5_A_Create_Theme.jpg/800px-5_A_Create_Theme.jpg)](https://www.oscommerce.com/wiki/File:5_A_Create_Theme.jpg)

5. Start creating a new theme using available options and tools.

[![5 B Create Theme.jpg](/wiki/images/thumb/8/89/5_B_Create_Theme.jpg/801px-5_B_Create_Theme.jpg)](https://www.oscommerce.com/wiki/File:5_B_Create_Theme.jpg)

**5) Creating a Theme Group**

1. Return to the Themes page.

2. Click **Add theme group**.

3. In the popup window, enter a group name and click **Ok**.

[![6 Add Theme Group.jpg](/wiki/images/thumb/b/be/6_Add_Theme_Group.jpg/799px-6_Add_Theme_Group.jpg)](https://www.oscommerce.com/wiki/File:6_Add_Theme_Group.jpg)

4. The new group folder will appear on the Themes page.

5 Click **Open** to start customizing the group.

[![6 A Add Theme Group.jpg](/wiki/images/thumb/0/03/6_A_Add_Theme_Group.jpg/800px-6_A_Add_Theme_Group.jpg)](https://www.oscommerce.com/wiki/File:6_A_Add_Theme_Group.jpg)

6. Select the edit mode:

- Basic
- Advanced
- Expert

7. Import or create theme for this theme group.

[![7 Working with Theme Group.jpg](/wiki/images/thumb/b/bf/7_Working_with_Theme_Group.jpg/801px-7_Working_with_Theme_Group.jpg)](https://www.oscommerce.com/wiki/File:7_Working_with_Theme_Group.jpg)

Your work with theme groups, as well as exporting and importing themes, is now complete. You may proceed with further design or customization.
