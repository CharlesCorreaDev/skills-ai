# Managing Pages

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to manage website pages in the admin area. You will learn how to create, edit, assign, and configure pages, including SEO, design templates, and publication settings.

Watch the video first—it gives you the basics.

Read the manual below for more detailed guidance.

**1) Access Pages Management**

1. Log in to your website’s **Admin area**.
2. Navigate to **Design and CMS → Pages**.
3. From this tab, you can:
   - **Add a new page**
   - **Edit an existing page**
   - **Delete a page**

**2) Manage Pages from the Listing Page**

On the **Pages** listing page, you can:

- Search for pages by **name**.
- Enable/disable pages.
- Delete selected pages.
- Assign pages to **sales channels** directly.

[![1068 listing page.jpg](/wiki/images/thumb/a/af/1068_listing_page.jpg/800px-1068_listing_page.jpg)](https://www.oscommerce.com/wiki/File:1068_listing_page.jpg)

**3) Assign Pages to Sales Channels**

When adding or editing a page:

1. Open the **Sales Channels** tab.
2. Select the required sales channels to assign the page.

[![1069 Sales channel.jpg](/wiki/images/thumb/8/83/1069_Sales_channel.jpg/800px-1069_Sales_channel.jpg)](https://www.oscommerce.com/wiki/File:1069_Sales_channel.jpg)

**4) Configure Main Details**

Open the **Main Details** tab to configure basic page information:

- Set **Page title**.
- Set **Name in the menu**.
- Add a **Description**, which can include:
  - Page links
  - Product links
  - Category links
  - Brand links
  - Common site links
- Add a **Short description**.
- Set **Keywords**.

[![1070 Main det 1.jpg](/wiki/images/thumb/c/cc/1070_Main_det_1.jpg/800px-1070_Main_det_1.jpg)](https://www.oscommerce.com/wiki/File:1070_Main_det_1.jpg)

[![1071 Main det 2.jpg](/wiki/images/thumb/1/1c/1071_Main_det_2.jpg/800px-1071_Main_det_2.jpg)](https://www.oscommerce.com/wiki/File:1071_Main_det_2.jpg)

**5) Configure SEO**

Open the **SEO** tab to improve page search engine visibility:

- Set **SEO page URL**.
- Define **Page title**.
- Enter a **META description**.
- Add **H tags**:
  - H1 (one per page)
  - H2 (multiple allowed)
  - H3 (multiple allowed)

[![1072 SEO.jpg](/wiki/images/thumb/9/9e/1072_SEO.jpg/800px-1072_SEO.jpg)](https://www.oscommerce.com/wiki/File:1072_SEO.jpg)

**6) Configure Template**

Open the **Template** tab to:

- Choose a **design template** for each sales channel.

[![1073 Template.jpg](/wiki/images/thumb/4/49/1073_Template.jpg/800px-1073_Template.jpg)](https://www.oscommerce.com/wiki/File:1073_Template.jpg)

**7) Manage Page Images**

Open the **Image** tab to:

- Upload images from your **computer** or **gallery**.
- Configure an **Image Map**.

[![1074 Image.jpg](/wiki/images/thumb/5/58/1074_Image.jpg/800px-1074_Image.jpg)](https://www.oscommerce.com/wiki/File:1074_Image.jpg)

**8) Configure Page Settings**

Open the **Settings** tab to manage page visibility and publication options:

- Set **Published** or **Draft** status.
- Set **Published date** or **Draft date**.
- View or update **Date added**.
- Use toggles to:
  - Enable/disable **Catalog Pages**.
  - **Hide page**.
  - Exclude page from **XML sitemap**.

[![1075 Settings.jpg](/wiki/images/thumb/3/3b/1075_Settings.jpg/800px-1075_Settings.jpg)](https://www.oscommerce.com/wiki/File:1075_Settings.jpg)
