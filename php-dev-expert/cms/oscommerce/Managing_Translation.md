# Managing Translation

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to manage translation keys in your website’s admin area.

Watch the video for a brief overview of this functionality.

The manual below provides step-by-step instructions.

**1)** **Access the Admin Area**

Log in to the admin area of your website, then navigate to **Design and CMS → Translation**.

**2) Using Search and Filters**

Under the **Translation** tab, you can manage and edit translation keys.

To find specific entries, use filters by:

- **Category (Entity)**
- **Key**
- **Value**
- **Language**

You can also apply additional filters:

- **Case sensitive**
- **Skip Admin and Configuration keys**
- **Display not translated only**
- **Display not checked only**

It is also possible to choose which columns appear in the listing and to use the **Quick Search** option.

[![1076 Filter.jpg](/wiki/images/thumb/a/a8/1076_Filter.jpg/800px-1076_Filter.jpg)](https://www.oscommerce.com/wiki/File:1076_Filter.jpg)

**3)** **Managing Translation Keys**

You can perform the following actions using the buttons provided:

- **Export keys**
- **Import keys**
- **Add new keys**
- **Edit**, **delete**, or **change** existing keys

[![1077 Edit.jpg](/wiki/images/thumb/9/99/1077_Edit.jpg/800px-1077_Edit.jpg)](https://www.oscommerce.com/wiki/File:1077_Edit.jpg)

**4)** **Adding or Editing Keys**

When adding or editing a translation key, the following options are available:

- **Mark as translated**
- **Mark as checked**
- **Move to the Next Untranslated Key**
- **Batch replace all identical values with the new value**
- **Batch replace all identical keys with the new value**

[![1078 Edit2.jpg](/wiki/images/thumb/c/c8/1078_Edit2.jpg/800px-1078_Edit2.jpg)](https://www.oscommerce.com/wiki/File:1078_Edit2.jpg)
