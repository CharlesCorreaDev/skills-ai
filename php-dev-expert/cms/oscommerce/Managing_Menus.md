# Managing Menus

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to create and manage menus in your website’s admin area. You will learn how to add menu items, arrange their order, assign categories, brands, or pages, and configure additional settings for each item.

Begin with the video to get an introduction.

Consult the manual for complete details.

**1) Access Menus**

1. Log in to your website’s **Admin area**.
2. Go to **Design → CMS → Menus**.

**2) Create and Manage Menus**

- To **create a new menu**, click **Add Menu**.
- To **enable or disable Show Tips**, use the switch.

- To **select a front end**, click on the corresponding tab.

**3) Work with Available Pages**

In the **Available pages** section, you can:

- Use the **Search tool**.
- Click **Expand all** or **Collapse all**.
- View **Pages, Categories, Brands**, and sub-levels (click the **+** icon to expand subcategories or sub-subcategories).

[![](/wiki/images/thumb/6/6c/1225_View_Pages.jpg/800px-1225_View_Pages.jpg)](https://www.oscommerce.com/wiki/File:1225_View_Pages.jpg)

- Scroll up and down with the scroller.
- Drag items with the **hand tool** to move them up or down.

[![1225a Scroller.jpg](/wiki/images/thumb/1/10/1225a_Scroller.jpg/800px-1225a_Scroller.jpg)](https://www.oscommerce.com/wiki/File:1225a_Scroller.jpg)

**4) Menu Section Options**

- Select menus from the **drop-down list**.
- **Copy** a menu from another sales channel.

- **Import/Export** menu data.

[![1226 Menu section.jpg](/wiki/images/thumb/b/b0/1226_Menu_section.jpg/801px-1226_Menu_section.jpg)](https://www.oscommerce.com/wiki/File:1226_Menu_section.jpg)

**5) Edit Menu Structure**

**Reorder items** by dragging and dropping:

- Arrange items in the right sequence.

[![1227 Right order.jpg](/wiki/images/thumb/4/40/1227_Right_order.jpg/800px-1227_Right_order.jpg)](https://www.oscommerce.com/wiki/File:1227_Right_order.jpg)

- Set up **parent/child** relationships.

[![1228 Parent Child order.jpg](/wiki/images/thumb/0/0b/1228_Parent_Child_order.jpg/801px-1228_Parent_Child_order.jpg)](https://www.oscommerce.com/wiki/File:1228_Parent_Child_order.jpg)

**6) Add Menu Items**

**Categories**

- Add a single category (or subcategory).
- Or select **All categories** to create an automatically updated category tree.

[![1229 All Categories.jpg](/wiki/images/thumb/c/cf/1229_All_Categories.jpg/800px-1229_All_Categories.jpg)](https://www.oscommerce.com/wiki/File:1229_All_Categories.jpg)

**Brands**

- Add a single brand.
- Or select **All brands** to create an automatically updated list of all brands.

**Pages**

Expand using the **+** icon and choose:

- Default pages
- Info pages
- Account pages

**Other options**

- Add **Components** (from existing ones).
- Add **Custom link**.
- Add **Custom catalog link**.

- Drag items with the **hand tool** to place them.

[![1230 Pages and Links.jpg](/wiki/images/thumb/6/6d/1230_Pages_and_Links.jpg/801px-1230_Pages_and_Links.jpg)](https://www.oscommerce.com/wiki/File:1230_Pages_and_Links.jpg)

**7) Edit or Delete Menu Items**

- To **edit**, click the **Pencil icon**.

- To **delete**, click the **Trash bin icon**.

**8) Edit Menu Item Settings**

While editing a menu item, you can:

- *Change the **title**.*
- *Set **Open in new tab** flag.*
- *Set **Nofollow link** for SEO.*
- *Assign a **CSS class**.*
- *Set a **link** (for Custom Link item type only).*

[![1231 Menu item edit.jpg](/wiki/images/thumb/1/1d/1231_Menu_item_edit.jpg/801px-1231_Menu_item_edit.jpg)](https://www.oscommerce.com/wiki/File:1231_Menu_item_edit.jpg)
