# Managing Meta Tags

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to create and manage meta tags for different pages through the SEO section in the admin area.

Watch the video for a brief overview.

**The manual below provides step-by-step instructions.**

**1) Access the Meta Tags Section**

1. Log in to the **Admin Area** of your website.
2. Navigate to **SEO → Meta Tags**.

**2) Overview of Meta Tag Management**

Use this section to manage the SEO text blocks associated with different types of pages.

To switch between tag types, use the available tabs:

- **Index Tags**
- **Category Tags**
- **Brand Tags**
- **Product Info Tags**
- **All Products Tags**
- **What’s New Tags**
- **Specials Tags**
- **Featured Products Tags**
- **Product Review Tags**
- **Gift Card Tags**
- **Wedding Registry Tags**
- **Free Samples Tags**

Each tab allows setting SEO text values **individually** **per sales channel**.

[![1236.jpg](/wiki/images/thumb/9/94/1236.jpg/800px-1236.jpg)](https://www.oscommerce.com/wiki/File:1236.jpg)

**3) Configuring Tags in Each Section**

#### **Index Tags**

Configure SEO content for your home page:

- Heading Title
- Heading Description
- **HTML H1**, **HTML H2**, **HTML H3** (with **Add more** and **Delete** options)

[![1237.jpg](/wiki/images/thumb/d/d7/1237.jpg/800px-1237.jpg)](https://www.oscommerce.com/wiki/File:1237.jpg)

**Category Tags**

Configure tag settings for category pages:

- Heading Title / Description *(with “Add Key” to insert dynamic elements such as category name or breadcrumb)*
- Default Breadcrumb (for top-level category)
- **HTML H1**
- **HTML H2**, **HTML H3** (with **Add more** or **delete**)
- **Mask (template) for Image ALT**
- **Mask (template) for Image TITLE**

[![1238.jpg](/wiki/images/thumb/6/6d/1238.jpg/801px-1238.jpg)](https://www.oscommerce.com/wiki/File:1238.jpg)

**Brand Tags**

Configure tag settings for brand pages:

- Heading Title / Description *(with Add Key for brand name)*
- **HTML H1**
- **HTML H2**, **HTML H3** (with **Add more** or **delete**)

[![1239.jpg](/wiki/images/thumb/5/5a/1239.jpg/800px-1239.jpg)](https://www.oscommerce.com/wiki/File:1239.jpg)

**Product Info Tags**

Manage SEO tags for product details pages:

- Heading Title / Description *(with dynamic product, category, brand, and breadcrumb keys)*
- Default Breadcrumb
- **HTML H1**
- **HTML H2**, **HTML H3** (with **Add more** or **delete**)
- Image ALT and TITLE Masks (templates)

[![1240.jpg](/wiki/images/thumb/3/3b/1240.jpg/802px-1240.jpg)](https://www.oscommerce.com/wiki/File:1240.jpg)

**All Products/ What’s New / Specials / Featured Products / Product Review / Gift Card / Wedding Registry / Free Samples**

For each of these content pages, you can configure:

- Heading Title
- Heading Description
- **HTML H1**
- **HTML H2**, **HTML H3** (with **Add more** or **delete**)
