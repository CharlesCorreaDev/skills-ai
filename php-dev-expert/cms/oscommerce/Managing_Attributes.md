# Managing Attributes

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to manage attributes, attribute values, and attribute templates for products.

#### **1) Accessing Product Attributes**

1. Go to the **admin area** of your website.
2. Click **Products/Catalogue → Attributes → Products Attributes**.
3. From here, you can:
   - **Insert** a new attribute
   - **Edit** an existing attribute
   - **Delete** an attribute if it is no longer needed

[![Image 914.png](/wiki/images/thumb/f/f3/Image_914.png/799px-Image_914.png)](https://www.oscommerce.com/wiki/File:Image_914.png)

#### **2) Adding or Editing an Attribute**

When adding or editing an attribute, you can configure the following settings:

- **Attribute Type:** Choose **Multi-select** or **Single-select (radio button)**.
- **Mark as Virtual:** Enable if the product is virtual/downloadable.
- **Display Mode:** Choose whether the attribute appears in **product filters** and **search**.
- **Attribute Name:** Set one common name for all languages, or individual names for each language.
- **Icon and Color:** Upload an icon and/or choose a color to visually represent the attribute (optional).

Click **Save** when finished.

[![Image 915.png](/wiki/images/thumb/9/97/Image_915.png/799px-Image_915.png)](https://www.oscommerce.com/wiki/File:Image_915.png)

**3) Managing Attribute Values**

1. In the **Products Attributes** tab, **double-click** the attribute you want to manage.
2. You can:
   - **Insert** a new attribute value
   - **Edit** an existing value
   - **Delete** a value

[![Image 916.png](/wiki/images/thumb/a/ae/Image_916.png/799px-Image_916.png)](https://www.oscommerce.com/wiki/File:Image_916.png)

When adding or editing an attribute value, you can configure:

- **Extra Field Type:** Choose between **text box** or **text area** (optional).
- **Attribute Value Name:** Apply one common name or set individual translations.
- **Icon and Color:** Upload an icon or set a color if needed.

Click **Save** to confirm changes.

[![Image 917.png](/wiki/images/thumb/c/cc/Image_917.png/799px-Image_917.png)](https://www.oscommerce.com/wiki/File:Image_917.png)

**4) Working with Attribute Templates**

1. Go to **Products/Catalogue → Attributes → Attributes Templates**.
2. You can:
   - **Add** a new template
   - **Edit** an existing template
   - **Delete** a template
   - **Assign attributes** to a template

[![Image 918.png](/wiki/images/thumb/b/bd/Image_918.png/799px-Image_918.png)](https://www.oscommerce.com/wiki/File:Image_918.png)

3. When adding or editing a template, set the **Template Name**.

[![Image 919.png](/wiki/images/thumb/1/1d/Image_919.png/799px-Image_919.png)](https://www.oscommerce.com/wiki/File:Image_919.png)

4. To assign attributes:

- Click **Templates Attributes**.
- Select attribute value(s) from the **Attributes** list.
- Use the **>>** button to move the selected values to **Assigned Attributes**.

[![Image 920.png](/wiki/images/thumb/0/00/Image_920.png/799px-Image_920.png)](https://www.oscommerce.com/wiki/File:Image_920.png)

**5) Configuring Attribute Price and Weight Effects**

For each assigned attribute value, you can specify:

- **Effect on Price:**
  - Add / Subtract a fixed value
  - Add / Subtract a percentage
  - Apply a percentage discount off the base price
- **Effect on Weight:**
  - Add / Subtract a weight value
  - Add / Subtract a weight percentage

[![Image 921.png](/wiki/images/thumb/1/1d/Image_921.png/799px-Image_921.png)](https://www.oscommerce.com/wiki/File:Image_921.png)

**6) Configuring Virtual Products (If Applicable)**

If the product is **virtual**, you can:

- Upload or link a **downloadable file**
- Set the **maximum number of available days**
- Set the **maximum number of allowed downloads**

[![Image 922.png](/wiki/images/thumb/7/79/Image_922.png/799px-Image_922.png)](https://www.oscommerce.com/wiki/File:Image_922.png)
