# Managing SEO

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to manage SEO settings for meta tags, products, and categories in your website’s admin area.

For a quick overview of this functionality, watch the video first.

**For detailed guidance, please refer to the manual below.**

**1) Managing Meta Tags**

1. Log in to the **Admin Area** of your website.
2. Navigate to **SEO → Meta Tags**. See also [**Managing Meta Tags**](Managing_Meta_Tags.md "Managing Meta Tags")
3. Select the required tab (e.g., **Index Tags**, **All Products**, etc.). *If needed, scroll the tab bar to the right to locate more sections.*
4. Select the required **frontend** by clicking the corresponding tab.
5. You can:
   - **View or edit** Heading Title, Heading Description and HTML H1 tags.
   - **Add** multiple HTML H2, H3 tag fields using the **Add more** button.
   - **Delete** fields using the **trash icon**.

[![](/wiki/images/thumb/5/54/1307_Meta_tags.jpg/800px-1307_Meta_tags.jpg)](https://www.oscommerce.com/wiki/File:1307_Meta_tags.jpg)

**2) Managing SEO for Products**

1. When **adding or editing** a product, open the **SEO** tab.
2. Select the required **frontend** by clicking on the corresponding tab.
3. In the **SEO Page Name** field, enter how the product URL should appear in the browser, after the domain. **Example:**
   - Page name: `casio-general-men-s-watches-edifice-digital-analog-combination`
   - URL: `https://yourwebsite/casio-general-men-s-watches-edifice-digital-analog-combination`

**Note:** The **Canonical (URL)** field should **not** be filled in.

[![](/wiki/images/thumb/5/53/1308_SEO_page_name.jpg/800px-1308_SEO_page_name.jpg)](https://www.oscommerce.com/wiki/File:1308_SEO_page_name.jpg)

**3) Managing SEO for Categories**

1. When **adding or editing** a category, open the **SEO** tab.
2. Enter the URL name in the **Category SEO Page Name (URL)** field. **Example:**
   - Page name: `watch-catalog`
   - URL: `https://yourwebsite/watch-catalog`

**Note:** The **Canonical (URL)** field should **not** be filled in.

[![](/wiki/images/thumb/0/00/1309_Category_SEO_page_name.jpg/800px-1309_Category_SEO_page_name.jpg)](https://www.oscommerce.com/wiki/File:1309_Category_SEO_page_name.jpg)
