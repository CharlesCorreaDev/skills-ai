# Managing Default Sort Order on Product Listing and Category

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to set the default sort order for products on product listing pages and within categories.

Watch the video for a brief overview of this functionality.

The manual below provides step-by-step instructions.

**Note: This manual is for osCommerce v4.**

#### **1) Access Product Listing Settings**

1. Log in to the **admin area** of your website.
2. Navigate to **Settings → Configuration → Product listing**.
3. Locate the **Product listing default sort order** option in the list.

#### **2) Set Default Sort Order**

1. Click the **Product listing default sort order** option.
2. Click the **Edit** button.
3. Choose the desired sorting method from the list, for example:
   - Price (low to high / high to low)
   - Model
   - Product name (A–Z or Z–A)
   - Date added
4. Click **Update** to save the changes.

[![](/wiki/images/thumb/0/09/Image_1003.png/799px-Image_1003.png)](https://www.oscommerce.com/wiki/File:Image_1003.png)

[![Prod List Sort Order.jpg](/wiki/images/thumb/b/bf/Prod_List_Sort_Order.jpg/800px-Prod_List_Sort_Order.jpg)](https://www.oscommerce.com/wiki/File:Prod_List_Sort_Order.jpg)

#### **3) Set Default Sort Order for a Specific Category**

1. Navigate to **Products/Catalogue → Products (Brands/Categories)**.
2. Select the category you want to edit.
3. Click **Edit**.
4. Under the **Main details** tab, find the **Default sort order** field.
5. Select the desired sorting option.
6. Save your changes.
