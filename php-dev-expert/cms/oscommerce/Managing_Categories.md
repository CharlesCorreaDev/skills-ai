# Managing Categories

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to manage product categories in your system.

If you want to get a short overview of this functionality please watch this video first.

For additional information, please read the manual below.

#### **1) Accessing Categories**

1. Access the **admin area** of your website.
2. Navigate to **Products/Catalogue** → **Products (Brands/Categories)**.
3. Open the **Categories** tab.

#### **2) Working with the Category Tree**

- Use **drag and drop** to change category structure.
- Toggle the **switch** to enable or disable categories.

[![Category 1000.png](/wiki/images/thumb/3/39/Category_1000.png/800px-Category_1000.png)](https://www.oscommerce.com/wiki/File:Category_1000.png)

- Click **Add new category** to create a new category.

[![Category 1001.png](/wiki/images/thumb/8/8c/Category_1001.png/804px-Category_1001.png)](https://www.oscommerce.com/wiki/File:Category_1001.png)

#### **3) Assigning Categories to Sales Channels and Customer Groups**

1. Click **Edit** to modify a category.
2. Open the **Assign/Restrict** tab.
3. Assign the category to specific **sales channels**.
4. To assign a category to a **customer group**, enable the **Assign** option in the corresponding column.

**See [Assigning Products and Categories to Front Ends](Assigning_Products_and_Categories_to_Front_Ends.md "Assigning Products and Categories to Front Ends")**

[![Assign Categ.jpg](/wiki/images/thumb/f/f9/Assign_Categ.jpg/800px-Assign_Categ.jpg)](https://www.oscommerce.com/wiki/File:Assign_Categ.jpg)

#### **4) Setting Category Name and Description**

1. Open the **Name and description** tab.
2. Here you can:
   - Enter the **category name**
   - Add a **description**
   - Attach a **banner**
   - Assign links to:
     - Pages
     - Products
     - Other categories
     - Delivery location
     - Brands
     - Common links
   - Enter **search keywords** for category search.

[![Categ name and descr.jpg](/wiki/images/thumb/0/05/Categ_name_and_descr.jpg/800px-Categ_name_and_descr.jpg)](https://www.oscommerce.com/wiki/File:Categ_name_and_descr.jpg)

#### **5) Configuring Category Display and Sorting**

1. Open the **Main details** tab to:
   - Set **category status**
   - Choose **default sort order** for product listing (e.g., *Price low to high*)
   - Set an **Out of stock level** specific to the category
   - Select **banner group**
   - Select **sales channels**

**See [Managing Default Sort Order on Product Listing and Category](Managing_Default_Sort_Order_on_Product_Listing_and_Category.md "Managing Default Sort Order on Product Listing and Category").**

[![Categ main details.jpg](/wiki/images/thumb/f/f9/Categ_main_details.jpg/799px-Categ_main_details.jpg)](https://www.oscommerce.com/wiki/File:Categ_main_details.jpg)

2. Configure **layout and images**, including:

- Gallery image
- Hero image

[![Category gal hero1006.png](/wiki/images/thumb/a/a4/Category_gal_hero1006.png/800px-Category_gal_hero1006.png)](https://www.oscommerce.com/wiki/File:Category_gal_hero1006.png)

- Home page image
- Menu image

[![Category home menu im1007.png](/wiki/images/thumb/9/99/Category_home_menu_im1007.png/801px-Category_home_menu_im1007.png)](https://www.oscommerce.com/wiki/File:Category_home_menu_im1007.png)

- Additional images

**See [Adding Images to Categories and Subcategories](Adding_Images_to_Categories_and_Subcategories.md "Adding Images to Categories and Subcategories")**

**Note:** If **no** image is uploaded for a **category** or **subcategory**, the system will display an **image** from a **product** within that category or subcategory.

[![Category addit im1008.png](/wiki/images/thumb/7/7f/Category_addit_im1008.png/801px-Category_addit_im1008.png)](https://www.oscommerce.com/wiki/File:Category_addit_im1008.png)

#### **6) Setting SEO Properties**

1. Open the **SEO** tab to:
   - Set (override) **SEO URL**
   - Apply **no index / no follow** flags if needed
   - Assign **canonical URL**
   - Set **Page Title**, **META Description**
   - Configure **H1**, **H2**, **H3** tags (if needed)
   - Set **image ALT** and **Title** text

**See** [**Managing SEO**](Managing_SEO.md "Managing SEO")

[![Category SEO1008.png](/wiki/images/thumb/0/05/Category_SEO1008.png/800px-Category_SEO1008.png)](https://www.oscommerce.com/wiki/File:Category_SEO1008.png)

#### **7) Using Category Filters**

1. Open the **Filters** tab.
2. Activate filters for:
   - Keywords
   - Price
   - Categories
   - Product properties (e.g., size, color, dimensions)
3. Use **View Values** link to check active filter values.

[![Filters tab1.jpg](/wiki/images/thumb/c/c0/Filters_tab1.jpg/800px-Filters_tab1.jpg)](https://www.oscommerce.com/wiki/File:Filters_tab1.jpg)

#### **8) Applying Page Templates**

1. Open the **Templates** tab.
2. Select the **design template** for the category page.
3. Set **default design template** for products inside the category.

[![Category Template1009.png](/wiki/images/thumb/1/16/Category_Template1009.png/800px-Category_Template1009.png)](https://www.oscommerce.com/wiki/File:Category_Template1009.png)

**9)** **Setting Supplier Information (If Applicable)**

1. Open the **Suppliers** tab.
2. Click **Select/Add new supplier** to select a **default supplier** or create a new one.

[![Suppliers tab.jpg](/wiki/images/thumb/a/ac/Suppliers_tab.jpg/800px-Suppliers_tab.jpg)](https://www.oscommerce.com/wiki/File:Suppliers_tab.jpg)

**10) Marketing Links**

1. Open the **Marketing** tab to:
   - Link the category with products for **cross-selling** and promotion.

[![Marketing tab.jpg](/wiki/images/thumb/d/d0/Marketing_tab.jpg/801px-Marketing_tab.jpg)](https://www.oscommerce.com/wiki/File:Marketing_tab.jpg)

Your category setup is now complete. You can return at any time to update structure, templates, SEO, suppliers, filters, and display settings.
