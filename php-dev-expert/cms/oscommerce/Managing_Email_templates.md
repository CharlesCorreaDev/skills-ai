# Managing Email templates

From osCommerce Wiki

[Jump to navigation](#mw-head)
[Jump to search](#searchInput)

This manual explains how to create, edit, and manage email templates in your website’s admin area to ensure consistent and customized communication with customers and administrators.

Start with the video to get a quick introduction to the feature.

OR refer to the manual below.

**1) Access the Email Templates**

1. Log in to your website’s **Admin area**.
2. Navigate to **Design → CMS → Email Templates**.

**2) Choose a Template Group**

Work with **all templates**, or select a specific group of templates by clicking on the corresponding tab:

- **Admin template**
- **User-related from admin**
- **User-related from user**

**3) Manage Templates**

On the **Email Templates** page, you can:

- **Insert a new template**
- **Edit** an existing template
- **Copy** a template
- **Delete** a template

A **Quick search** option is available at the top of the listing page to help you find templates quickly.

[![1079 Templates.jpg](/wiki/images/thumb/d/d8/1079_Templates.jpg/800px-1079_Templates.jpg)](https://www.oscommerce.com/wiki/File:1079_Templates.jpg)

**4) Edit an Email Template**

When editing a template, you can configure the following settings:

- **Assign to sales channel**
- **Choose type**:
  - Any
  - Admin only
  - User only
  - Admin template for users
- **Select template design** (for HTML format)
- **Set template title**
- **Enter content**
- **Add template keys**, such as:
  - Store-specific
  - Customer-specific
  - Order-specific
  - Discount coupon-specific
- **Enter template information** for both **HTML** and **Text** versions
