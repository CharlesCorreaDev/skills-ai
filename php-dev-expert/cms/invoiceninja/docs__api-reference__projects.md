# Projects | Invoice Ninja

> **Fonte / Source:** https://invoiceninja.github.io/docs/api-reference/projects

---

A project groups tasks and expenses for a client, typically for time-based
or milestone work. The Projects API lets you organise work, set a budget
and default task rate, and roll project tasks up into invoices.
