# Tasks | Invoice Ninja

> **Fonte / Source:** https://invoiceninja.github.io/docs/api-reference/tasks

---

A task records time worked — billable or non-billable — optionally against
a project and client. The Tasks API lets you start and stop timers, log
time entries, and invoice tracked time.
