# Credits | Invoice Ninja

> **Fonte / Source:** https://invoiceninja.github.io/docs/api-reference/credits

---

A credit is effectively a negative invoice that reduces a client's
balance — issued for refunds, goodwill, or overpayments. The Credits API
lets you create and manage credits and apply them against a client's
outstanding invoices.
