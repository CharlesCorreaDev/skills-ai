# Recurring Invoices | Invoice Ninja

> **Fonte / Source:** https://invoiceninja.github.io/docs/api-reference/recurring-invoices

---

A recurring invoice is a template that automatically generates invoices on
a schedule (weekly, monthly, annually, and more). The Recurring Invoices
API lets you define the cadence, auto-billing behaviour, and remaining
cycles for subscription-style billing.
