# Package installation · intelliants/subrion Wiki · GitHub

> **Fonte / Source:** https://github.com/intelliants/subrion/wiki/Package-installation

---

Package installation is very easy in Subrion 4.1. You need to download the premium package from subrion.org account area and unpack it. Once done, you need to upload package (using FTP or hosting control panel tools) folder to **modules/** folder of your subrion installation.

Examples: *modules/autos/* for auto classifieds software.

Once you upload the files, you need to go to Admin Dashboard and clear script cache. You can find that in System menu section.

And the final step would be to go to Extensions / Packages and install the package.

That's it.
