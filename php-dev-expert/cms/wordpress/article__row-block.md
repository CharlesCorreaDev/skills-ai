Row block is one of the container blocks that can be used to arrange blocks in a single horizontal line.

## [Add a Row block](#add-a-row-block)

To add a Row block, click the **+ Block Inserter** button in the top-left corner of the editor. Search for the Row block and click on the block to add it to the page.

You can also use the keyboard shortcut `/row` to quickly insert a Row block in the editor.

[Get detailed instructions on adding blocks](article__adding-a-new-block.md).

## [Block toolbar](#block-toolbar)

To view the block toolbar, click on the block, and the toolbar will be displayed.

Every block comes with unique toolbar icons. These block-specific controls allow you to manipulate the block right in the editor.

![Row block toolbar options](https://wordpress.org/documentation/files/2022/11/row-block-toolbar-1.png)

The Row block has the following block toolbar options:

- Transform to
- Drag
- Move up/down
- Change items justification
- Change vertical alignment
- Align
- Options

### [Transform to](#transform-to)

Click on the **Transform to** button to convert the Row block into Group, Stack, Grid, Cover, Columns, or Details block.

![Row block transform options](https://wordpress.org/documentation/files/2022/11/row-block-transform-options.png)

### [Drag button](#drag-button)

To drag and drop the block to a new location on the page template, click and hold the **Drag** button, then drag it to the new location.

![Row block drag button (six-dot icon)](https://wordpress.org/documentation/files/2022/11/row-block-drag-button.png)

The blue separator line indicates where the block will be placed. Release the left mouse button when you find the new location to place the block.

### [Move arrows](#move-arrows)

The **Move** **up** and **Move down** buttons can be used to move the block up and down on the page.

![Row block move buttons (up/down arrows)](https://wordpress.org/documentation/files/2022/11/row-block-move-handles.png)

[Get more information about moving a block within the editor](article__moving-blocks.md)

### [Change items justification](#change-items-justification)

Click the **Change items justification** button in the Block toolbar to display the justification drop-down. You can justify the items inside of the Row block to the left, make them center-justified, align them to the right or leave a space between items.

![Row block justification options](https://wordpress.org/documentation/files/2022/11/row-block-justification.png)

### [Change vertical alignment](#change-vertical-alignment)

Use the **Change vertical alignment** tool to reposition items inside of the Row block. The following is a list of the block alignment options:

- Align top
- Align middle
- Align bottom
- Stretch to fill

![Row block vertical alignment options](https://wordpress.org/documentation/files/2022/11/row-block-vertical-alignment-2.png)

### [Change alignment](#change-alignment)

Use the **Change alignment tool** to change the width of the Row block. The following is a list of the block width options:

- None
- Wide width
- Full width

![Row block alignment options to change width](https://wordpress.org/documentation/files/2022/11/row-block-width.png)

### [More options](#more-options)

The More options menu (three vertical dots) on a block toolbar gives you more features to customize the block.

![Row block More options menu (three vertical dots)](https://wordpress.org/documentation/files/2022/11/row-block-more-options-menu.png)

[Read about the More options menu and its settings](article__more-options.md)

## [Block settings](#block-settings)

The block settings panel contains customization options specific to the block. To open it, select the block and click the **Settings** button next to the Save/Publish button

![Settings button highlighted in the block editor next to the Save button.](https://wordpress.org/documentation/files/2019/03/block-settings-7-0.png)

Click **Group**, **Stack**, or **Grid** button in the Block Settings to transform the block into one of these variations.

![Row block transform options in block settings](https://wordpress.org/documentation/files/2022/11/row-block-settings-transform-options.png)

### [Typography](#typography)

The Row blockprovides typography settings to change the font family, color, appearance, line height, letter spacing, decoration, letter case, and font size.

For details, refer to this support article: [Typography settings overview](article__typography-settings-overview.md)

### [Background](#background)

The Background settings allow you to customize the appearance of supported blocks using background images, colors, and gradients.

For details, refer to the [Background Settings Overview](article__background-settings-overview.md).

### [Layout](#layout)

The Row blockprovides Layout settings options to change the justification or orientation of the text and to wrap to multiple lines.

For details, refer to this support article: [Layout settings overview](article__layout-settings-overview.md)

### [Dimensions](#dimensions)

The Row block provides dimension settings options to add padding and margin.

#### [Width of blocks inside a Row](#width-of-blocks-inside-a-row)

When you select a block inside a Row, additional options appear under it’s **Dimensions** settings to control its width:

![Width properties for child blocks of row and stack including fit, grow, max, and fixed](https://wordpress.org/documentation/files/2026/09/child-items-of-row-and-stack-width-settings-edited.png)

- **Fit** uses only the space the block needs.
- **Fill** expand the block to use available space in the Row.
- **Max** width sets the maximum width of the block.
- **Fixed** sets a specific width for the block.

For details, refer to this support article: [Dimension settings overview](article__dimension-controls-overview.md)

### [Border & Shadow](#border-shadow)

The Row block provides border settings options to add border color, width, and radius.

For details, refer to this support article: [Border settings overview](article__border-settings-overview.md)

### [Elements](#elements)

Use the elements panel to change colors for blocks nested inside the selected block.

[Learn more about changing colors for nested elements](article__colors-settings-overview.md#elements-panel-for-nested-elements).

### [Position](#position)

The position setting is only available when the Row block is located at the root-level. The drop-down menu has two options: **Default** and **Sticky**. If the Sticky option is selected, the Row block will remain at the top of the window when you scroll down the page.

![Position dropdown options for the Row block including Default and Sticky](https://wordpress.org/documentation/files/2026/09/7-1-position-dropdown.png)

### [Advanced](#advanced)

The Row block provides the following Advanced settings options: HTML Anchor, Additional CSS Class(es), Additional CSS, HTML Element, Styles, and Allowed blocks.

[Learn more about advanced settings](article__advanced-settings-overview.md)
