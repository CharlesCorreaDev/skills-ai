The Cover block lets you add a background color, image or video with a text overlay. It is an excellent tool for creating headers, banner-style displays, call-to-actions, and more.

[](https://wordpress.org/documentation/files/2019/03/Kapture-2026-04-17-at-15.57.38.mp4)

Adding and configuring a Cover block

## [Add a Cover block](#add-a-cover-block)

To add the Coverblock, click the (+) icon to open the block inserter pop-up window. Look for the Cover block using the search bar and click the block icon to add it to the editor.

Alternatively, you can quickly add the Coverblock by typing `/cover` and pressing Enter.

![Add a cover block by typing /cover in the editor](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-04-17-at-2.45.23-PM.png)

[Detailed instructions on adding blocks](article__adding-a-new-block.md)

### [Initial options](#initial-options)

Once you add the Cover block, you have a few options to choose to get started:

- **Upload** an image or video from your device
- Choose **Media Library** to choose from an existing image or video on your site.
- Select the **Use featured image** option to set the [featured image](https://wordpress.com/support/featured-images/) of your page or post as the cover background
- Pick a **background color** for the Cover block by clicking a palette color circle
  - You can later change it to another color in the block settings.
- Resize the Cover block by dragging the bottom border and moving it up and down.

![Options when adding a new cover block including buttons to upload media, view the media library, use a featured image or choose a background color from the palette](https://wordpress.org/documentation/files/2019/03/initial-state-602839477-1556443d-c3db-4e5b-81fb-50be7214cf4b.png)

### [Resizing the Cover block](#resizing-the-cover-block)

The Cover block comes with a resize handle which appears below the Cover block when dragging. You can resize the block by moving the handle up and down.

This change will set a Minimum height value that you can see in the Block Settings – Styles toolbar. You can also change the size by updating this number.

[](https://wordpress.org/documentation/files/2019/03/Kapture-2026-04-17-at-16.18.26.mp4)

Resizing the Cover block from handles and block settings

## [Display a Featured Image](#display-a-featured-image)

You can set the [featured image](https://wordpress.com/support/featured-images/) of your page or post as the Cover block background.

## [Block toolbar](#block-toolbar)

![Cover block toolbar](https://wordpress.org/documentation/files/2019/03/block-toolbar-602839471-6eafaacc-c9ff-4208-82e8-4ed5d07600b8.png)

Each block toolbar comes with different options. These block toolbars let you customize or modify the block in the editor. To view the Cover block toolbar, select the block, and it will show a list of toolbar options.

The Cover block has the following tools:

- Transform to
- Moving handles
- Change alignment
- Change content position
- Toggle full height
- Crop
- Replace
- More options

### [Transform to](#transform-to)

![Block toolbar transform options](https://wordpress.org/documentation/files/2019/03/transform-602839475-802cc27b-5f37-440b-a3c7-90efe95a3977.png)

The Transform to tool allows you to convert the Cover block into the following blocks:

- Columns
- Details
- Group
- Media & Text
- Image
- Video

### [Moving handles](#moving-handles)

![The blog moving tool for the cover block](https://wordpress.org/documentation/files/2019/03/move-up-602839472-c6fbeac9-32b9-4ec6-b625-047a41e45ac1.png)

The up and down arrow icons can be used to shift a block up and down in your document.

![Block toolbar moving handles](https://wordpress.org/documentation/files/2019/03/move-handles-602839468-89b4e9f6-fde7-4a6b-8c70-bc0489f71141.png)

Or you can drag the six dots icon allows you to freely reposition the Cover block anywhere within the editor by holding the icon and dragging the block to the new location.

[Get more information about moving a block within the editor.](article__moving-blocks.md)

### [Change alignment](#change-alignment)

![Block alignment options](https://wordpress.org/documentation/files/2019/03/block-align-602839473-200e41c8-fd11-46b7-a813-94e5cd202a98.png)

Use the Change alignment tool to modify the alignment of the Cover block. Select the tool and pick one of the following alignment options:

- **None** – Leaves the block the current size.
- **Wide width** – Increase the width of the post beyond the content size.
- **Full width** – Extend the block to cover the full width of the screen.
- **Align left** – Make the block left-aligned.
- **Align center** – Make the block alignment centered.
- **Align right**– Make the block right aligned.

### [Change content position](#change-content-position)

![Change content position tool](https://wordpress.org/documentation/files/2019/03/align-inside-602839474-4c4fc6dc-d7d4-4278-9109-20b192a20a6c.png)

The Change content position lets you modify the position of the Paragraph block within the Cover block. You can position the Paragraph block on the top left to the bottom right of the Cover block.

[](https://wordpress.org/documentation/files/2021/02/alignment.mov)

### [Toggle full height](#toggle-full-height)

![Block toolbar full height button](https://wordpress.org/documentation/files/2019/03/full-viewport-height-602839476-87566305-600d-4a06-aa1b-afc8b922731d.png)

This option allows the Cover block to take up the height of the reader’s screen to create an immersive experience.

[](https://wordpress.org/documentation/files/2021/02/fullheight_trimmed_720.mov)

### [Add media / Replace](#add-media-replace)

![Add media block toolbar button showing options](https://wordpress.org/documentation/files/2019/03/open-Media-Library-602839469-71153440-5b19-4cf3-8751-8b02028efa98.png)

In a new Cover block you will see an Add Media button in the block toolbar. You can open the Media Library, upload a file, use featured image or embed a video from a URL.

![Block toolbar replace button](https://wordpress.org/documentation/files/2019/03/replace-602839470-c5a729ba-e2e5-41a6-8299-9d1cfc9854b4.png)

If your Cover block already has a background image or video, choosing Replace will allow you to select a new image or video file for your block.

### [Crop](#image-editing)

![Crop button in the Cover block toolbar](https://wordpress.org/documentation/files/2026/08/CleanShot-2026-08-18-at-15.38.55@2x-edited.png)

Use the **Crop** button in the block toolbar to open the Media Editor and make detailed edits to the Cover block’s background image directly in the editor.

The Media Editor has two tabs: **Crop** and **Details**.

#### [Crop tab](#crop-tab)

- Drag the handles on the image to make a freeform selection, or choose a preset from **Aspect ratio** (Free, Square – 1:1, and more).
- Use **Zoom** (+/−) to magnify the image for finer adjustments before selecting your crop.
- Use **Rotate** to turn the image left or right, or drag the ruler beneath the image to straighten it by degree.
- Use **Flip** to mirror the image horizontally or vertically.
- Crop handles snap to the source image’s pixels, so selections line up precisely.

#### [Details tab](#details-tab)

Select **Details** to update the background image’s metadata without leaving the editor:

- **Alt text** – describe the image for accessibility, or leave empty if the image is decorative.
- **Caption** and **Description**.
- Read-only file info: date added, author, file name, file type, file size, and dimensions.

Select **Save** to apply your changes, or **Cancel** to discard them and close the Media Editor.

**Note**: WordPress saves the edited version as a new image file, so the original image remains available in your Media Library.

## [Block settings](#block-settings)

![Block settings button ](https://wordpress.org/documentation/files/2019/03/block-settings-Screenshot-2026-03-08-at-8.13.56-AM-1-1.png)

Every block has specific options in the editor sidebar in addition to the options found in the block toolbar. If you do not see the sidebar, click on the **Settings button** next to the Save/Publish button.

The Cover block settings panel is divided into two tabs – Settings and Styles. It contains the following sections:

### [Layout](#layout)

![Layout section of Block settings](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-04-17-at-4.26.16-PM.png)

In the Layout section, you will see the following customization options:

- The Inner blocks use the content width toggle button, allowing nested blocks to use content width with options for full and wide widths.
- The Content width settings let you customize the width for all elements assigned to the center or wide columns.

### [Settings](#settings)

![Block settings for cover block with an image](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-04-17-at-4.29.44-PM-420x1024.png)

#### [Fixed background](#fixed-background)

The **Fixed background** toggle lets you create a parallax scrolling effect. When enabled, the background image stays still while the page content scrolls over the top of it. Toggling this setting off makes the image scroll naturally with the rest of the text.

[](https://wordpress.org/documentation/files/2020/08/Cover87899-1.mp4)

#### [Repeated background](#repeated-background)

![Repeated background settings for the cover image](https://wordpress.org/documentation/files/2019/03/Screenshot-repeated123.png)

The **Repeated background** option lets you repeat the same image to form a pattern in the Cover block. For example, if you have a small image and you want it to repeat multiple times in the Cover block, you can enable this option.

[](https://wordpress.org/documentation/files/2020/12/5-05cb8f618d67.mov)

You can use the **Repeated background** toggle in combination with **Fixed background**, but **Fixed background** does not necessarily have to be turned on. Feel free to play around with these options to find what suits your needs.

#### [Focal point picker](#focal-point-picker)

If the fixed background option is turned off, you will see the focal point picker. This tool lets you identify the main point of interest in the photo and highlight. Click on the picker to drag it to the spot you want, or use the left and top position percentages below to set it manually.

[](https://wordpress.org/documentation/files/2019/03/Kapture-2026-04-17-at-16.49.12.mp4)

Demonstrating using the focal point picker to focus on the bottom of the picture

#### [Set poster image (for videos)](#set-poster-image-for-videos)

The Cover Block supports setting a poster images for videos, enhancing accessibility for users with slow internet or mobile devices. After uploading a video, you’ll see the option available and can upload the image of your choosing.

[](https://wordpress.org/documentation/files/2019/03/set-poster-image.mov)

#### [Resolution](#resolution)

Cover block has been enhanced with new image resolution controls. You now have access to Resolution dropdown when selecting either a Featured Image, existing image from Media Library or uploading new image. This dropdown allows you to choose from available image sizes such as Thumbnail, Medium, Large and Full Size, helping you optimize for performance and visual quality.

#### [Alternative text](#alternative-text)

The alternative text field allows you to add an alternative text for the cover image that makes the content of the image accessible to a person who is using a screen reader.

### [Color](#color)

![Color options in Block settings toolbar](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-04-17-at-4.51.06-PM.png)

With the Color settings, you can customize the Coverblock by adding text, background, and link colors. The color selections vary depending on your active theme.

You can also add a gradient color to the Cover block. To do that, transform the block into the Media & Text block. Click the Background option and select the Gradient tab. Choose a color from the list. Convert the Media & Text block back into the Cover block.

[Learn more about the Color settings.](article__colors-settings-overview.md)

### [Filter options](#filter-options)

The Filters section contains the Apply duotone filter option. So, you can enable the duotone filter from the block settings panel

[Read more about the filter options](article__filters-settings-overview.md).

### [Typography](#typography)

The Typography settings enable you to customize the font and text appearance of the content within the Coverblock. The settings have various options, such as font size, font style, font family, and letter spacing.

[Get more details about changing typography settings](article__typography-settings-overview.md)

### [Dimensions](#dimensions)

![Cover block dimension controls in block settings](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-04-17-at-4.11.08-PM.png)

The Cover block provides dimension settings options to add padding, margin and block spacing. You can also choose an aspect ratio and a minimum height.

[Learn more about dimension controls](article__dimension-controls-overview.md)

### [Border & Shadow](#border-shadow)

The Cover block provides border settings options to add border color, width, radius and shadow.

[Learn more about border & shadow settings](article__border-settings-overview.md)

### [Advanced](#advanced)

The Cover block provides the following Advanced settings options: HTML Anchor, Additional CSS Class(es), Additional CSS, HTML Element, Styles and Allowed Blocks.

[Learn more about advanced settings](article__advanced-settings-overview.md)
