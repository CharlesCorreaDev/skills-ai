# Custom Post Types

Copy page
[View as Markdown](dev_plugins__post-types.md)

WordPress stores the Post Types in the `posts` table allowing developers to register Custom Post Types along the ones that already exist.

This chapter will show you how to [register Custom Post Types](dev_plugins__post-types__registering-custom-post-types.md), how to [retrieve their content from the database, and how to render them to the public](dev_plugins__post-types__working-with-custom-post-types.md).
