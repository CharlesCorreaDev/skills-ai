WordPress provides two core APIs to make the administrative interfaces easy to build, secure, and consistent with the design of WordPress Administration.

The [Settings API](dev_plugins__settings__settings-api.md) focuses on providing a way for developers to create forms and manage form data.

The [Options API](dev_plugins__settings__options-api.md) focuses on managing data using a simple key/value system.

See the complete example of [building a custom settings page](dev_plugins__settings__custom-settings-page.md) using the Settings API and Options API.
