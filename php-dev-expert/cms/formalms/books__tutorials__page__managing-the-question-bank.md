# Managing the Question Bank

The Question Bank is a central repository that allows you to **create, organize, and reuse questions across multiple tests** within your courses. By storing questions in one place, you can efficiently **build new assessments**, maintain consistency in evaluation standards, and **save time** when updating or exporting content.

This feature is especially useful for **managing large question sets**, standardizing difficulty levels, and ensuring flexibility in test creation and reuse.

## Managing the Question Bank

This feature can be accessed within any course. If not available, you can add and configure module permissions as for any other course feature (see **[reference guide](books__reference-guide__page__manage-menu.md)**).

[![Question Bank interface](https://docs2.formalms.org/uploads/images/gallery/2026-02/scaled-1680-/image.png)](https://docs2.formalms.org/uploads/images/gallery/2026-02/image.png)

### Export Questions from the Question Bank

From the "Question Bank" section, you can export specific questions and answers so you can insert them:

- Into an **existing test** within the course
- Into a **new test** that will be automatically created after export
- Into a **GIFT** file that can be used for insertion into other tests in other courses

![Export options](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-ry4dhqmy.png)

#### Selecting questions to export

Use the "Search" field to choose and select the questions to export.

This search can be done by Category and/or Difficulty and/or Type.

![Search filters](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-58hewr61.png)

Once you've set up your search, click Search to view only the questions that match the selected filters.

In our example, we will choose:

- Questions of any category
- Medium difficulty
- SC type – single choice

![Filtered results](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-ckbfkhmi.png)

#### Exporting questions

At this point, all we have left to do is:

1. Select the questions you wish to export
2. Click Export
3. Choose from the available options

*In our example, we will choose the “create a new test” option.*

![Create new test option](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-x5n1tzzd.png)

Enter the title of the new test and click on New Test.

![New test creation](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-hql0zkpt.png)

The new test will be created with the imported questions and answers.

![New test created](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-payrxvhe.png)

### Import questions to the Question Bank

To insert a list of new questions and answers, click on Import.

![Import button](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-mhn4g3m1.png)

Select a GIFT file to import and click the IMPORT button.

![Import file selection](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-fabrvwnf.png)

You will receive feedback on the import process and the questions will be added to the Question Bank.

![Import confirmation](https://docs2.formalms.org/uploads/images/gallery/2026-02/embedded-image-mqfo37yk.png)
