Craft is a flexible, user-friendly CMS for creating custom digital experiences on the web—and beyond.

People who use Craft love its…

- …intuitive, user-friendly [control panel](docs_5x__system__control-panel.md) for content creation and administrative tasks;
- …clean-slate approach to content modeling and [front-end development](docs_5x__development.md) that doesn’t make any assumptions about your content or how it should be delivered;
- …official Plugin Store with hundreds of free and commercial [plugins  (opens new window)](https://plugins.craftcms.com/);
- …robust framework for [plugin development](docs_5x__extend.md);
- …active, vibrant [community  (opens new window)](https://craftcms.com/community);

You can learn all about it at [craftcms.com  (opens new window)](https://craftcms.com).

Documentation Changes

The documentation has been rearranged a bit for this release, in order to better highlight the breadth of Craft’s features and consolidate technical material:

- High-level concepts are more visible in the [**System**](docs_5x__system.md) section;
- [**Reference**](docs_5x__reference.md) material has been given a dedicated space, including [element types](docs_5x__system__elements.md), [field types](docs_5x__system__fields.md), [console commands](docs_5x__reference__cli.md), controllers, Twig features, and [configuration](docs_5x__configure.md).
- Some pages geared toward front-end development have been moved into the [**Development**](docs_5x__development.md) section, including lots of new information on [eager-loading](docs_5x__development__eager-loading.md) and [collections](docs_5x__development__collections.md);
- Information about using [forms](docs_5x__development__forms.md) has been split into a dedicated page, while specific [controller actions](docs_5x__reference__controller-actions.md) remain in the **Reference** section.

## [#](#tech-specs)Tech Specs

Craft is a self-hosted PHP application, built on [Yii 2  (opens new window)](https://www.yiiframework.com/). It can connect to MySQL and PostgreSQL [databases](docs_5x__reference__config__db.md) for content storage. Server-side rendering is powered by [Twig  (opens new window)](https://twig.symfony.com), and headless applications have access to content via a [GraphQL API](docs_5x__development__graphql.md).

[View System Requirements
→

Craft runs best on the latest PHP and MySQL or Postgres versions, but can be configured to work on most modern hosting platforms.](docs_5x__requirements.md)
