# Developer Plugin Store FAQ

Answers to common questions about selling plugins on the Craft Plugin Store.

### What do I need to do to publish my plugin?

See the [Publishing to the Plugin Store](https://craftcms.com/docs/5.x/extend/plugin-store.html) guide for details on preparing, submitting, and maintaining your plugin. You’ll also want to review the [Plugin Store Approval Process](kb__plugin-store-approval-process.md) so you know what to expect.

### Can I write a private plugin that’s not on the Plugin Store?

Yes. Craft plugins can be added to a project like any other Composer dependency. If you’re writing a single-use plugin for a specific project, however, you may want to consider making it a module instead. See the [introduction to extension development](https://craftcms.com/docs/5.x/extend/) for more on the difference between the two.

### Do I need a Stripe account to sell plugins?

No. A Stripe account is the easiest way to connect and automatically receive payouts from Plugin Store sales, but if you have a PayPal account you can write [support@​craftcms.​com](mailto:support@craftcms.com) and we can arrange manual transfers to that instead.
