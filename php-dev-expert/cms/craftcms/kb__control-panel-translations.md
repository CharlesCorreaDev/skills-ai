# Control Panel Translations

Craft’s control panel is currently translated into the following languages:

- Arabic
- Chinese (Simplified)
- Czech
- Danish
- Dutch
- English (United Kingdom)
- English (United States)
- French
- French (Canada)
- German
- German (Switzerland)
- Hebrew
- Hungarian
- Italian
- Japanese
- Korean
- Norwegian Bokmal
- Persian
- Polish
- Portuguese
- Russian
- Slovak
- Spanish
- Swedish
- Thai
- Turkish
- Ukrainian

## Contributing to Control Panel Translations [#](#contributing-to-control-panel-translations "Direct link to Contributing to Control Panel Translations")

If you’d like to help improve Craft’s translations, please contribute to [Craft’s project on Crowdin](https://crowdin.com/project/craft-cms).

Applies to
Craft CMS 4 and Craft CMS 3.
