# Requirements

Craft Commerce requires Craft Pro, and therefore shares [its requirements](https://craftcms.com/docs/5.x/requirements). Your environment must also support PHP’s [SOAP extension  (opens new window)](https://www.php.net/manual/en/book.soap.php).

If you encounter Composer errors during installation, you can verify SOAP is installed and enabled by vising

1. Settings→
2. Utilities→
3. PHP Info

in the Craft control panel.

If you’re using MySQL or MariaDB, the engine should provide timezone support for the best experience. See [Populating MySQL and MariaDB Timezone Tables  (opens new window)](https://craftcms.com/knowledge-base/populating-mysql-mariadb-timezone-tables).
