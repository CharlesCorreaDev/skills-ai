# Running Multiple Craft Sites with Craft Commerce

Craft Commerce 5.x comes with a brand new multi-store feature to complement Craft’s native [multi-site](https://craftcms.com/docs/5.x/system/sites.html) architecture.

[Stores](https://craftcms.com/docs/commerce/5.x/system/stores.html) are configured independently—and then *attached to*—one or more sites (each site having one store). Your product content is still managed per-site (so it can be localized for each audience), but some core properties like prices, dimensions, and SKUs are defined for each store, or globally.

In addition to connecting each site to a store, stores support [multiple currencies](https://craftcms.com/docs/commerce/5.x/system/currencies.html). When you create a store, you select a primary currency; store managers can then enable additional currencies for customers to select while shopping (and to use at checkout).

## Limitations [#](#limitations "Direct link to Limitations")

Commerce is currently limited to five distinct stores and five inventory locations, but has no restrictions on the number of sites those stores are connected to. There are no limits on the number of product types, SKUs, orders, stock, revenue, customers, and so on.

Start building your storefront with Commerce by checking out the [documentation](https://craftcms.com/docs/commerce/5.x), or read more about its [key features](https://craftcms.com/commerce)!

Applies to
Craft CMS 5 and Craft Commerce 5.
