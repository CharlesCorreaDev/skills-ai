# Choosing a Text Editor

Choose a text editor for working with October CMS

- [Recommended: VS Code](docs__user-guide__quickstart__introduction__text-editor.md#recommended-vs-code)
- [October Code Extension](#october-code-extension)
- [Built-in Terminal](#built-in-terminal)
- [Other Options](docs__user-guide__quickstart__introduction__text-editor.md#other-options)
- [Next Steps](docs__user-guide__quickstart__introduction__text-editor.md#next-steps)

You will need a text editor to work with October CMS templates, blueprints, and configuration files. While any plain text editor will work, a modern code editor makes the experience much better with features like syntax highlighting, file browsing, and integrated terminal.

## [#](#recommended-vs-code) Recommended: VS Code

[Visual Studio Code  (opens new window)](https://code.visualstudio.com/) (VS Code) is a free, open-source editor that works on macOS, Windows, and Linux. It is the most popular choice for web development and has excellent support for the languages used in October CMS.

### [#](#october-code-extension) October Code Extension

Install the [October Code  (opens new window)](https://marketplace.visualstudio.com/items?itemName=SergeyKasyanov.october-code) extension to get:

- Twig syntax highlighting for October CMS templates
- Autocompletion for Twig tags, filters, and functions
- Blueprint YAML support
- Quick navigation between pages, layouts, and partials

Search for **"October Code"** in the VS Code extensions panel, or install it from the [VS Code Marketplace  (opens new window)](https://marketplace.visualstudio.com/items?itemName=SergeyKasyanov.october-code).

### [#](#built-in-terminal) Built-in Terminal

VS Code includes an integrated terminal (open it with `` Ctrl+` ``), so you can run commands without switching windows. This is especially handy during installation and development.

## [#](#other-options) Other Options

If VS Code is not your style, these editors also work well:

- **[Sublime Text  (opens new window)](https://www.sublimetext.com/)**: Lightweight and fast. Available on all platforms.
- **[PhpStorm  (opens new window)](https://www.jetbrains.com/phpstorm/)**: A full-featured PHP IDE with deep Laravel support. Paid, but powerful.
- **[Cursor  (opens new window)](https://cursor.sh/)**: An AI-enhanced code editor built on VS Code.
