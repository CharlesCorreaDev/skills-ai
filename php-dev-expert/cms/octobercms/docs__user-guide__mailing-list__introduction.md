# Creating a Mailing List

Build an email mailing list with signup forms, campaigns, and dynamic content.

- [What You Will Build](docs__user-guide__mailing-list__introduction.md#what-you-will-build)
- [Premium Plugins](docs__user-guide__mailing-list__introduction.md#premium-plugins)
- [Prerequisites](docs__user-guide__mailing-list__introduction.md#prerequisites)
- [Overview](docs__user-guide__mailing-list__introduction.md#overview)
- [Next Steps](docs__user-guide__mailing-list__introduction.md#next-steps)

In this tutorial, you will build a mailing list system for your website. Visitors subscribe through a signup form, you compose professional HTML email campaigns in the backend, and the plugin handles sending, tracking, and unsubscribing automatically. You will also create a dynamic template that pulls your latest blog posts into a recurring newsletter.

## [#](#what-you-will-build) What You Will Build

- A subscriber list with a frontend signup form and email confirmation
- A campaign template for sending professional HTML emails
- Backend tools for composing, previewing, and launching campaigns
- A customized email template with your own branding and layout
- A dynamic campaign that automatically includes your latest blog posts

## [#](#premium-plugins) Premium Plugins

Responsiv.Campaign is a premium plugin available from the [October CMS Marketplace  (opens new window)](http://octobercms.com/plugin/responsiv-campaign). Premium plugins work exactly like free plugins: you install them the same way and use their components identically. The only difference is that premium plugins require a license to install.

## [#](#prerequisites) Prerequisites

Before starting this tutorial, make sure you have:

- October CMS installed and running
- A theme with a default layout that includes Tailwind CSS and the AJAX framework
- The [Creating a Blog](docs__user-guide__blog__introduction.md) tutorial completed (for the dynamic campaigns chapter)
- Mail configured in **Settings > Mail Configuration** (campaigns send real emails)

1. [Installing the Plugin](docs__user-guide__mailing-list__installing-the-plugin.md): install Responsiv.Campaign, create a subscriber list, and generate the default campaign template
