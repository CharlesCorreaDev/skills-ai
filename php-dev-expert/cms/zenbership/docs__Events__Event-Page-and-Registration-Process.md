# Event Page and Registration Process

## Overview

The event page is the online display for an event. Users can view an event's details, timeline, media, and register for the event from this location.

- Location: http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.event.php?id=event\_id\_here

## Event Page ("Overview")

- Templates: Event Details

| Item | Description |
| --- | --- |
| 1 | Cover photo. Note that if you upload multiple cover photos for an event, the program will automatically create an image "slider" which rotates images. |
| 2 | Event details. Start date, end date, location name, and capacity. |
| 3 | Key Registration Dates. Current registration status, date on which registration begins, ends, and if there is an early bird registration end date, that date as well. |
| 4 | Event tagline. |
| 5 | Event description. |
| 6 | Event Navigation. The "Overview" page is currently being displayed; the "Timeline" page has all timeline entries, if any; the "Register" page allows users to register for the event. |
| 7 | Additional Photos. Any files uploaded as an "Additional Photo" is displayed here. |
| 8 | Map. If you have inputted a location with a full address, a map will be generated here. |

## Register Page and Process

- Templates (in order of appearance):
- Event Register Pricing Options
- Event Registration Form
- Event Register Guests Number
- Event Register Guests Form

### Step 1: Product Selection Screen

The "Register" page allows users to register for an event. Based on the product options you set up when [creating the event](docs__Events__Creating-Events.md), you may or may not see all of the possible options displayed in the above image.

1. **Early Bird Pricing Options**: If you have allowed for early bird pricing and have selected early bird products, those options will appear here.
2. **Ticket Options**: These are standard ticket options.
3. **Additional Options**: These products are not required to register but act as "Add On" products.

### Step 2: Registration Form

Primary registration form. Note that the fields on the form can be customized by editing the "Attendee Registration Form".

### Step 3: Guest Registration Form

Guest selection form. Note that (1) this form will only appear if you are allowing guests, and if so, (2) the fields on the form can be customized by editing the "Guest Registration Form". Item 1: Guest selection input. Item 2: Guest ticket options. If you selected guest ticket options when creating the event, they will appear here. Otherwise guests can be registered for free.

Guest registration form: If the user elected to bring guests, they can register them from here.

### Step 4: Confirmation

### Step 5: Checkout

If the event is a paid event, the user will next see the shopping cart checkout page. Otherwise, the user will skip to the confirmation step.

### Step 6: Confirmation

The final step is a simple confirmation page with the user's ticket number and ticket status. That status is usually confirmed, with the exception of when a user requests an invoice. In that case, the status will only become "Confirmed" once the invoice is settled in full.
