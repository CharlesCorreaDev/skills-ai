# Member Dashboard

## Overview

1. **Member Management Menu**: contains links to all management pages for a member. This menu can be changed by editing the "Member Management" menu from "Content > Widgets > Menus".
2. **Content Menu**: A list of all content this member has access to appears in this menu.

### Location

http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.manage/

### Function

The member management panel is a self-service dashboard from which members can do all of the following:

- Update their membership details, such as contact information.
- Manage their subscriptions, including adding a credit card, cancelling, and upgrading/downgrading.
- View login announcements.
- Manage credit cards on file.
- Review past transactions
- Review invoices
- View event registrations
- View their personal "Storage Box" of [uploaded files](docs__Uploads__Setting-Labels.md).

## Setting Updatable Fields

You can select which fieldsets appear on the "member update" form from the "Integration > Fieldsets". Edit any fieldset and under "Scopes" select the "Member Update" option.
