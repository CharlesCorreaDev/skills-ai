# Setting Labels

## Overview

A "label" is a "tag" applied to an uploaded file that can be used to organize [uploaded files](docs__Uploads__Uploading-Files.md) within [upload widgets](docs__Widgets__File-List.md).

## Setting a Label

### When Uploading the File

- [Click here](docs__Uploads__Uploading-Files.md) for an overview.

### After a File Has Been Uploaded

- To set a file's label after uploading a file, you will need to access the item (IE: member, account) to which it was uploaded.
- Find the file on the list and click the existing label under the "Label" column of the upload table.
- A popup will appear. On this popup, either type in a new label, or select an existing label by clicking on the "List View" icon and selecting the correct label.
- Click "Save" to apply the changes.
