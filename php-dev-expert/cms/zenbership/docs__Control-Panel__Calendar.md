# Calendar

## Overview

Sample Administrative Calendar View.

The administrative calendar provides a day-by-day overview for all of the following items:

- **Administrators:** Administrators can see all of the following items for all employees:
- Transactions
- Revenue from transactions
- Event registrations
- New Contancts
- New Members
- Contacts due
- Deadlines
- Appointments
- **Employees:** Employees can see all of the following items owned by them personally:
- Contacts due
- Deadlines
- Appointments

## Accessing the Calendar

To access the calendar, simply click on "Calendar" on the homepage of the administrative control panel. Alternatively, you are click on "My Calendar" link, found in the employee menu in the top right corner of the control panel.
