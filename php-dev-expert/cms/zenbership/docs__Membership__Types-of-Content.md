# Types of Content

## Overview

Zenbership supports various types of content.

| Type | Description | Secure? |
| --- | --- | --- |
| Secure Folder | A physical folder on your website that is secured by Zenbership. | Yes |
| Page | A page within the [CMS](docs__Integration__Integration-Overview.md). | Optional |
| Section | A virtual section within the CMS. Works like secure folders, except the folder is not physically found on the server. | Optional |
| Page Redirect | A redirection from one page to another. | No |

## Notice About Page/Section Security Conflicts

Content security can be "multi-leveled", meaning that if you have several secure pages within a secure section, the member will need access to both the secure page and the secure section to view the page. For this reason, we recommend that you secure sections and create "public" pages within the section. Despite being "public", the pages will actually be secured by the section's security.
