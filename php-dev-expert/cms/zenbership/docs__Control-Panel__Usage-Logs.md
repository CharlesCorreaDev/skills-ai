# Usage Logs

## Overview

Usage logs allow you to see what actions employees have been taking throughout the control panel.

## Accessing the Logs

Note that you must be logged in as an "Administrator" to use this feature.

1. Click on "Employees" in the top right corner of the program.
2. In the secondary navigation, click on "Usage Logs"

## Filtering by Employee

You can view a specific employee's actions by using the "Filters" button and typing in the employee's username into the "Username" field.
