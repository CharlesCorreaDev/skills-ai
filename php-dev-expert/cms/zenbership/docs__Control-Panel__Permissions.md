# Permissions

## Overview

Permissions control what features on the administrative control panel employees can and cannot use.

## Setting Permission Groups

Permissions are established using "Permission Groups". The program comes with several pre-established permissions groups from which you can select when creating or editing an employee.

- To select a permission group, click on "Employees" in the top right corner.
- Click on any existing employee's username to load the employee slider.
- On the right side of the slider, under "Additional Details", select the permission group to which this employee will be assigned from the "Permissions" dropdown.
- Click on "Save" to apply the changes to the employee's account.

## Customizing Permission Groups

At this time, the program does not allow for customize employee permissions.
