# Event Types

## Overview

Event types help to classify events into categories. They appear on the calendar as color-coded circles:

Every event can be "tagged" with one or more event type.

## Creating Event Types

From the administrative dashboard:

- Click on "Events > Event Types"
- A popup will appear:

- To create a new event type, click on "[+] Add New Event".
- Type in a name for the event type.
- Click the color picker icon to select a color code for this event type.
- Click on "Save" to create the event type.

## Assigning Event Types

[Click here](docs__Events__Creating-Events.md) to learn how to "tag" events with a event types.
