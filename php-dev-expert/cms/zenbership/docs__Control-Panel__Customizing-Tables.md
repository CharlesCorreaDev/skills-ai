# Customizing Tables

Tables appear on all listings pages throughout the administrative control panel. For many, but not all, of these tables, you can customize the fields that appear in the column headers.

To customize table headings, look for the "Gear" icon in the top right corner of any table. Clicking the icon reveals a list of possible column headers for this table. Select the fields that you wish to use as the column headers and click on "Save" to apply the changes.

Table headers can be customized by each employee to meet their own requirements.
