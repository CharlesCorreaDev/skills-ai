# Duplicating Items

## Overview

The program allows you to duplicate specific items in the database with one click. Items that can be duplicated include:

- Events
- Products

## Duplicating Items

To duplicate an item, you must first visit the listings page for the item you want to duplicate. For example, if you are duplicating an event, you would go to "Events".

Once there, find the item you want to duplicate and click on the duplicate icon:

When you duplicate an item, an exact copy will be created. In most cases, the item will be disabled until you activate it. You will most likely also need to rename it, as most copied items have the word "copy" attached to them.

Sample duplicated event.

## What Isn't Duplicated

Some information is never copies when duplicating an item. This information is listed below.

### Events

- Registration data

### Products

- Transaction History
- Subscriptions linked to a product.
