# Registration Forms

## Overview

A registration form is a form from which a visitor to your website can become a "member". There are two types of registration forms.

## Paid Registration Form

### Overview

A "Paid" registration form requires that a user purchase a product to become a member. You can specify the products when creating the form. There are two types of products:

- Required Option
- Optional Addon

A "Required Option" must be selected to proceed with the registration, while an "Optional Addon" is not required to become a member, but can be added to the form as an optional addon for the registering member.

### Creating a Paid Registration Form

- Click on "Form" from the "Quick Add![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)The quick add menu is located in the primary navigation bar. It is a green icon with a white plus sign." menu.
- A popup will appear with five options. Select "Paid Registration".
- Most of the fields on the resulting popup are covered under the "Form Creation Fields" section below.

### "Products" Tab

The products tab is unique to paid registration forms and allows you to specify which products will appear as options on the registration form.

| Field | Description |
| --- | --- |
| Product | AutocompleteAdditional InformationPlease remember that when using the auto-complete tool you must click the result to select it. You also cannot create a new item by simply typing the name of an item that doesn't exist. tool that allows you to find and select the product you wish to add to the registration form. |
| Type | Allows you to specify whether a product is required to register, or whether it is optional. |
| Quantity | Determines whether the quantity will always be "1", or whether the user can select how many units of the product they wish to purchase. |

## Free Registration Form

A free registration form is a form that creates a member without requiring a purchase.

## Form Creation Fields

These fields are standard for both Paid and Free registration forms. These are outlined in details in the "[Registration Form Breakdown](docs__Membership__Registration-Form-Breakdown.md)" article.
