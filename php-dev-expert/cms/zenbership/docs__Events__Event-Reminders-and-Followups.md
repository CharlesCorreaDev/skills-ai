# Event Reminders and Followups

## Overview

Reminders and followups are sent to registrants of an event before the event takes place and after the event takes place. All event reminders and followups use the "Default Event Reminder" and "Default Event Followup" templates. The program gives you the option to create custom templates as well, which can be used for the same purpose.

## Creating a Reminder or Followup

You will need to create reminders and followups for every event individually. The good news is that this is an easy process, requiring only a couple basic steps.

- Click on "Events"
- On the resulting listings page, click on the event you want to create the followup for.

- Click on the "Reminders" link in the slider's navigation.
- A popup will appear with three tabs: "Reminders", "Followups", and "Create New". You can manage existing reminders and followups using the first two tabs, while the third tab allows you to create a new reminder or followup.
- Click the "Create New" tab.

Create a reminder or followup for an event.

1. **Type:** whether you wish for this followup/reminder to be sent as an SMS message or email message.
2. **Template:** Selecting "Default Template" uses the "Default Event Reminder" or "Default Event Followup" template. Alternatively, you can create a [custom email template](docs__Integration__Creating-Custom-Email-Templates.md) and use it for followups/reminders by selecting it from this list.
3. **When?:** This controls whether this message is a reminder (sent before the event takes place) or a followup (sent after the event is over).
4. **Scheduled:** Controls the timeframe before or after the event when this message will be sent. So for example, if your event is scheduled for July 14th and you are creating a reminder that is scheduled for "7 Days", the message will be sent on July 7th. The same message set up as a followup would be sent on July 21st.
5. **Custom Message:** The default templates have a "custom\_message" caller tag. Whatever you input into this field will appear on the email where the "custom\_message" caller tag appears.

- Complete the process by clicking on "Save".
- The page will reload and the new message will appear under the "Reminders" or "Followups" tabs.

## Notes About SMS Messages

If you select to send an SMS reminder, you will need to remember the following:

- SMS messages only work if the registrants has submitted a cell phone number and cell phone provider.
- SMS messages do not use a template. Instead, the "Custom Message" field is what is sent to registrants.

[Click here](docs__SMS__How-SMS-Works.md) for more information on SMS messages.
