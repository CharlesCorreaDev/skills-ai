# Extension Overview

An "Extension" is anything that is not a standard feature of the program but which "extends" the standard functionality to include new features. An extension could be any of the following:

- Plugin
- Widget
- Custom Hook
- HTML Theme
- E-Mail Theme
- Mobile Theme
