# List of Common URLs

This article lists common locations for pages that you or your users will often access. Note that these examples presume that Zenbership was installed into the "members" sub-domain of your website.

## [Administrative Dashboard](docs__Control-Panel__Control-Panel-Overview.md)

- http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.admin

The management center of the program. Allows you employees to manage all aspects of the program.

## Member Self-Service Portal

- http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.manage

Location from which your members can manage their account, including view subscriptions, billing history, event registrations, invoices, and update their account details, including credit cards.

## Event Calendar

- http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.calendar.php

This will provide users with access to all upcoming and past events.

## Store Front

- http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.catalog.php

This provides your users with access to your entire shopping cart.

- Registration Forms: http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.register.php
- Lost Password Recovery: http://members.yoursite.com/![Additional Information](/templates/html/blank_slate/imgs/icon-help.png)Remember that you will need to change "http://members.yoursite.com/" to the actual URL at which Zenbership is installed.lost\_password.php
