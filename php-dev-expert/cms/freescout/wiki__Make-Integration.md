FreeScout can be integrated basically with anything via **[Make Integration](https://www.make.com/en/integrations/freescout)** (Formerly "Integromat")

To use FreeScout with Make you will need to install [API & Webhooks Module](https://freescout.net/module/api-webhooks/)

FreeScout integration looks like this in Make:

![2022-06-22_09-01-11](https://user-images.githubusercontent.com/40499291/174954823-855fa870-4c57-4b2c-98db-dfcb6ed4fc65.png)

**Mailbox ID** you can find in the URL of the mailbox in FreeScout, for example: <https://demo.freescout.net/mailbox/settings/2>, where 2 - is the mailbox ID.
