# Modules Development · freescout-help-desk/freescout Wiki · GitHub

> **Fonte / Source:** https://github.com/freescout-help-desk/freescout/wiki/Modules-Development

---

Modules allow to extend FreeScout functionality (just like WordPress plugins). Every single aspect of FreeScout can be adjusted via modules. It is achieved by adding [actions/filters](wiki__Development-Guide.md#actions-and-filters) to the core.

If you need to add some action/filter to the application, just create a [pull request](wiki__Development-Guide.md#step-by-step-instruction). If you need to adjust some existing module - see [this](wiki__FreeScout-Modules.md#5-modifying-modules).

Modules are developed using [Laravel-Modules](https://github.com/nWidart/laravel-modules) v2 package ([documentation](https://nwidart.com/laravel-modules/v2/introduction)).

[**FreeScout Modules Development Guide**](http://freescout.net/modules-guide/)
