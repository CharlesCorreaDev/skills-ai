## Dependencies Security

Various security scanners may flag vulnerabilities in dependencies, but that does not mean they exist in the application or can be exploited. [Here](wiki__Development-Guide.md#maintaining-security-and-laravel-no-upgrade-policy) you can read how FreeScout Team ensures application dependencies security.
