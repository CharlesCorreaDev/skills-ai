> Keep in mind that FreeScout Team can not guarantee that community modules are 100% reliable and secure. Please use them at your own risk.
>
> If you want to share with others your custom module please create a Git Repository and send a link to [support@freescout.net](mailto:support@freescout.net)
>
> Need more modules? Check out [Modules Marketplace](https://freescout.net/marketplace/)
