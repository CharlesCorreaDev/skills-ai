FreeScout can be integrated basically with anything via **[FreeScout Zapier Integration](https://zapier.com/apps/freescout/integrations)**

To use FreeScout with Zapier you will need to install [API & Webhooks Module](https://freescout.net/module/api-webhooks/)

### Troubleshooting

**— Conversation Created trigger not firing**

1. Make sure that Zapier app created a webhook in your FreeScout in Manage > Settings > API & Webhooks.
2. If the webhook exists, check it's "Error Log".
3. Check FreeScout logs in Manage > Logs > App Logs
