### Maian Media is Evolving

[![View: Maian Media is Evolving](https://www.maianmedia.com/assets/img/news/maian-media.png "Maian Media is Evolving")](latest-news__maian-media-is-evolving.md "View: Maian Media is Evolving")

We are pleased to announce a new direction for Maian Media as we take on board the full power of Agentic Coding.  
  
It's difficult to ignore AI these days. Almost everything you read and see in the news is talking about AI and it can be overwhelming. There's also a lot of what people are branding as 'slop' coding. There are apps coming out every 5 minutes built in technologies that many people don't understand. Building projects with no coding experience at all has many drawbacks, most of which relate to security issues that are never discovered or addressed. The bottom line is AI does not know everything and cannot be fully trusted unless you have that experience.  
  
For us we see it as a way to enhance our products rather than just letting it run amok to build something inferior. The Maian Media projects have been online for over 20 years now and as things have changed over the years, output has got less and less. A number of older projects got shelved and a number of newer projects were put on hold simply because of the time constraints involved. But now with AI we feel we are able to move forward at a much faster pace, update/add things faster and build new projects. Exciting times are ahead for sure.   
  
A project that we put on hold a while ago, but we did start, is a project called Maian Changelog ([maianchangelog.com](https://www.maianchangelog.com)). Maian Changelog is a changelog release system that enables you to add projects, versions, changelogs, changelog types, subscribers, comments and roadmaps. It also has a full Rest API. It has been completed and enhanced using the full power of AI and is built using the Flight PHP framework (flightphp.com). Flight is a fast and extensible PHP framework and not over bloated like many other frameworks. It is perfectly suited for this project and we will be using this a lot going forward. It's worth noting we will also be using other frameworks depending on the size of the project. We will only use frameworks that we are experienced with. eg: Laravel, Yii, Fat Free, Flight etc.   
  
Maian Changelog is just going through the final testing phases and will be released very soon. Going forward, all existing Maian Media projects will be fully reimagined using AI. Several of the Maian projects are already in progress and we hope you enjoy the changes that are coming in the months ahead.  
  
Thank you for taking the time to read this and for your interest in our scripts.   
  
All the best,  
  
David  
Lead Developer @ Maian Media
