### Installation Service

For people who need help installing our scripts, we offer a reliable installation service for a single fee. This fee is for a single setup only and has two levels of service as shown. The installation service is for any free or commercial script.  
  
Please note that we will require server access to install the script. If you cannot give us this access, we cannot help you. We **do not** do installs via
remote desktop connections or SSH.  
  
The premium service is usually 24hrs guaranteed, the standard service 3 to 5 business days. Note that day 1 is the day after payment Hong Kong time. Business days are Mon to Fri only.  
  
Note that for the premium option you must be available to answer any questions if we require additional information. If we get no reply the 24hr option may not be guaranteed.
