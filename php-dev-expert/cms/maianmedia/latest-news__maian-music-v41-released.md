### Maian Music v4.1 Released

[![View: Maian Music v4.1 Released](https://www.maianmedia.com/assets/img/news/maian-music.png "Maian Music v4.1 Released")](latest-news__maian-music-v41-released.md "View: Maian Music v4.1 Released")

We are pleased to announce the release of Maian Music v4.1.  
  
Please note that the minimum PHP version required to run Maian Music is now 8.3, this is due to vendor updates. This new version has some maintenance updates and code fixes as well as an optional dark theme. Refer to the changelog for an overview of changes.  
  
Download:  
<https://www.maianmusic.com/download>  
  
v4.1 Changelog:  
<https://www.maianmusic.com/changelog.txt>  
  
Refer to the upgrade information in the docs. If you have any problems, please see the support options on the Maian Media website:  
[https://www.maianmedia.com/support](support.md)  
  
As always, if you have purchased a commercial licence, this upgrade is free of charge.  
  
Take care and thank you for your interest in our scripts,  
  
David  
Lead Developer @ Maian Media
