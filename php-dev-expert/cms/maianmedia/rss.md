<![CDATA[Maian Media is Evolving]]>
https://www.maianmedia.com/latest-news/maian-media-is-evolving
Fri, 17 Jul 2026 10:05:05 +0100

https://www.maianmedia.com/latest-news/maian-media-is-evolving
We are pleased to announce a new direction for Maian Media as we take on board the full power of Agentic Coding.<br>
<br>
It's difficult to ignore AI these days. Almost everything you read and see in the news is talking about AI and it can be overwhelming. There's also a lot of what people are branding as 'slop' coding. There are apps coming out every 5 minutes built in technologies that many people don't understand. Building projects with no coding experience at all has many drawbacks, most of which relate to security issues that are never discovered or addressed. The bottom line is AI does not know everything and cannot be fully trusted unless you have that experience.<br>
<br>
For us we see it as a way to enhance our products rather than just letting it run amok to build something inferior. The Maian Media projects have been online for over 20 years now and as things have changed over the years, output has got less and less. A number of older projects got shelved and a number of newer projects were put on hold simply because of the time constraints involved. But now with AI we feel we are able to move forward at a much faster pace, update/add things faster and build new projects. Exciting times are ahead for sure. <br>
<br>
A project that we put on hold a while ago, but we did start, is a project called Maian Changelog (<a href="https://www.maianchangelog.com">maianchangelog.com</a>). Maian Changelog is a changelog release system that enables you to add projects, versions, changelogs, changelog types, subscribers, comments and roadmaps. It also has a full Rest API. It has been completed and enhanced using the full power of AI and is built using the Flight PHP framework (flightphp.com). Flight is a fast and extensible PHP framework and not over bloated like many other frameworks. It is perfectly suited for this project and we will be using this a lot going forward. It's worth noting we will also be using other frameworks depending on the size of the project. We will only use frameworks that we are experienced with. eg: Laravel, Yii, Fat Free, Flight etc. <br>
<br>
Maian Changelog is just going through the final testing phases and will be released very soon. Going forward, all existing Maian Media projects will be fully reimagined using AI. Several of the Maian projects are already in progress and we hope you enjoy the changes that are coming in the months ahead.<br>
<br>
Thank you for taking the time to read this and for your interest in our scripts. <br>
<br>
All the best,<br>
<br>
David<br>
Lead Developer @ Maian Media

<![CDATA[Maian Cart - SQL Injection Vulnerability.]]>
https://www.maianmedia.com/latest-news/maian-cart-sql-injection-vulnerability
Wed, 04 Feb 2026 16:12:13 +0000

https://www.maianmedia.com/latest-news/maian-cart-sql-injection-vulnerability
r0am1ng has been kind enough to contact us about a possible SQL injection vulnerability in Maian Cart when using the remote option to add product images. Note that this is only possible if someone was to gain access to the admin interface of Maian Cart and execute the code. The level of the severity is therefore low. As a precaution we have disabled this option for now and will address it later when the cart system gets a brand new update.<br>
<br>
If you are using the latest version of Maian Cart, please download the zip file from the Maian Cart website and update your 'admin' folder with the current version, omitting the 'control/access.php' file.<br>
<br>
We would like to thank r0am1ng for taking the time to let us know about this issue. :)

https://www.maianmedia.com/latest-news/maian-cart-v38-released
We are pleased to announce the release of Maian Cart v3.8, this updates a few libraries, fixes some bugs and updates the Authorize.net payment gateway.<br>
<br>
If you are using Authorize.net you must update your installation and update the signature key, which is generated in your Authorize.net control panel. Previously in Maian Cart this would have been the value of a MD5 hash, but this must now be an actual signature key. See the docs for assistance. Please do not just change the key in your existing installation, the core files must also be updated as they contain API changes related to the Authorize.net gateway.
