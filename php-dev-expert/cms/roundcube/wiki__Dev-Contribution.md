# How to get involved

## Contribute code

If you're interested in contributing to the project, please subscribe to the [dev-mailing list](https://lists.roundcube.net/postorius/lists/dev.lists.roundcube.net/) first and join the discussion about ongoing development. Share your ideas and plans with us and prove your talent by submitting patches to the mailing list or attach them to the according tickets. Since we're on github now, you can also [fork](https://help.github.com/articles/fork-a-repo) our repository and submit pull requests for the changes you're made. To get familiar with our codebase, read the [Code Documentation](wiki__Dev-Docs.md) and check out the latest copy from [github](https://github.com/roundcube/roundcubemail). Please also read the [Development Guidelines](wiki__Dev-Guidelines.md) and make sure your code fits the requirements described there.

### Find a task

Visit the [issue tracker](https://github.com/roundcube/roundcubemail/issues) to see open tickets for the next release.

### Join the team

Everybody who **seriously** considers joining the project team is asked to drop a message with his/her skills and his/her ideas about Roundcube to hello[at]roundcube.net. Please don't forget to mention the patches you've already contributed. In order to get the requested privileges, register on this platform before and include your username in the mail message.

## Translation

We have moved our translations to Transifex where you can contribute and help to keep the translations up-to-date. Go to [Transifex](https://explore.transifex.com/roundcube/roundcube-webmail/) and register yourself as a Transifex user. In order to start translating, you have to become a member of the translation team for your language. To do so, choose your language from the list and then click "Join team" on the upper right part of the overview page. Your request will be proceeded as fast as possible.

## Documentation

Did you want to know how to do something and find that the documentation didn't explain it or didn't explain it well? We're happy to accept additions to the documentation; simply create a [ticket](https://github.com/roundcube/roundcubemail/issues/new) with the text and either a link to the existing page or a request for a new page.
