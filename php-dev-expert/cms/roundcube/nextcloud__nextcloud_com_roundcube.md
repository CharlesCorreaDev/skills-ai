## Serving mail quickly with Stalwart

Stalwart Mail Server is a secure, fast, robust and scalable on premises email SMTP and MTA solution. It offers key features, from message authentication standards and transport security to advanced Spam and Phising detection technology. It offers multiple storage technologies, web based administration and industry-leading security.

The Nextcloud Roundcube Enterprise subscription optionally includes Stalwart as mail server and MTA.
