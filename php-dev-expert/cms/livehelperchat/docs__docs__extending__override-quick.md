# Customize Your Web Application by Overriding Templates, Images, and CSS | Live Helper chat

> **Fonte / Source:** https://doc.livehelperchat.com/docs/extending/override-quick

---

This document serves as a reminder of the customization options available.

- You can override any image in the web application without [overriding the default ones](docs__docs__development__unbrand.md#how-to-change-logo).
- You can override any CSS in the web application without [overriding the default ones](docs__docs__development__unbrand.md).
- You can override [any template](docs__docs__extending__override-template.md) without overriding the default ones.
- You can override [any class](docs__docs__development__override-class.md).
- You can override [any module or a single URL](docs__docs__extending__override-module.md).
- You can override [translations](docs__docs__language.md#how-to-override-default-translations).
- If you are unsure which template is being used, enable [debug output](docs__docs__debug.md).
- If you change templates and nothing happens, [disable the cache](docs__docs__debug.md#disabling-cache).
- You can write [your own extensions](docs__docs__extending__writing-extension.md).
- We use the Bootstrap 4 CSS framework.

Each time you modify the original files, you lose upgrade capabilities. Live Helper Chat is very flexible and allows you to change almost everything without modifying the core.
