## WordPress

If you are using OWA in connection with WordPress, install the [OWA WordPress integration plugin](https://wordpress.org/plugins/open-web-analytics/) from the WordPress's plugin repository. Documentation and instructions can be found in the [plugin's Github repository](https://github.com/Open-Web-Analytics/owa-wordpress-plugin/).

## MediaWiki

The bundled MediaWiki plugin was removed in 2025 and OWA no longer ships
`mw_plugin.php`. Track a MediaWiki site with the [Javascript Tracker](Javascript-Tracker.md), or from
PHP with the [OWA PHP SDK](https://github.com/Open-Web-Analytics/owa-php-sdk).
