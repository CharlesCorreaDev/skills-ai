There are three ways to integrate OWA with your web site or application:

- [Javascript Tracker](Javascript-Tracker.md)
- [OWA PHP SDK](https://github.com/Open-Web-Analytics/owa-php-sdk)
- REST Web Service

If your application is written in PHP, you can use the [OWA PHP SDK](https://github.com/Open-Web-Analytics/owa-php-sdk) to add OWA tracking to your application server-side, which avoids the extra HTTP request made by the Javascript tracking method.

If your application is written in a programming language other than PHP, the [Javascript Tracker](Javascript-Tracker.md) (or posting directly to the REST web service) is probably your best bet.
