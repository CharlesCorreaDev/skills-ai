# Form Fields | Joomla! Programmers Documentation

> **Fonte / Source:** https://manual.joomla.org/docs/general-concepts/forms-fields/

---

Version: 6.1 (Current)

This section describes the types of Joomla fields which you can use in Joomla forms, and how to develop custom form fields. The descriptions assume that you're familiar with [Joomla forms](manual_docs__general-concepts__forms.md).

You can download [this example component](https://github.com/joomla/manual-examples/tree/main/component-exampleform) which demonstrates a number of the aspects described here.
