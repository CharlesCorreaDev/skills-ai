# Tutorials

This is a series of mini-tutorials how to use Joomla. It gradually and step-by-step teaches you how to use Joomla.  Starting with the base, gradually adding more advanced topics. We have divided those tutorials into three main subjects:

- **Content Management**: given you have a Joomla site and have administrator rights (for instance by creating **a free site on [launch.joomla.org](https://launch.joomla.org/)**.) make webpages, add new content and edit existing articles.
- **Site building**: how to set up a Joomla site. Including user groups, ACL, Custom Fields, templates and overrides, configuration, editors, dashboards etc.
- **Site Maintenance**: to keep the software of an existing site up-to-date, you have to update Joomla and extensions, make backups (and know how to restore the site), manage users, check site health.
