# General Concepts | Joomla! Programmers Documentation

> **Fonte / Source:** https://manual.joomla.org/docs/general-concepts/

---

Version: 6.1 (Current)

This is the content for developers who want to know how Joomla works, the underlying concepts and patterns. These general concepts are applicable to different types of Joomla [extensions](manual_docs__building-extensions.md).

Concepts which are specific to a particular type of extension are described within the appropriate [building extensions](manual_docs__building-extensions.md) area, for example:

- [MVC pattern](manual_docs__building-extensions__components__mvc.md) - which is appropriate to components
- [Events](manual_docs__building-extensions__plugins__plugin-events.md) - which is appropriate to plugins
