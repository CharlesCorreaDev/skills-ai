# Joomla User Guide

This user guide shows the current user documentation. You can contribute to that: see under [Contributors](guide__contributors.md).

In this user guide we have four types of documentation, following the [Diátaxis](https://diataxis.fr/) system:

- **Explanations**: articles *about* working with Joomla, ordered by subject.
- **Tutorials**: step-by-step introductions into the concepts used in Joomla. We have tutorials for content management , and are working on tutorials for site building and site maintenance.
- **How-to guides**: step-by step recipes how to accomplish specific things in Joomla.
- **References**: help pages, summing up all possibilities of an Administrator page.

See [manual.joomla.org](https://manual.joomla.org/) for the developers manual for Joomla. You can do a pull request to the [Github repository](https://github.com/joomla/manual) to improve or enhance the developers documentation.

## Help wanted

Your help to improve and enhance the documentation is needed and very much appreciated! We are working on it to make contributions to the user guide as easy as possible. This is the current procedure to do that:

- Under "Contributors" you'll find more detailed instructions and suggestions how to sign in with Joomla's Identity Portal, and what to contribute.
- After logging in (under "Contributors"), create a new article. Don't bother about where to place it: we'll do that. Just write and submit it.

## Translations

We are implementing our system for automatic translations, with translator feedback. Then the user documentation will be available in many languages. Please let us know if you want to help improving those translations.

We now want to focus on the content and only work on the text in English.

## Origin

The content under "Explanations" of the current user guide is composed of articles that were originally in our wiki at [docs.joomla.org](https://docs.joomla.org). Three years ago they were migrated to Github Markdown and used as basis for [JDocManual](https://jdocmanual.org) (a Joomla extension using documents in a Git repository) and Docs-Next (also using a GitHub repository as basis, but rendered with Docusaurus, like the developers manual does). The content of JDocManual was updated after that migration. For our user guide on this site we used the content of JDocManual as our base. We are constantly updating it and we added the tutorials. If you have anything that is missing or should be improved, please let us know.
