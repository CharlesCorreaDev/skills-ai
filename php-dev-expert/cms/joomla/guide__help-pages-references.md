# Help Pages

Joomla has so called Help Pages: the reference documentation we have for all pages in the administrator side. When clicking the Help button in an administrator page, you'll see that page in a pop-up. You already have an overview of those pages in the administrator, when clicking Help in the side menu and then clicking "Joomla! Help" in the main screen.   
  
Help pages are typically a reference type of documentation: summing up all possible options you can set on that page. By adding the Help pages here, we have the four Diátaxis categories complete:

- The **explanations** in the original User Guide.
- The new **tutorials** about content management, site building and site maintenance.
- The **how-to** guides about getting concrete tasks done.
- The Help pages **references**.
