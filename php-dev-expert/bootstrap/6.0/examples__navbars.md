# Navbar examples

This example is a quick exercise to illustrate how the navbar and its contents work. Some navbars extend the width of the viewport, others are confined within a `.container`. For positioning of navbars, checkout the [top](examples__navbar-static.md) and [fixed top](examples__navbar-fixed.md) examples.

At the smallest breakpoint, a drawer is used to hide the links and show a menu button to toggle the collapsed content.
