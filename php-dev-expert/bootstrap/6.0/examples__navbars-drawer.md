# Navbar with drawer examples

This example shows how responsive drawer menus work within the navbar. For positioning of navbars, checkout the [top](examples__navbar-static.md) and [fixed top](examples__navbar-fixed.md) examples.

From the top down, you'll see a dark navbar, light navbar and a responsive navbar—each with drawers built in. Resize your browser window to the large breakpoint to see the toggle for the drawer.
