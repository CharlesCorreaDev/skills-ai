## Visão geral

O SQL Server® 2005 é uma plataforma de banco de dados ideal para uso em ambientes de hospedagem da Web compartilhados e dedicados.

## Guia de implantação

O  oferece práticas recomendadas para configurar o SQL Server 2005, com o objetivo de otimizar a segurança, o isolamento de inquilinos e o desempenho da sua implantação do SQL Server 2005 hospedado. Scripts de exemplo para provisionamento de usuários e bancos de dados para uso na hospedagem compartilhada estão incluídos.

## Provisionamento de Usuário

A seção [Provisionamento de Usuário](https://www.microsoft.com/technet/prodtechnol/sql/bestpractice/sql2005dgwhe.mspx#EBBAC) aborda:

- Provisionamento de usuário e banco de dados (logons, usuários e bancos de dados)
- Procedimento armazenado para criar assemblies
