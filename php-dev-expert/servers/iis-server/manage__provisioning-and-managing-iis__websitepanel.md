## WebsitePanel

Outra opção para provedores de hospedagem é WebsitePanel. WebsitePanel, anteriormente conhecido como DotNetPanel, é um painel de controle de software livre criado exclusivamente para a plataforma de tecnologia Web do Windows. Com a ajuda de ex-desenvolvedores do DotNetPanel, a Microsoft está investindo no futuro e no sucesso do WebsitePanel, contribuindo com suporte para esforços de desenvolvimento contínuos. O WebsitePanel foi projetado para desenvolvedores que gerenciam servidores e sites de clientes e provedores de serviços de hospedagem que oferecem serviços de hospedagem do Windows.

[![Captura de tela da tela Painel do Site mostrando as seções Espaços de Hospedagem e Regras de Conta de Usuário.](websitepanel/_static/image2.png)](https://learn.microsoft.com/pt-br/iis/manage/provisioning-and-managing-iis/websitepanel/_static/image1.png)

A lista de recursos do WebsitePanel inclui:

· Arquitetura de vários servidores verdadeira

· Lista longa de [software e plataformas com suporte](http://websitepanel.net/SupportedSoftware.aspx)

· Fechar a integração com a Galeria de Aplicativos Web da Microsoft

· Integração do WPI (Microsoft Web Platform Installer)

· Forte apoio da comunidade

O WebsitePanel foi enviado recentemente como um projeto de software livre no [SourceForge](https://sourceforge.net/projects/websitepanel/) e carrega uma licença BSD.
