# Melhorando o desempenho com o cache de saída nativa

Comentários

por a equipe do IIS

Reduza drasticamente o tempo de resposta do aplicativo Web aproveitando o HttpCacheModule nativo no IIS que armazena todas as saídas do aplicativo no cache do modo Kernel. Este tutorial aborda a habilitação e a configuração do cache do modo de usuário e do kernel criando novas regras de cache de saída na configuração e por meio da GUI do Gerenciador do IIS.
