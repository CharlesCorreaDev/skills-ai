## Introdução

O Provedor do PowerShell do IIS é um Snap-In do PowerShell que permite gerenciar a configuração do IIS e os dados em tempo de execução. Ele fornece acesso fácil a sites, pools de aplicativos, aplicativos web, diretórios virtuais, requisições em andamento, processos de trabalho e domínios de aplicativos .NET nos processos de trabalho.

Siga os passo a passo subsequentes. Elas abrangem a funcionalidade abrangente do Provedor do IIS PowerShell usando cenários comuns. É recomendável que você comece com os passo a passo básicos primeiro para entender como o Provedor do IIS PowerShell funciona.
