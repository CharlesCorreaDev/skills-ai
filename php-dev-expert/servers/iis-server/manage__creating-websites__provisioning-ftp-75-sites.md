# Provisionando sites FTP 7.5

Comentários

por [Walter Oliver](https://github.com/walterov)

Os artigos a seguir apontam para guias recomendados para provisionamento de sites FTP 7.0:

- Criando um novo site
- Adicionando FTP a um site
- Administrando usando arquivos de configuração

## Guia para criar sites FTP

Este [guia](publish__using-the-ftp-service__creating-a-new-ftp-site-in-iis-7.md "criando um novo site ftp")  orienta você através da criação de sites FTP do zero usando dois métodos:

- A nova interface do usuário do Serviço de Publicação FTP
- Editando diretamente os arquivos de configuração do IIS.

## Guia para adicionar FTP a um site

Este  explica como adicionar a publicação FTP a um site existente:

- Usando a nova interface do usuário do Serviço de Publicação FTP
- Editando diretamente os arquivos de configuração do IIS.

## Guia para arquivos de configuração

Essa  orienta você na criação de sites FTP e na implementação de alguns cenários comuns editando diretamente os arquivos de configuração do IIS.
