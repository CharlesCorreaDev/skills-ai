# Configurando o SSL no Gerenciador do IIS

Comentários

por a equipe do IIS

Habilitar a segurança SSL avançada para proteger seus aplicativos Web é mais simples de configurar com o Gerenciador do IIS e mais fácil de implantar com certificados autoassinados no IIS 7.0 e superior. Este tutorial aborda a adição de certificados autoassinados, a criação de certificados com uma Autoridade de Certificação e a configuração de associações HTTPS.
