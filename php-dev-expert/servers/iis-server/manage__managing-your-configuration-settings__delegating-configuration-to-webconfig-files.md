# Delegando a configuração para arquivos de web.config

Comentários

por a equipe do IIS

A configuração distribuída baseada em arquivo é um recurso poderoso do IIS que permite o gerenciamento delegado das configurações do aplicativo Web em um nível muito granular. Este tutorial aborda a estrutura do IIS e ASP.NET configuração, desbloqueando a configuração do IIS para delegação, criando e definindo a configuração em arquivos Web.config e usando marcas de localização.
