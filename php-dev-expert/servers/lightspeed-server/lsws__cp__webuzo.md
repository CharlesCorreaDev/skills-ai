# Overview[¶](#overview "Permanent link")

Webuzo is a multi-user web-hosting control panel built for hosting providers, resellers, and website owners around the world. It's powerful and easy to use.

## Key Features[¶](#key-features "Permanent link")

- User Plans
- MultiPHP Selector
- Mail server
- FTP Server
- DNS server
- Automatic SSL
- Site Backup
- Applications Management
- Statistics
- Terminal

## Security Features[¶](#security-features "Permanent link")

- Two-Factor Authentication
- Brute Force Protection
- Mod Security
- Jailshell
