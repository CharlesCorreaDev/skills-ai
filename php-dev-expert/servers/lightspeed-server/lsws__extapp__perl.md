# Introduction[¶](#introduction "Permanent link")

LiteSpeed Web Server comes with a persistent Perl CGI daemon which can run Perl CGI scripts without modification, just like mod\_perl in Apache. This documentation will help you [get started](lsws__extapp__perl__configuration.md), configure Perl, troubleshoot, and more.
