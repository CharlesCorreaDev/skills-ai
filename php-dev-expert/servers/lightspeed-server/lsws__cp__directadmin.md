# DirectAdmin[¶](#directadmin "Permanent link")

This guide will teach you how to convert a DirectAdmin shared-hosting server to an optimized high-performance DirectAdmin + LiteSpeed Enterprise Web Server.

You will learn how to best utilize LiteSpeed Web Server, LiteSpeed Cache, and LiteSpeed Cache Manager for DirectAdmin.

Start with [Installation](lsws__cp__directadmin__installation.md) or navigate the sidebar menu for other options.
