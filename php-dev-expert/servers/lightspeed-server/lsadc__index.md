# Overview[¶](#overview "Permanent link")

LiteSpeed Web ADC is a high-performance load-balancer application. It is feature-rich, secure, and efficient, offering more flexibility than similarly-priced load balancing software. This makes it an excellent choice for small enterprises looking to scale their applications beyond one server. LSADC gives you improved service speed as well as reliability in case of hardware failure. Manage multiple backend servers, and handle scenarios ranging from a few very heavy sites, to thousands of domains at a time. [Learn more about LiteSpeed Web ADC](https://www.litespeedtech.com/products/litespeed-web-adc)

## System Requirements[¶](#system-requirements "Permanent link")

Your hardware must meet the following minimum system requirements in order to use LiteSpeed Web ADC.

### Operating System[¶](#operating-system "Permanent link")

One of the following:

- Linux(x86\_64): Kernel 2.6 and above
- FreeBSD(x86\_64): 9.0 and above

### CPU[¶](#cpu "Permanent link")

One of the following:

- Intel: Core i7 ("Nehalem") and above
- AMD: AMD Bulldozer and above

### Memory[¶](#memory "Permanent link")

- 512MB and above

### Disk[¶](#disk "Permanent link")

- Installation: 100MB
- Runtime: 200MB and above, swapping space depends on usage
