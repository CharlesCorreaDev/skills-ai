# Switching Licenses[¶](#switching-licenses "Permanent link")

You can switch to an Enterprise license from a trial license with the **License Management** section of the LiteSpeed WHM plugin. Simply click the **Change License** button.

[![!WHM Plugin Main Page With Change License Icon Circled](../images/switch-license01.png)](https://docs.litespeedtech.com/lsws/cp/cpanel/whm-litespeed-plugin/images/switch-license01.png)

## Switch from Trial license[¶](#switch-from-trial-license "Permanent link")

After clicking **Change License**, you should see the image below.

[![!WHM Plugin "Change Software License for LiteSpeed Web Server" Page](../images/switch-license02.png)](https://docs.litespeedtech.com/lsws/cp/cpanel/whm-litespeed-plugin/images/switch-license02.png)

- Tick `I agree`
- Tick `Use an Enterprise license`
- Enter in your serial number, e.g. `TEST-DRue-zm-m-TEST`
- Click the **Switch** button

## Switch to Apache when License Expires[¶](#switch-to-apache-when-license-expires "Permanent link")

LiteSpeed will automatically switch to Apache if the LiteSpeed license expires. To avoid this behavior, please renew your LiteSpeed license (from the store where it was purchased) *before* the expiration date.
