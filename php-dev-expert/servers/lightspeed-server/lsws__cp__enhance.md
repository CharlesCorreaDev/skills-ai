# Overview[¶](#overview "Permanent link")

Enhance is relatively a new, containerized web hosting control panel which supports LiteSpeed Web Server and OpenLiteSpeed. With Enhance you can easily add new domains or vhosts, and manage SSL for them. Additionally, the LSCache module is activated by default, making it easy for users to cache their web pages.

Enhance also has WordPress toolkit which includes plugin management.

## Features[¶](#features "Permanent link")

- Multiple PHP versions
- WordPress installer
- Multi-server cluster
- Auto SSL
- DNS Server.
- PHPMYAdmin.
- Mail Server.
- FileManager.

See [Enhance's documentation](https://enhance.com/support) for more information.
