# Using mod\_rewrite to control access

This document has been deprecated. Its content has
been reorganized into the
[When not to use mod\_rewrite](rewrite__avoid.md) document, since
the recipes here are better accomplished using other Apache httpd
features. This page will be removed in a future version of this
documentation.

- **Forbidding image hotlinking** - See
  [When not to use mod\_rewrite](rewrite__avoid.md#blocked-inline-images)
- **Blocking of robots** - See
  [When not to use mod\_rewrite](rewrite__avoid.md#blocking-of-robots)
- **Denying hosts in a reject list** - See
  [When not to use mod\_rewrite](rewrite__avoid.md#host-deny)
